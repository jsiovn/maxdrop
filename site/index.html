Version {{version}} is an early release

MaxDrop is a new fork of the free io_scene_max importer. MaxDrop reads the scene and its materials with its own reader, also from the scene pack it came in; io_scene_max's file parser is gone.

It brings in editable meshes with their UVs, smoothing, instances, hierarchy, layers and scene units, and V-Ray, Corona, Standard and Physical materials with their texture maps. Lights, cameras, splines and modifiers are not read yet, so a whole interior scene will arrive incomplete. See the full list.

Whole scenes are what the next versions are for, and updates arrive inside Blender.

Install

Install it from this repository, either way below, so Blender can update it later.

By drag and drop Quickest

  1. With Blender open, drag MaxDrop {{version}} (or the big button above) onto the Blender window.
  2. The first time, Blender says the extension comes from an unknown repository. Click Add Repository…, tick Check for Updates on Startup, then click Create.
  3. Drag the button onto Blender again and click OK to install. If Blender asks, choose Allow Online Access.

By repository URL

  1. In Blender open Edit › Preferences › Get Extensions, then Repositories › + › Add Remote Repository.
  2. Paste this URL, tick Check for Updates on Startup and click Create:
    {{repo_url}}
  3. Search for MaxDrop in Get Extensions and click Install.

Do not use Install from Disk

Blender never updates a copy installed from a downloaded zip. If you installed it that way, uninstall it and install it again as above.

What version {{version}} imports

The honest list for this release. The support page on GitHub has every detail and is updated with each version.

Arrives in Blender

  • Editable Mesh and Editable Poly objects: vertices, faces, material IDs, UV channels, smoothing groups, and instances as shared meshes.
  • Position, rotation, scale and the whole hierarchy of the objects; groups and Dummy helpers become empties.
  • Scene units: a scene saved in millimeters, centimeters, inches or feet arrives at its real size.
  • Layers as collections, with their hidden, frozen and non-rendering flags.
  • Materials, as a Principled BSDF with their maps as nodes (tiling, offset, rotation, cropping, Mix, Color Correction, normal and bump maps): VRayMtl and the other V-Ray materials and wrappers, Standard, Physical, Multi/Sub-Object, CoronaPhysicalMtl, CoronaMtl, CoronaLightMtl and CoronaLayeredMtl.
  • Textures that are plain image files, next to the .max file, in a maps or textures folder beside it, or in folders you add in the preferences.

Not imported yet

  • Lights and cameras, V-Ray lights included.
  • Modifiers (Extrude, UVW Map, TurboSmooth, Shell…): the object arrives as it was before its modifiers.
  • Splines and shapes, so walls and floors made from an extruded outline are missing.
  • Primitives (Box, Sphere, Cylinder…): they arrive as empties until a later version.
  • Animation: objects arrive as they stand at frame 0.
  • Procedural maps (Noise, Gradient, VRayDirt, Falloff…): simplified to the image below them, or the channel keeps its plain color.
  • Other materials (Arnold Standard Surface, Raytrace, Architectural, Corona Skin and Hair…): a grey material that keeps its name.
  • Proxies, particles, hair and bones.

Using it

There is no panel: MaxDrop adds an importer.

Import a scene

  1. Drag a .max file from your file manager onto Blender's 3D Viewport, or choose File › Import › MaxDrop (.max, .zip, .rar, .7z).
  2. Check the options. Units: Auto takes the unit the scene was saved with, so it arrives at its real size.
  3. Click Import. A large scene takes a while; Blender does not respond until it is done.
  4. The text MaxDrop Report in the Text Editor lists what arrived and what did not. It also says what became of the materials: converted, simplified, and the textures not found.

Scene packs work too: choose the .zip, .rar or .7z in File › Import, or drop the .rar or .7z. MaxDrop unpacks the scene with the maps it uses into a folder named after the archive, next to it, and imports it from there. Nothing else in the pack is written or run.

The options

  • Scene picks the .max to import from a pack that holds several.
  • Image Search also looks for the textures in the subfolders of the scene's folder.
  • Object Filter picks whether materials and UV maps come along.
  • Units overrides the unit of the file (millimeters, centimeters, meters, inches, feet); Scale is an extra factor; Forward and Up turn the scene.
  • Every import makes a collection named after the file, with one collection per 3ds Max layer.

Textures

A .max file names its texture files but does not contain them. MaxDrop looks for each file name in the folder of the scene, then in maps or textures folders beside it, then in the Texture Search Folders of the preferences, and last at the path stored in the scene, only when it is on a local drive.

A network or device path stored in a scene is never opened. A texture that is not found is skipped: the material keeps its color.

Next to io_scene_max

MaxDrop can be enabled together with the importer it comes from. When you drop a .max file, Blender then asks which one to use: pick MaxDrop (.max, .rar, .7z).

Updating

With Check for Updates on Startup ticked, Blender offers new versions in Get Extensions.

Or press Check for Updates in Preferences › Add-ons › MaxDrop: a newer version is installed right away.

Troubleshooting

Still stuck? Open an issue with your Blender version and the text MaxDrop Report from the Text Editor (or the system console).

Blender says the extension comes from an unknown repository

That is the first drop doing its job. Click Add Repository…, tick Check for Updates on Startup, click Create, then drag the button onto Blender once more to install.

The scene arrives huge, or tiny

With Units: Auto MaxDrop uses the unit the file was saved with. If the scene was modelled in another unit than that, import again with that unit picked in Units; Scale is an extra factor and should stay at 1.

Objects are missing, or the room has no walls

Lights, cameras, splines and everything built by a modifier are not imported yet; see what this version imports. An object MaxDrop cannot convert arrives as an empty that keeps its place in the hierarchy.

Materials arrive without textures

Put the texture files in the folder of the .max file, in a maps or textures folder beside it, or add their folder under Texture Search Folders in the MaxDrop preferences. Image Search also searches the subfolders of the scene's folder. Mix, Color Correction, simple Composite and normal maps arrive as nodes; Falloff and other procedural maps are simplified to the image below them, and a channel with no image below keeps its plain color.

Dropping a .zip opens Blender's extension installer

Blender takes every dropped .zip for an extension to install, before any importer is asked. Choose the .zip in File › Import › MaxDrop instead; a .rar or .7z can be dropped.

A .rar or .7z cannot be read

MaxDrop unpacks them with a program already on your computer and brings none itself: UnRAR (installed with WinRAR), 7-Zip, or a recent bsdtar (the tar of an up-to-date Windows 11, and of macOS). Install one, or extract the archive yourself and import the .max. Archives with a password or split into parts are not read.

“Online access is off”

Only Check for Updates goes online. Allow it in Edit › Preferences › System › Network › Allow Online Access. Importing works without it.

“This copy was installed from disk, so Blender cannot update it”

Uninstall it in Preferences › Add-ons, then install it from this page.

About

A free tool for people who receive .max scenes and work in Blender.

Credits

MaxDrop is a fork of io_scene_max by Sebastian Schrand, which builds on Importer3D by Jens M. Plonka and on olefile by Philippe Lagadec. Reading .max files without 3ds Max is their work.

Independent

MaxDrop is not affiliated with, endorsed by or supported by Autodesk or Chaos. Autodesk and 3ds Max are trademarks of Autodesk, Inc.; V-Ray and Corona are trademarks of Chaos. The names are used only to say which files and materials are read.

Privacy

The importer reads the file you give it and the textures beside it, on your computer; from a scene pack it writes the scene and its maps into a folder next to the archive. The add-on goes online for one thing only, when you press Check for Updates: it reads the version list of this site. No telemetry, no account.
