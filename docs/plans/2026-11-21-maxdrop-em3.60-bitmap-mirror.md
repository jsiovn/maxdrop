# Bitmap mirror as 3ds Max draws it Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Bitmap (CoronaBitmap, VRayBitmap) with Mirror on is drawn mirrored as 3ds Max draws it, with and without a
crop, per axis (bead maxdrop-em3.60).

**Architecture:** `maxdrop/build/materials.py` only. One rule for both paths: per axis MIRROR (mirror on, wins over
tile), REPEAT (tile) or CLIP; a mirrored axis is doubled right after the placement Mapping (a Vector Math MULTIPLY,
2 on a mirrored axis, 1 on the other), then ping-ponged with period 2 (Blender's MIRROR extension or a PINGPONG node
at scale 1). Without a crop one extension still serves when both axes agree; mixed axes get the crop path's per-axis
nodes over a unit cell.

**Tech Stack:** Blender shader nodes (4.2 to 5.2), tests/blender/run.py.

---

## Measured in 3ds Max 2020 (2026-11-21)

`renderMap` (scanline, `filter:false`, Bitmap filtering none) of a self-made 64 x 64 ramp (R = 4 x column, G = 4 x row
from the top), 32 samples across U at mid height, red channel:

| case | row |
|---|---|
| U tile on, mirror off, tiling 1 | 4 12 19 ... 244 252 (one copy) |
| U tile on, mirror on, tiling 1 | 8 24 40 ... 231 248 248 231 ... 24 8 (two copies, the second mirrored) |
| U tile off, mirror on, tiling 1 | the same as tile on: mirror tiles too |
| mirror on, tiling 0.5 | 131 139 ... 244 252 252 244 ... 139 131 |
| mirror on, tiling 2.0 | 239 208 ... 48 16 16 48 ... 208 239 239 208 ... 16 16 ... 208 239 |
| mirror on, U offset 0.1 | 40 24 8 4 19 36 ... 244 248 231 ... 72 55 |
| mirror on, crop u 0.25 w 0.5 | 68 75 ... 180 187 187 180 ... 75 68 (the crop twice) |
| mirror on, placed u 0.25 w 0.5 | out x4, 16 48 ... 239 (whole image), out x8, 239 ... 16, out x4 |
| V mirror on (column, G) | 248 231 ... 24 8 8 24 ... 231 248 |
| U mirror on, W angle 90 (16 x 16) | along V: R 16 48 ... 239 239 ... 16 (doubled); along U: G once 248 .. 8 |
| CoronaBitmap tilingU 2 (mirror) | 7 23 ... 247 247 ... 23 7: the same doubling |

So image coordinate = pingpong(2 p, period 2) on a mirrored axis, p the placed coordinate (after tiling, offset and
the W turn: the doubling acts on the image's axis, after the rotation); mirror wins over tile. The crop path's
ping-pong today runs at half that frequency (one copy per tile): fixed here too. CoronaBitmap mode 2 sets
tile and mirror, so no convert change.
