# Corona render measurements Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn what maxdrop-em3.28 could only approximate (CoronaLegacyMtl PBR mode off, CoronaPhysicalMtl iorMode,
edge color and translucency, CoronaLayeredMtl mask weighting) into measured rules or confirmed issues, from Corona 12
renders.

**Architecture:** `convert/materials.py` only: a measured table for the PBR-off glossiness (as `texmaps.CORONA_KELVIN`
is one), the specular IOR mode for the base and clearcoat IORs, the translucency issue narrowed to thin mode; the
layered weighting and the edge color stay as they are (confirmed rule, confirmed issue). One fixture script gains two
nodes (`corona_physical.ms`), its file and oracle regenerated. Docs: FORMAT.md, SUPPORT.md, CHANGELOG.md.

**Tech Stack:** Python 3.11 syntax, standard library, `unittest`; 3ds Max 2020 + Corona 12 (`3dsmaxbatch`) for the
probes and the fixture save; Blender 4.2 / 4.5 / 5.2 headless for the fixture checks.

## Facts (Corona 12 renders, 2026-11-24, probes local in a folder of the bead's own, outside the repo)

Read with `getPixels ... linear:true` from CoronaRenderer with tone mapping off (`colorMap_enabled false`), a pass
and a time limit on every render; a CoronaLightMtl patch at 0.5 / 1.0 read 0.49999 / 1.0, a white diffuse plane under
a white background 0.99999 (so the readout is the linear value).

- **CoronaLayeredMtl** (black base, a self-illuminated white layer): amount 0.6 with a constant mask 0.25 at mask
  amount 0.5 gives 0.375 = amount x lerp(1, mask, maskAmount) (the alternative lerp(amount, mask, maskAmount) would
  be 0.425); amount 0.4, mask 0.75, mask amount 0.5: 0.35; mask amount 0: the amount; masksOn off: the amount.
  The mask takes the value the same map gives as a self-illumination color, in both gamma modes (gamma off: swatch 64
  0.251, Bitmap 128 0.502; gamma on: swatch 128 0.502, Bitmap 128 0.2195; CoronaBitmap 128 0.2195 in both): the
  em3.122 rule (a mask in a color graph) holds; what a gamma-off scene shows of a CoronaBitmap is em3.165's.
  The rule as implemented is confirmed: no code change.
- **Opacity** (em3.122): a CoronaLegacyMtl and a CoronaPhysicalMtl opacity color 128 grey, gamma on: alpha 0.502
  (the swatch as stored): confirmed.
- **CoronaPhysicalMtl iorMode (461)**: 0 the value is an IOR; 1 the value is a specular level, F0 = 0.08 x value
  (0.5 -> 0.04, 3.0 -> 0.24), for baseIor (171) and clearcoatIor (221) alike; F0 never above 0.25 in either mode
  (an IOR above 3 reflects as 3, a specular above 3.125 as 3.125; an IOR below 1 as its reciprocal). 2 renders as an
  IOR (not a value the UI offers: MAXScript's setter converts the stored values on every mode change, so a script
  must set iorMode before the values). The renderer's defaultIorMode only picks a new material's mode.
- **Edge color (161)**, metal spheres under a white background, roughness 0: per channel; white edges brighten the
  grazing reflection above Schlick, black darkens it; the default (0.75) is close to Schlick (rms 0.006 / 0.016 /
  0.05 for F0 0.9 / 0.6 / 0.3). No model fits all spheres: Schlick, Blender's F82 tint (best tint 0.98-1.32 for the
  default edge, 0.64-0.82 for black, above 1 for white), Gulbrandsen's edge tint, a free conductor (n, k). Blender's
  Specular Tint cannot reproduce it (a tint above 1 would be needed, and the tint a dark edge needs depends on F0 too):
  **confirmed issue**, kept for a non-default edge color.
- **Translucency**: CoronaPhysicalMtl translucency does nothing unless thin mode is on (fraction 0.5 / 1.0 lit from
  below: 0 / 0; thin: 0.48 / 0.96); CoronaLegacyMtl's works without thin (0.49 / 0.99): a diffuse transmission of the
  fraction. Blender's Principled BSDF has no diffuse transmission; a Translucent BSDF under a Mix Shader would scale
  the specular and coat by the fraction too and adds a BSDF path the layer mixing does not have. **Not worth it in
  this bead**: the issue stays (CoronaLegacyMtl) and is narrowed to thin mode (CoronaPhysicalMtl).
- **CoronaLegacyMtl PBR mode off (402)**: a mirror plane (Fresnel IOR 999) under a hidden emitter, the radial profile
  of the highlight compared with a PBR-on sweep (glossiness 0..1, step 0.025 and 0.01 above 0.9). The PBR-off
  glossiness g gives the profile of the PBR-on glossiness g' below; roughness = 1 - g'. From g 0.35 up the profiles
  agree (log rms 0.005-0.02, 0.038 at 0.85); below 0.3 no PBR-on glossiness has the same lobe (log rms 0.05 at 0.3,
  0.24 at 0): the best match flattens at roughness 0.618.
