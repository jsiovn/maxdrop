# Shell rim: rim_corners at _open_loops' peak Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `rim_corners()` in `maxdrop/convert/scene.py` returns the same count with a peak memory no higher than
`_open_loops()`' own (which it calls), instead of several int64 and float64 arrays per corner of every boundary face.

**Architecture:** Only the body of `rim_corners` changes (signature and result kept; part E owns the rest of the
file). Indices become int32 (vertex indices are int32 in reader.geometry, corners below `MAX_LOOPS = 1 << 27`), and
the per-corner work (face normals, their sums at the boundary vertices) and the per-open-edge work (rim normals,
the turn between consecutive rim faces) run in chunks of a fixed number of corners / edges, accumulating into
per-face and per-boundary-vertex sums. The rim normal of an edge is recomputed per chunk for the edge and the edge
that follows it, so no (B, 3) array of rim normals is kept. `check()` runs between the passes and per chunk.

**Tech Stack:** numpy, `tracemalloc` (numpy reports its buffers to it) for the test.

Bead: maxdrop-em3.146

## Task 2: rim_corners body

- [ ] int32 `lv`, `slot` (vertex -> boundary place), `oa` / `ob`; `loops` / `nxt` of `_open_loops` dropped
  once `oa` / `ob` are taken.
- [ ] Boundary faces found per chunk of loops (`slot[lv[a:b]] >= 0`, face by `searchsorted(starts)`), kept as one
  sorted int32 array of face indices.
- [ ] Pass 1, per chunk of the boundary faces' corners (a chunk may split a face: `numpy.add.at` sums), Newell
  normals into `normals` (F_b, 3); normalised after the pass.
- [ ] Pass 2, same chunks: unit face normals summed at the boundary vertices.
- [ ] Pass 3, per chunk of open edges: the rim normal of the edge and of the open edge leaving its end vertex
  (int32 argsort of `oa`, `searchsorted`), the turn, the count.
- [ ] Run: green; `python -I tools/lint.py` clean.
