# baseline.py: read the Imported line when it counts curves Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `tools/baseline.py` parses the operator's `Imported ...` line also when it holds `, N curves`, and
reports `curves` in `import_report`.

**Architecture:** `Report.summary()` (`maxdrop/convert/report.py`) writes `N objects, N meshes[, N curves][, N
materials]`; curves only when non-zero. The `IMPORTED` regex gets an optional curves group between meshes and
materials; `read_log` sums it into `import_report["curves"]` (0 when absent: the operator leaves the part out
when no curve was built, unlike materials, whose absence means "not counted" and stays `None`).

**Tech Stack:** Python standard library (`re`, `unittest`).

Bead: maxdrop-em3.55
