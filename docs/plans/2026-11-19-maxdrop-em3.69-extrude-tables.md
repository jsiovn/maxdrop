> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** an extruded object added to a fixture without entries in `EXTRUDE_EULER` / `EXTRUDE_SHARP_EDGES` of
`tests/blender/run.py` fails a plain test naming it, instead of a KeyError in the Blender run only.

**Architecture:** `check_extruded` (run.py) runs for every oracle node with a `shape` that converts to a mesh
(an Extrude on a shape): today `FixtureExt*` of `extrude.max` (all but `FixtureExtOff`, whose Extrude is off:
no `eval_verts`) and `FixtureUVWExtrude` of `uvwmap.max`. A new `FixtureTables` test in
`tests/unit/test_convert_scene.py` collects those names from every fixture's oracle (`shape` and `eval_verts`
not None, the rule the `Fixtures` mesh test already uses) and reads run.py's tables through `_run_py_table`
(ast, run.py imports bpy). No numpy, no convert: it runs in `FixtureTables`, which is not numpy-gated.

**Tech Stack:** plain Python `unittest`, `ast.literal_eval`.
