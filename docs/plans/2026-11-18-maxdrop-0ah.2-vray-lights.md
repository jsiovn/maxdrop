# V-Ray Lights Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A VRayLight becomes a Blender light: plane and disc an Area light (rectangle, disk), sphere a Point light
with a radius, with the shape, size, color and a power in watts from the ported formulas, times one calibrated
"Light Strength"; mesh and dome lights stay empties, named in the report.

**Architecture:** `convert/lights.py` (no bpy) reads a VRayLight's ParamBlock2 (reference slot 0) by parameter id
and returns a `LightDescription` in meters and linear color, or the reason it is not built. `convert/scene.py` calls
it for a base object of class VRayLight: the node's kind is `LIGHT`, `node.light` the key into `desc.lights` (the
base object index, so instances share one light). `build/lights.py` makes the Light datablock;
`build/objects.py` makes the object of a LIGHT node from it and sets the per-object flags (off, invisible, not in
reflections). `ops.py` has the option "Light Strength" (Transform panel's neighbor: Include), passed to the build.

**Tech Stack:** Python 3.11 syntax; 3ds Max 2020 + V-Ray 5.2 through 3dsmax-mcp (own instance) for the probes,
the fixture, its oracle and the calibration renders; Blender 4.2 / 4.5 / 5.2 headless.

## What 3ds Max 2020 + V-Ray 5.2 store (probed through the SDK's .NET wrapper, then read back by the reader)

- VRayLight: ClassId `(0x3C5575A1, 0x5FD602DF)`, superclass `0x30` (light). References: 0 = ParamBlock2 (block id
  0), 2 = the viewport icon object. Parameter ids: 0 on, 1 type (0 plane, 1 dome, 2 sphere, 3 mesh, 4 disc), 2 size0,
  3 size1 (world units; plane: HALF length along local X and half width along local Y, checked by a V-Ray render of
  a 20 x 60 plane; disc and sphere: size0 = radius), 7 color, 8 multiplier, 9 doubleSided, 10 invisible, 12
  normalizeColor (units: 0 default/image, 1 lm, 2 lm/m2/sr, 3 W, 4 W/m2/sr), 18 texmap, 19 texmap_on, 25
  affect_diffuse, 26 affect_specular, 30 affect_reflections, 36 lightDistribution (directional), 38
  color_temperature, 39 color_mode (0 color, 1 temperature), 43 targeted, 53 diffuse_contribution, 54
  specular_contribution.
- In temperature mode V-Ray also stores its own color in 7 (3500 K: 1.0, 0.584, 0.256); the rules source's
  `ocbaby_exsKelvinRGB` is used instead (as the bead says), decoded from sRGB like CoronaColor's temperature.
- A targeted VRayLight is a Look At controller node with a Target: maxdrop-0ah.1 already places it.

## Rules (ported from f_export_scene.ms, ocbaby_exsVrayLightWatts 902-918, ocbaby_exsKelvinRGB 887-893)

- area `a` in m²: plane `(2 size0 m)(2 size1 m)`, disc `pi (size0 m)²`, sphere `4 pi (size0 m)²`, other 1; plane and
  disc double-sided: `a *= 2`.
- watts by units: 1 `mult / 683`, 2 `pi mult a / 683`, 3 `mult`, 4 `pi mult a`, else `mult a 1500 / 683`.
- Blender power = watts × Light Strength; a double-sided plane or disc gets half (Blender's area light shines on
  one side: an issue says so). Color: color mode = the swatch rule of the scene (convert.colors), temperature mode =
  kelvin_rgb decoded from sRGB.
- Area: `RECTANGLE`, size = 2 size0, size_y = 2 size1 (m); disc `DISK`, size = 2 size0; sphere: `POINT`,
  shadow_soft_size = size0 (m). V-Ray's plane shines along local -Z, as Blender's area light: no turn.
- Object: off -> hide_viewport and hide_render; invisible -> visible_camera off; affect reflections off ->
  visible_glossy off. Light: diffuse_factor = affect_diffuse ? diffuse_contribution : 0, specular_factor the same
  with specular.
- Not built (EMPTY, an issue, not a placeholder): mesh light, dome light ("dome light -> World" is later work).
  Issues (approximations): double-sided, a texmap switched on, directional > 0, an animated parameter (its default).
- Dropped on purpose: spot mirrors, stock-light mirrors, light de-instancing.

## Calibration

V-Ray 5.2 and Cycles render the same scratch scene (the fixture's lights one at a time, invisible, 0.5 m above a
white Lambert floor, an orthographic camera looking down; V-Ray color mapping linear, no clamp, gamma off); the
mean of the center patch below each light, V-Ray / Blender at strength 1, gives the factor. The factor and the
spread across types and units go into docs/FORMAT.md and the bead notes; scene and renders stay in the scratch
folder.
