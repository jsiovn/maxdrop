# Node tree: negative constants on Mix color inputs; volume-only materials Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A constant color below 0 reaches every Mix color input and every RGB-node stand-in unclamped; a
volume-only material (a Corona medium, no surface) renders through any number of boxes, shows the scene in Solid
view and names Cycles' Volume Bounces in the report. With it, the two test gaps of maxdrop-6n0.6.31
(maxdrop-6n0.8.1).

**Architecture:** build/materials.py `_Tree.unclamped(value, space, depth)` puts a COLOR constant with a channel
below 0 on a Combine XYZ output (em3.161's arith form) and is used by every Mix feed (mix, multiply, arith, blend,
composite) and by `socket()`. `_Tree.build` / `_Tree.volume`: a material whose IR has a medium, a constant alpha of
0, no alpha map and no layers leaves Surface unlinked once `volume()` linked the Volume socket, keeps the default
render method and gets a viewport alpha of VOLUME_VIEWPORT_ALPHA; a medium that scatters adds one builder issue
per material (owner, 2026-11-24: a report line only, no scene setting changed). Beads: maxdrop-6n0.6.33,
maxdrop-6n0.8.1. Code only, no 3ds Max.

**Tech Stack:** Python 3.11, Blender shader nodes (4.2 to 5.2), unittest.

## Tasks

### Task 1: negative constants (maxdrop/build/materials.py)

- [ ] `_Tree.unclamped(value, space, depth)`: value unchanged unless space is COLOR, it is a constant and a
  channel is below 0: then `combine_xyz(value, depth)`.
- [ ] `socket()`: COLOR constant below 0 -> `combine_xyz` (an RGB node clamps too).
- [ ] `mix()`: both sides through `unclamped(v, space, depth + 1)` before `feed`.
- [ ] `multiply()` (COLOR Mix): both sides likewise.
- [ ] `arith()`: its inline branch replaced by `unclamped`.
- [ ] `blend()` (both Mix nodes, SPOTLIGHT_BLEND's second too) and `composite()` (A: the result so far, B: top).
- [ ] Docstrings of mix / multiply / arith / socket say so.

### Task 2: volume-only materials (maxdrop/build/materials.py)

- [ ] `VOLUME_VIEWPORT_ALPHA = 0.1`; `_volume_only(ir)`: medium set, alpha constant 0, no "alpha" texture, no layers.
- [ ] `volume()` returns whether it linked the Volume socket.
- [ ] `build()`: volume-only and linked -> remove the Surface link, render method left at the default (not
  BLENDED), `diffuse_color` alpha VOLUME_VIEWPORT_ALPHA; a linked medium with max(scattering) > 0 ->
  `builder.issue(label, VOLUME_BOUNCES)`: Cycles scatters once at its default Volume Bounces of 0, raise it for
  Corona's multiple scattering (the import changes no scene setting).
- [ ] Module docstring line for the volume rule.
