# LookAt Constraint: an unreadable target weight falls back to 50 Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a LookAt Constraint target weight the reader cannot read (an animated weight whose block slot is empty or
whose controller gives no value, a controller of an unknown class, a stored weight that is not finite, a weight
table shorter than the targets) takes 50, the weight 3ds Max's `appendTarget` gives a new target, on the
constraint's 0-100 scale, instead of 1, which beside a stored 100 almost dropped that target out of the average.
An empty slot or a value-less controller is reported (`CONSTRAINT_SETTING`, "its default used"), as a non-finite
or missing weight already is.

**Architecture:** `maxdrop/reader/controllers.py`, `_constraint`'s weight loop only. A new constant
`_LC_WEIGHT_DEFAULT = 50.0`. An animated weight is read with `self.scalar(index, None)`: `None` comes back for an
empty slot, a keyframe controller without value or keys, an empty Float List and an unknown class (which
`_scalar` already reports as `UNKNOWN_CLASS` on the weight's controller). The unknown class keeps that one issue
(the node evaluation keeps a set of the controllers it reported as `UNKNOWN_CLASS`: no scan of the issue list, which a hostile table of empty slots would make quadratic; the set still answers when the memo does); the other unreadable cases add `CONSTRAINT_SETTING` on
the constraint, once. `_list` (list controllers, 0-1 scale) keeps its 1.0.

**Decision (the bead's Scope):** 50, not the mean of the readable weights: it is the constraint's own default (so
`CONSTRAINT_SETTING`'s text stays true), it does not depend on the other targets, and a mean would need a second
fallback when no weight is readable. Not measured in 3ds Max: what 3ds Max does with a damaged weight is unknown;
50 is the value a target has until the user changes it.

**Tech Stack:** plain Python `unittest`; Blender 5.2 (before review), then 4.2.23, 4.5.16 and 5.2 headless.

Bead: maxdrop-em3.155
