# CoronaLegacyMtl metal rule beside a reflection map Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `corona_legacy_mtl` judges its metal rule by the reflection swatch's share beside a reflection map, as
`vray_mtl` does since maxdrop-em3.118, so a map at full amount never turns the material into a metal.

**Architecture:** One condition in `maxdrop/convert/materials.py` (`corona_legacy_mtl`): the swatch share is
`mean(reflection) * (1 - min(1, amount))`, where `reflection` already holds the color times the reflection level.
Corona's documentation (Corona Legacy Material, Reflection Level: "Both the reflection constant color and texture map
are multiplied by this number") says the level multiplies the map too, so the swatch's share keeps the level and the
map itself is not judged. Convert only: build/ is untouched.

**Tech Stack:** Python 3.11, plain unittest (no Blender for the unit test), Blender 4.2 / 4.5 / 5.2 smoke.
