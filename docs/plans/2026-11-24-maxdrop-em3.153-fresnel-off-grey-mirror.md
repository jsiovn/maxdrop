# VRayMtl Fresnel off: a grey reflection keeps the diffuse Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a VRayMtl with Fresnel off and a grey reflection swatch between METAL_REFLECTION and 1 (no reflection map)
is drawn by em3.120's mirror (w at every angle + (1 - w) diffuse), as V-Ray renders it, instead of a metal in the
reflection color that drops the diffuse.

**Architecture:** convert only (`vray_mtl`): the metal rule keeps Metallic 1 for a full reflection (mean >= 1), a
colored swatch (channel spread above NEUTRAL_REFLECTION, a new V-Ray-only constant) and a reflection map (as
today); a neutral swatch below 1 without a map falls through to the mirror drawing build/materials.py already
makes for a dim one. METAL_REFLECTION keeps its value (corona_legacy_mtl reads it).

**Tech Stack:** 3ds Max 2020 + V-Ray 5.2 (`3dsmaxbatch`), Blender 4.2 / 4.5 / 5.2 headless (EEVEE, Cycles), plain
Python unittest.

## Why convert only (no colored mirror copy here)

The exact V-Ray law, measured below, is per channel: `R_c + (1 - R_c) d_c`. A colored copy (Base Color R / max(R),
weight max(R)) would give `R_c + (1 - max R) d_c`, between today's metal and V-Ray in every channel, but it needs
`reflection_weight` / `specular` of build/materials.py changed. Those were part F's (em3.135); the epic's notes hand
them to part E after part F's PR #28 merged, but #28 is not on this branch (`git merge-base --is-ancestor
origin/main HEAD` fails) and rewrote both functions (refraction twin, total internal reflection). Editing them here
would collide when main is taken in. So: the grey case here, the colored copy a P4 debt bead in part E (after main
is in), with these numbers.

with Fresnel off over a colored diffuse (kept as today), a refracting Fresnel-off material (it now takes the
mirror drawing of this branch: a constant Transmission Weight 1 keeps the lone BSDF with Fresnel; main's 6n0.7.2
draws w + (1 - w) T there).
