## Facts measured (probes in `C:\maxdrop_fixtures\probe\o53_2_1\`, outside the repo)

- **Descriptors** (`.NET` `IParamBlock2.GetParamDef`), VRayPhysicalCamera block 0: 2 `f_number` (float, 8), 12
  `shutter_speed` (float, 200 = 1/200 s), 16 `ISO` (100), 10 `exposure` (int, 1), 56 `exposure_value` (float,
  13), 11 `vignetting` (bool, off), 39 `vignetting_amount` (1), 37 `whiteBalance_preset` (int, 4), 19
  `whiteBalance` (RGB, 254.783 254.874 255), 46 `temperature` (6500), 14 shutter angle, 17 shutter offset, 15
  latency, 36 legacy ISO, 38 system lighting units. Physical block 0: 6 `f_number` (8), 22 exposure gain type, 23
  ISO, 24 exposure value (out of scope: the exposure control decodes them, M8).
- **maxdiff** (base, base again, one change each): f-number -> params 2 and 56; shutter -> 12 and 56; ISO -> 16 and
  56; mode -> 10; EV -> 56 and 16; vignetting -> 11; preset 4 -> 0 (the same color) -> 37 only; temperature -> 46 and 19; Physical f-number ->
  6; Physical DOF -> 11; Physical focus -> 10 and 9.
- **Coupling** (3dsmaxbatch): setting f-number, shutter or ISO recomputes EV = log2(N² · shutter · 100 / ISO); setting
  EV recomputes ISO; in mode 2 a new f-number or shutter keeps EV and recomputes ISO. A new camera stores EV 13, not
  the 13.6439 its defaults give.
- **Modes** (V-Ray renders, a self-lit white plane, linear color mapping, gamma off): mode 0 renders 1.0 whatever the
  EV; mode 1 at the defaults 0.0199 (from f-number, shutter, ISO: EV 13.64), mode 2 at EV 13 0.0311 (from the stored
  EV); 3 EV stops darker, 8 times darker. So 0 off, 1 physical exposure, 2 exposure value. The factor itself is
  maxdrop-o53.2.2.
- **White balance presets** 0..6 set the color (0 and 4: 254.783 254.874 255; 1: white; 2: 191.25 226.023 255; 3:
  208.111 226.727 255; 5: 255 226.974 192.683; 6: 255 210.465 160.141); 7..9 white. Preset names not read.
- **Fixture** (first save 835 584 bytes, re-authored with FixtureExpStored 839 680; sanitize blanked 4 values; check_fixture clean; oracle dumped twice: same
  bytes): values as the script header lists; render 800 x 450; system unit mm; viewport 1 FixturePhysDof (active),
  viewport 2 FixtureExpPhysical, render view locked on 2 (oracle `render.camera` 3 = FixtureExpPhysical's handle).
  Reader read-back equals every value (f32: 5.6 -> 5.5999999).
