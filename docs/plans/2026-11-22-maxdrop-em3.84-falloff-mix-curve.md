# Falloff mix curve and Mix Use Curve Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw a Falloff's edited MixCurve (Custom Curve Control) as a Float Curve node on its ratio, and a Mix's
Use Curve as its measured smoothstep, instead of drawing both linear / reporting them.

**Architecture:** `reader/materials.py` reads the Curve Control a map references (by ClassID) into its curve points,
bounded, bpy-free. `convert/texmaps.py` evaluates them as 3ds Max does (measured) into a polyline, a new IR node
`Remap(input, points)` over the Falloff's `Facing`; a linear curve makes no node. A Mix with Use Curve folds a
constant factor, or puts a new IR node `Smoothstep(input, lower, upper)` over its mask. `build/materials.py` draws
`Remap` as a Float Curve node (VECTOR points, no clipping) and `Smoothstep` as a Map Range (SMOOTHSTEP) or a
step (1 - LESS_THAN, 3ds Max gives 1 at lower itself); a Mix whose factor is a `Remap` does not clamp it.

**Tech Stack:** Python 3.11 syntax, Blender 4.2 / 4.5 / 5.2 shader nodes, 3ds Max 2020 for the fixture.

## Measured in 3ds Max 2020 (this session)

- Storage: a Falloff references a `Curve Control` `(0x14585773, 0x483A7DCF)`, superclass 0x100; its reference 0
  is the curve `(0x5F2D3A0A, 0x4BE75269)`, nameless in the class directory (the "point class" of FORMAT.md is
  this curve). The curve: `0x1000` u32 point count, then per point a `0x1030` container holding a `0x1000` leaf of
  28 bytes: point x, y, in handle x, y, out handle x, y (both absolute: point + offset), u32 flags (seen: 0x102
  first point, 0x100 last, 2 Bezier, 4 corner). Its `0x2035` head is the point count (2 default).
- Evaluation (`ICurve.GetValue`, matched to 1e-6): segment i is the cubic Bezier p_i, p_i + out_i, p_{i+1} +
  in_{i+1}, p_{i+1}, y solved at x. Flags 0, 1, 2, 3, 4, 8, 16 evaluate the same. A point's y outside 0..1 is
  evaluated at the nearest bound, its handle offsets kept (also after a reload); the curve between points is not
  clamped (1.195 overshoot).
- Falloff renders lerp(color 1, color 2, curve(ratio)) without clamping (Scanline: 152.8 for 1.195 x 128), for
  Perpendicular / Parallel, Towards / Away and Fresnel alike (within 8-bit rounding).
- Mix Use Curve (renderMap, amount and mask alike): x < lower -> 0, x >= upper -> 1, else smoothstep
  (u = (x - lower) / (upper - lower), 3u^2 - 2u^3); lower >= upper: a step at lower.
