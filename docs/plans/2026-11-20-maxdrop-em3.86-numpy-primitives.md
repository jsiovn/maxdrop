# Primitives built with numpy Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `convert/primitives.py` builds every primitive's mesh with numpy array operations instead of one Python call
per face corner, so a primitive at `MAX_CORNERS` (2^21 corners) builds in well under 1 s (measured before: 1.3 s to
3.4 s per class, the GeoSphere slowest) and the fuzz case `primitives.max:60125` replays in under 0.5 s.

**Architecture:** `_Builder` keeps its role (points, polygons, corner UVs -> `MeshData`) but takes blocks: `points()`
appends an (..., 3) array and returns its indices, `faces()` appends faces of one size as (F, n) vertex indices, (F,
n, 2) UVs and per-face material / group (scalars or arrays), with an optional per-face sort key where 3ds Max's face
order interleaves faces of different sizes (Pyramid, Cylinder, Cone). Each generator computes its lattice, corner
indices and UVs as arrays with the same float operations in the same order as before, so the output arrays are the
ones the per-corner code made: the same points in the same order (lazily made points of Box, Plane and GeoSphere
keep their first-use order through `numpy.unique(return_index=True)`), the same polygons, corners, groups, IDs and
UVs. Only `math.sin` / `cos` / `atan2` / `acos` on per-corner values become numpy's, which may differ by an ulp
before the float32 rounding.

**Tech Stack:** Python 3.11 syntax (runs under the test Python 3.9 too), numpy (1.26 here, Blender's 4.2 to 5.2
copies), no bpy.

### Task 2: `_Builder` on blocks

**Files:** Modify `maxdrop/convert/primitives.py` (`_Builder`, `build`).

- [ ] `points(xyz)` -> indices shaped like xyz without its last axis; `faces(verts, mat, group, uvs, order=None)`,
  `flip` reverses the block's corners and their UVs; `data(mapping)` concatenates, sorts by key (stable) when blocks
  carry keys, checks finiteness as before.
- [ ] `build()` runs the generator and `data()` under `numpy.errstate(all="ignore")`: overflowing sizes give inf/nan,
  refused by the existing finiteness check as before.

### Task 3: generators

- [ ] `_grid` -> corner lattice helper; Box and Plane points by first use; Pyramid (sort keys: per outline step the
  apex triangle then the quads, then the base fan); Sphere (three blocks); Cylinder / Cone (sort keys per side: the
  bottom center triangle, the ring quads, the top center triangle; `_seam` vectorized with the same subtractions);
  Tube; Torus; GeoSphere (lattice of each base face slerped as arrays, deduplicated on coordinates rounded to 1e-9
  as integers, points in first-use order, per-triangle seam and pole UVs as masks).
