# Primitives built with numpy Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `convert/primitives.py` builds every primitive's mesh with numpy array operations instead of one Python call
per face corner, so a primitive at `MAX_CORNERS` (2^21 corners) builds in well under 1 s (measured before: 1.3 s to
3.4 s per class, the GeoSphere slowest) and the fuzz case `primitives.max:60125` replays in under 0.5 s.

**Architecture:** `_Builder` keeps its role (points, polygons, corner UVs -> `MeshData`) but takes blocks: `points()`
appends an (..., 3) array and returns its indices, `faces()` appends faces of one size as (F, n) vertex indices, (F,
n, 2) UVs and per-face material / group (scalars or arrays), and `columns()` lays out faces column by column where 3ds
Max's face order mixes triangles and quads in each column (Pyramid, Cylinder, Cone). Each generator computes its
lattice, corner indices and UVs as arrays with the same float operations in the same order as before, so the output
arrays are the ones the per-corner code made: the same points in the same order (lazily made points of Box, Plane and
GeoSphere keep their first-use order through `_first_use`, one sort of key * count + position), the same polygons,
corners, groups, IDs and UVs. The `math.sin` / `cos` / `atan2` / `acos` on per-point values of the Torus and GeoSphere
become numpy's; measured bit-equal on Windows (numpy 1.24, 1.26, 2.3), and a vectorised libm elsewhere could differ in
the last bit before the float32 rounding.

**Tech Stack:** Python 3.11 syntax (runs under the test Python 3.9 too), numpy (1.26 here, Blender's 4.2 to 5.2
copies), no bpy.

### Task 2: `_Builder` on blocks

**Files:** Modify `maxdrop/convert/primitives.py` (`_Builder`, `build`).

- [ ] `points(xyz)` -> indices shaped like xyz without its last axis; `faces(verts, mat, group, uvs)` and
  `columns(*parts)`, `flip` reverses the block's corners and their UVs; `data(mapping)` concatenates and checks
  finiteness as before.
- [ ] `build()` runs the generator and `data()` under `numpy.errstate(all="ignore")`: overflowing sizes give inf/nan,
  refused by the existing finiteness check as before.

### Task 3: generators

- [ ] `_grid` -> corner lattice helper; Box and Plane points by first use; Pyramid (columns: per outline step the
  apex triangle then the quads, then the base fan); Sphere (three blocks); Cylinder / Cone (columns per side: the
  bottom center triangle, the ring quads, the top center triangle; `_seam` vectorized with the same subtractions);
  Tube; Torus; GeoSphere (lattice of each base face slerped as arrays, the points on base edges deduplicated on
  coordinates rounded to 1e-9 in Python as before, points in first-use order, per-triangle seam and pole UVs as
  masks).
