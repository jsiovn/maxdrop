# Splines Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Read shape objects (Line, Editable Spline, Rectangle, Circle, Ellipse, Arc, NGon) as Bezier splines and
build each shape node as a Blender curve object that keeps its transform and parent.

**Architecture:** `maxdrop/reader/shapes.py` (no bpy) reads the stored knots of SplineShape / Line and turns the
parameters of the parametric shapes into the same Bezier description (3ds Max's own construction, fitted to the
oracle). `convert/scene.py` gains the kind CURVE and `desc.curves` (keyed like meshes by base object and offset,
offset baked, meters applied, straight segments' handles put on the chord). `maxdrop/build/curves.py` makes the
Curve datablock (FREE handles, cyclic flag, resolution from the steps, bevel when renderable);
`build/objects.py` links it like a mesh. Oracle layout 4 adds each shape node's base object as 3ds Max's own
Bezier (knots, vectors, segment types, segment midpoints, interpolation and rendering settings).

**Tech Stack:** Python 3.11 syntax, standard library, unittest; 3ds Max 2020 via 3dsmax-mcp for the fixture and
the oracle; Blender 4.2 / 4.5 / 5.2 headless for the build.

## Facts found while planning (shapes fixture, a scratch probe, corpus scenes A and B)

- Classes, superclass `0x40`: SplineShape `(0xA, 0)`, Line `(0x1040, 0)`, Rectangle `(0x1065, 0)`, Circle
  `(0x1999, 0)`, Ellipse `(0x1097, 0)`, Arc `(0x1996, 0)`, NGon `(0x1050, 0)`.
- SplineShape: `0x1010` BezierShape container: one `0x1010` per spline {`0x2900` u32 knot count, `0x2904`
  u32, `0x290A` knots of 52 bytes (i32 knot type 0 smooth / 1 corner / 2 bezier / 3 bezier corner, i32 segment
  type 0 curve / 1 line, f32, 3 f32 point, 3 f32 in vector, 3 f32 out vector, u32; absolute object-space
  positions), `0x290D` u32 closed}; then `0x1050` i32 steps (-1 = adaptive), `0x1060` optimize. The object's own
  `0x1060` is the steps. Line wraps the same chunks in a `0x2000` container. Scene A (format 14000): the same
  layout on all 255 splines, 434 straight-line segments.
- References: slot 0 = the rendering ParamBlock (old, 28 entries: 0 thickness, 1 sides, 2 angle in degrees,
  6 Enable In Renderer, 8 Enable In Viewport, 11 rectangular, 12 width, 13 length). Parametric shapes: slot 1 =
  their parameters (old ParamBlock; Ellipse a ParamBlock2), slot 2 = old ParamBlock 0 steps, 1 optimize,
  2 adaptive. Rectangle 0 length, 1 width, 2 corner radius; Circle 0 radius; Ellipse (PB2) 0 length, 1 width,
  2 thickness, 3 outline; Arc 0 radius, 1 from, 2 to (degrees), 3 pie, 4 reverse; NGon 0 radius, 1 sides,
  2 circular, 3 corner radius, 4 scribe (0: the radius is the apothem).
- 3ds Max's Bezier for a circular arc of angle a: vector length = radius * veccalc(a), the SDK's bisection that
  makes the mean radius of 10 samples 1 (0.5517857 for 90 degrees). Arc: always 3 segments; first in and last
  out vectors at the knot; pie adds the center and closes; reverse runs the other way.
- A segment of type line is straight whatever its vectors (probe: interpCurve3D at 0.25 = the chord).
