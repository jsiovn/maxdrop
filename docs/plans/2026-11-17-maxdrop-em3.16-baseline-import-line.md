# baseline.py counts the operator's import line Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `tools/baseline.py` reads what the current operator prints (`MaxDrop: Imported <name>: ...`) instead of
the deleted io_scene_max engine's `\tImportError:` / `\tskipping ` lines, whose counts are now always 0.

**Architecture:** `read_log()` drops `NODE_ERROR`, `node_errors`, `nodes_failed`, `nodes_skipped`. It parses the
summary line `convert/report.py` `Report.summary()` builds (printed by `ops.py` with the `MaxDrop: ` prefix) into
`import_report`: objects, meshes, materials, placeholders, modifiers not applied, textures missing, approximated,
issues; `None` when no such line. The scene name in the line is never stored (the JSON names the scene only by
`--label`). `traceback` stays.

**Tech Stack:** Python 3.11 standard library, `unittest`.

Bead: maxdrop-em3.16 (CLAUDE.md half already done; remaining scope is `tools/baseline.py`).
