# VRayIES: the IES file header makes the power exact — Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** With the intensity override off, a VRayIES whose IES file is found gets the flux V-Ray renders:
power × (the file's integrated flux / its rated lumens), not the power alone.

**Architecture:** A new bpy-free parser `maxdrop/convert/ies.py` reads an LM-63 file with bounded reads and
integrates its candela table (type C) into lumens. `convert.lights.read_params` takes an optional `files` lookup
(a `convert.textures.TextureIndex`): for a VRayIES with the override off and power > 0 it finds the IES file by the
texture lookup's rules (no UNC, no links) and stores the parsed photometry (or why it cannot be read) in the values;
`_describe_ies` scales the lumens. `convert.scene.describe` / `read` pass `files` through; `ops._read_file` gives
the description a TextureIndex of its own (the materials' report counts only textures).

**Tech Stack:** Python 3.11 (plain), Blender 4.2 / 4.5 / 5.2 headless for the end-to-end check.

---

## Measured rule (docs/FORMAT.md, "VRayIES power, measured")

Override off: V-Ray scales the file's candelas by power / rated lumens. Rendered flux = power × flux / rated.
Rated -1: loading sets power = flux, so the power is the flux. So lumens = power × flux / rated when rated > 0,
else the power. Override on: the power is the flux (unchanged).

Unmeasured (decided from LM-63, written in FORMAT.md and the bead notes):
- the candela multiplier applies (LM-63: candelas × multiplier are the luminaire's); ballast factors are ignored
  (as Cycles' own IES reader does);
- rated lumens are per lamp: the total is lamps × lumens per lamp; a file with lamps ≠ 1 is a report line;
- any rated ≤ 0 is taken as -1 (absolute photometry);
- only photometric type C is integrated; type A / B is "cannot be read" (power as flux, reported);
- a missing file in V-Ray renders otherwise (1.689 at 1000 lm): not modeled (needs a V-Ray measurement).

## Parser (`maxdrop/convert/ies.py`)

- `read(path) -> Photometry` (namedtuple: rated, lamps, multiplier, flux, `scale` property); `parse(data)`;
  `IesError(ValueError)` with the reason.
- Bounds: file > MAX_BYTES (4 MiB) refused unread past the cap; MAX_ANGLES 4096 per axis; MAX_VALUES 1 << 20
  candelas; TILT=INCLUDE pairs ≤ MAX_ANGLES.
- Tokens after the `TILT=` line, whitespace or commas; a strict number regex (no `nan`, `inf`, `_`); counts
  integral; angles non-decreasing, vertical in [0, 180] with at least 2, horizontal span 0, 90, 180 or 360 (first
  0 or 90 as LM-63-2002 allows); candelas, multiplier finite and ≥ 0.
- Flux: per horizontal plane Σ (I_i + I_i+1)/2 · (cos θ_i − cos θ_i+1); over the planes the trapezoid in radians ×
  2π / span (one plane: 2π). Exact for an isotropic file (4π I).
