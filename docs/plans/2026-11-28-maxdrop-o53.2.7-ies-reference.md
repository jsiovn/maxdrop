# IES reference: an asymmetric profile and a web rotation in V-Ray 5.2 Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** three measured rules in docs/FORMAT.md "Standard and photometric lights" that maxdrop-o53.3.5 needs to
place a photometric web light's distribution: the azimuth convention, the order and sign of the web rotation
(block 3, parameters 1 to 3), and what the light's intensity in cd means against the file's candelas.

**Architecture:** a self-authored LM-63 type C file without symmetry, written by a scratch Python script from a
formula on a stated grid (outside the repo, `C:\maxdrop_fixtures\probe\o53_2_7\`), is rendered by 3dsmaxbatch on
the calibration floor through a Free Light (photometric web) and a VRayIES; five floor points per render (below the
light, 0.5 m toward its local +X, -X, +Y, -Y). A scratch fit script turns each pixel into the candela of the
direction it sees and checks it against the file under each candidate azimuth convention and rotation order. The
formula, the setup, the tables and the rules go into docs/FORMAT.md. No `maxdrop/` code, nothing else committed but
this plan and docs/FORMAT.md.

**Tech Stack:** MAXScript (3ds Max 2020, V-Ray 5.2, `3dsmaxbatch.exe`), plain Python (`maxdrop/convert/ies.py`
read only).
