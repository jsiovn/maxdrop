# Colored data maps on float inputs: the mean, as V-Ray Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a colored map on a float input (roughness, metallic, alpha, a Mix or layer mask, a bump height) gives the
mean of its channels, as V-Ray 5.2 renders it, instead of Blender's implicit color-to-float conversion.

**Architecture:** `MaterialBuilder.graph()` (build/materials.py) memoizes each IR node per space. When a FLOAT graph
comes out as a color socket (an Image's Color, or a ColorCorrect, Adjust, Tint, Blend or a blend-mode Composite,
which work in color whatever space is asked), one Vector Math DOT_PRODUCT by (1/3, 1/3, 1/3) is put after it before
it is memoized, so no color output is ever linked into a float input. One helper `_mean_of()` makes that node; the
color branch of `float_input` (times scale / 3), `rewire`'s mono and `weight()` use it.

**Tech Stack:** 3ds Max 2020 + V-Ray 5.2 (`3dsmaxbatch`, scratch MAXScript), Blender 4.2.23 / 4.5.16 / 5.2 headless,
plain Python `unittest`.

## Measurement (outside the repository: `C:\maxdrop_fixtures\probe\em3_42\`)

`probe.ms`: a 160 x 16 PNG of eight stripes R G B Y C M W K (0 / 255 per channel, so the gamma plays no part), on
three planes: a VRayLightMtl whose texmap is a Mix black -> white masked by the stripes; a VRayMtl whose reflection
glossiness map is the stripes (glossiness mode), read from the V-Ray frame buffer's VRayMtlReflectGlossiness channel
(`gloss.ms`: `vfbControl #setchannel` / `#saveimage`; `render()`'s `renderElementBitmaps:` returns none in batch);
a VRayMtl whose opacity map is the stripes (the render's alpha). `blender_render.py` imports `stripes.max` through
MaxDrop and draws what feeds the mask factor, Roughness and Alpha (through a Math ADD 0, the same implicit
conversion) as an emission; EEVEE and Cycles renders, the median per stripe.

| Stripe | R | G | B | Y | C | M | W | K |
|---|---|---|---|---|---|---|---|---|
| V-Ray: mask, glossiness, opacity | 0.333 | 0.333 | 0.333 | 0.667 | 0.667 | 0.667 | 1 | 0 |
| MaxDrop before (all three, 4.2 / 4.5 / 5.2, EEVEE and Cycles) | 0.213 | 0.715 | 0.072 | 0.928 | 0.787 | 0.285 | 1 | 0 |

V-Ray takes a data map as the mean of its channels; Blender converts a color to a float as the Rec.709 luminance
(0.2126, 0.7152, 0.0722). Off by up to 0.38: the fix is needed.

Not measured, follow the same rule: metallic (no V-Ray channel), a bump height (3ds Max's own mono value is the
mean), Corona materials (no Corona render in batch). The gamma of a data map is maxdrop-em3.122.
