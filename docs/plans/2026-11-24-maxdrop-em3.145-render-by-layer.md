# Rendering Control By Layer Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A node whose Object Properties > Rendering Control is By Layer renders, casts and receives shadows as its
own layer says; a layer's Renderable no longer hides the nodes that are By Object (bead maxdrop-em3.145).

**Architecture:** The reader reads the By Layer mask (node chunk `0x0A28`) and the layer's Cast / Receive Shadows
bits (`0x1050`); one reader helper merges node and layer bits; convert/scene.py resolves the node's three flags
through it; build/collections.py stops putting `hide_render` on a non-rendering layer's collection.

**Tech Stack:** plain Python reader/convert, Blender build, MAXScript fixture + oracle (3ds Max 2020 batch).

## Probe findings (3ds Max 2020, 3dsmaxbatch, own probe folder outside the repo)

Saves of one change each (A, A2 the same scene; tools/maxdiff.py):

| Save | Change | Difference |
|---|---|---|
| BL | `renderByLayer = true` | node `0x0A28` (8 bytes) second u32 `0` -> `0x3040C600` |
| DL | `displayByLayer = true` | `0x0A28` first u32 -> `0xF9F80000`, second `0x00030000` (not read) |
| ML | `motionByLayer = true` | `0x0A28` second u32 -> `0x00040800` (not read) |
| LC | layer `castShadows = false` | layer `0x1050` `0x0B00D600` -> `0x0B00D400` |
| LR | layer `receiveShadows = false` | layer `0x1050` -> `0x0B00D200` |
| LN | layer `renderable = false` | layer `0x1050` -> `0x0B005600` |
| BLNC | `renderByLayer = true` then `castShadows = false` | only `0x099C` `0x0F00D400`: setting a render flag turns By Layer off again |

So the second u32 of `0x0A28` is a mask over the `0x099C` render bits that come from the layer (it holds the three
read bits `0x8000`, `0x400`, `0x200`). MAXScript then reports the layer's values for the node (BLC: castShadows
false with `0x099C` unchanged), so the oracle's node flags are the effective ones.

Scanline renders (lit pixels of a box on a black background; a shadow area of a ground plane under an angled spot):

- By Object node on a non-rendering layer: rendered (324 lit, as in em3.97). By Layer: not rendered (0).
- By Layer node whose layer renders, below a non-rendering parent layer: rendered (324): only its own layer counts.
- By Layer node with its own Renderable off on a rendering layer: rendered.
- By Layer box on a layer with Cast Shadows off: no shadow; By Object box on that layer: shadow. By Layer box with
  its own Cast Shadows off on a casting layer: shadow. A parent layer with Cast Shadows off: shadow (not inherited).
- By Layer ground on a layer with Receive Shadows off: no shadow on it; By Object: shadow.

Fixtures: every node of every fixture has `0x0A28`, 8 bytes, mask 0 (saved_as 2017-2019 included). Corpus (counts
only): scene A has 23 By Layer nodes (mask `0xB044CE00` / `0xB047CE00`, all three bits, never partial), their own
bits and their layers' all on: no visible change; no By Object node sits on a non-rendering layer in either scene.
