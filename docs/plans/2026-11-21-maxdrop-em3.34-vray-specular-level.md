# VRayMtl Specular IOR Level against a V-Ray render Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** settle by a reference render whether a VRayMtl's reflection color reaches Blender's Specular IOR Level at
the right strength, and write the mapping down (docstring, test, plan, bead notes).

**Architecture:** bead `maxdrop-em3.34` comes from root cause 5 of the M2 A/B findings, read from
`convert/materials.py` alone: `specular = mean(linear reflection)` gives 1.0 for a white reflection. But
`build/materials.py` draws `Specular IOR Level = SPECULAR_LEVEL (0.5) x ir.specular` on both paths (the constant at
`float_input`'s default, a map through a Multiply or a dot product by 0.5 / 3), and did so already at the A/B commit
(27528f2). So a white reflection is 0.5, Blender's "the IOR's own Fresnel", which is what V-Ray renders for a white
reflection with Fresnel on. The render below checks that instead of assuming it. If it confirms, no formula
changes: the IR keeps "1 = the full Fresnel reflection at the IOR" and the docstring says where the 0.5 comes from.
If it does not, the factor changes in one place and the tests follow.

**Tech Stack:** 3ds Max 2020 + V-Ray 5.2 (`3dsmaxbatch`, a scratch MAXScript), Blender 5.2 headless (EEVEE and
Cycles) through `import_scene.maxdrop`, plain Python `unittest`.

## Result (measured 2026-11-21)

MaxDrop's sockets: S1, S2 and S4 Specular IOR Level 0.5, S3 0.251 (swatch 128 read as 0.502); S4 metallic 1, base
white. Mean reflectance per radius band (fraction of the sphere's radius in the image; Cycles 256 samples, EEVEE 64):

| Sphere | Band | V-Ray 5.2 | Cycles | EEVEE |
|---|---|---|---|---|
| S1 white, gloss 1.0 | 0 to 0.2 (normal) | 0.0533 | 0.0532 | 0.0532 |
| | 0.8 to 0.88 | 0.0862 | 0.0861 | 0.0749 |
| | 0.9 to 0.95 (toward grazing) | 0.1678 | 0.1677 | 0.1502 |
| S2 white, gloss 0.8 | 0 to 0.2 | 0.0543 | 0.0532 | 0.0527 |
| | 0.9 to 0.95 | 0.1415 | 0.1416 | 0.1432 |
| S3 grey 128, gloss 1.0 | 0 to 0.2 | 0.0267 | 0.0267 | 0.0267 |
| | 0.8 to 0.88 | 0.0415 | 0.0534 | 0.0488 |
| | 0.9 to 0.95 | 0.0789 | 0.1209 | 0.1233 |
| S4 control (metal) | 0 to 0.2 | 1.0000 | 0.9995 | 1.0000 |

(S1 and S4 also mirror their neighbors in V-Ray and Cycles; EEVEE does not trace them.)

Decision: the mapping stays. A white reflection is Specular IOR Level 0.5 and matches V-Ray at every angle in
Cycles and within EEVEE's approximation. A grey or colored reflection matches facing the camera, but Blender's
Specular IOR Level scales only the reflectance at normal incidence (the curve still rises to 1 at grazing), while
V-Ray multiplies the whole Fresnel curve by the color: about 50 % too bright near the rim for swatch 128. Principled
has no input for that (Specular Tint also tints only the normal-incidence reflectance), so it is debt bead
`maxdrop-em3.119`, not part of this one; docs/SUPPORT.md's VRayMtl row says so. Standard and Physical use the same weight and the same build factor; not rendered here (no V-Ray
shading of a Standard material to compare with).
