# VRayMtl Specular IOR Level against a V-Ray render Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** settle by a reference render whether a VRayMtl's reflection color reaches Blender's Specular IOR Level at
the right strength, and write the mapping down (docstring, test, plan, bead notes).

**Architecture:** bead `maxdrop-em3.34` comes from root cause 5 of the M2 A/B findings, read from
`convert/materials.py` alone: `specular = mean(linear reflection)` gives 1.0 for a white reflection. But
`build/materials.py` draws `Specular IOR Level = SPECULAR_LEVEL (0.5) x ir.specular` on both paths (the constant at
`float_input`'s default, a map through a Multiply or a dot product by 0.5 / 3), and did so already at the A/B commit
(27528f2). So a white reflection is 0.5, Blender's "the IOR's own Fresnel", which is what V-Ray renders for a white
reflection with Fresnel on. The render below checks that instead of assuming it. If it confirms, no formula
changes: the IR keeps "1 = the full Fresnel reflection at the IOR" and the docstring says where the 0.5 comes from.
If it does not, the factor changes in one place and the tests follow.

**Tech Stack:** 3ds Max 2020 + V-Ray 5.2 (`3dsmaxbatch`, a scratch MAXScript), Blender 5.2 headless (EEVEE and
Cycles) through `import_scene.maxdrop`, plain Python `unittest`.

## Measurement (outside the repository: `C:\maxdrop_fixtures\probe\em3_34\`)

Scene: four spheres (radius 20) in a row under a uniform white environment (Max background color white, V-Ray GI
off, default lights off, color mapping linear, gamma 1), black diffuse, no lights, a Free camera above. Every pixel
is then the reflectance at its viewing angle: the center is normal incidence, the rim grazing.

| Sphere | VRayMtl | Expected center (Fresnel at IOR 1.6: F0 = 0.0533) |
|---|---|---|
| S1 | reflection white, glossiness 1.0, IOR 1.6 | 0.053 |
| S2 | reflection white, glossiness 0.8, IOR 1.6 | about 0.05 |
| S3 | reflection grey 128, glossiness 1.0, IOR 1.6 | F0 x the linear grey |
| S4 | reflection white, Fresnel off (control: a metal in MaxDrop) | 1.0 everywhere |

- [ ] `render.ms` through `3dsmaxbatch`: save `spec.max`, render `vray.exr` (float).
- [ ] `blender_render.py`: import `spec.max` with MaxDrop, world white strength 1, view transform Standard, the
  imported camera; render `eevee.exr` and `cycles.exr` at the same size; print each material's Specular IOR Level.
- [ ] `measure.py` (run in Blender for EXR reading): per sphere (alpha mask) the mean at r < 0.2 R (normal) and at
  0.80 to 0.88 R (toward grazing), for the three images. The control S4 must read about 1.0 in all three.
