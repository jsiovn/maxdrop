# EEVEE Thickness 0 for Fresnel-off clear glass Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** clear (constant white base) Fresnel-off glass keeps about 1.0 of a white environment in EEVEE, as in
Cycles, by a Value 0 linked to the Material Output's Thickness; or, if Thickness 0 changes how a solid looks
through the glass too much, a won't-do with the numbers in the `build/materials.py` docstring.

**Architecture:** maxdrop-6n0.7.4 measured EEVEE's w + ((1 - w) c)^2 for Fresnel-off glass (0.84 at w 0.2 on white
glass) and Thickness linked to 0 giving 0.990-0.994 (EEVEE only: one refraction event; Cycles ignores the socket),
but too light on tinted glass. Thickness is material-wide, so `_Tree.build()` links it only when the material has a
refracting Fresnel-off mirror (`reflection_weight(mirror=True)` on a `refracting()` BSDF) and every transmitting
Principled of the material (every layer, its twins included) has an unlinked white Base Color: a tinted or mapped
glass anywhere keeps EEVEE's default. The node is a Value node labelled `THICKNESS_LABEL`.

**Tech Stack:** Blender 4.2 / 4.5 / 5.2 headless (Cycles, EEVEE), plain Python unittest.
