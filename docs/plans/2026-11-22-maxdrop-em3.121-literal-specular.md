# Literal 0.5 speculars: the IR default Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a CoronaPhysicalMtl, a Standard material with the Strauss shader and the grey fallback reflect the
IOR's own Fresnel (Blender's Specular IOR Level 0.5) instead of half of it (0.25).

**Architecture:** `MaterialIR.specular` is a reflection weight: 1 is the full Fresnel reflection at the IOR, which
`build/materials.py` draws as `SPECULAR_LEVEL (0.5) x ir.specular` (confirmed against V-Ray 5.2 in
`docs/plans/2026-11-21-maxdrop-em3.34-vray-specular-level.md`). Three places still hold a literal 0.5 meant as
Blender's socket value: the dataclass default (inherited by `corona_physical_mtl`, which never sets the specular,
and by `_grey`) and Strauss's `specular = 0.5`. The literal and `SPECULAR_LEVEL` arrived in the same commit
(20fe776, M2), so the literal was Blender's value written in IR units by mistake; the module docstring says so
("Specular stays 0.5 (Corona derives it from the IOR)"). The fix is 1.0 in IR units everywhere.

**Tech Stack:** plain Python `unittest`; Blender 4.2.23 / 4.5.16 / 5.2 headless (`tests/blender/run.py`).

---

## Decisions

- **IR default 1.0.** Rules relying on the default: only `corona_physical_mtl` and `_grey` (which also covers
  `corona_layered_mtl`'s grey returns and every unknown class). Every other rule in `RULES` sets `ir.specular`
  itself (VRayMtl, VRayLightMtl, VRayFastSSS2, both car paints, Standard, Physical, CoronaLegacyMtl,
  CoronaLightMtl, CoronaSkinMtl). A grey material then matches Blender's default Principled BSDF (0.5).
- **CoronaPhysicalMtl sets `ir.specular = Input(1.0)` explicitly**, so the rule no longer depends on the default.
  Its parameter list (docs/FORMAT.md, Corona 12) has no reflection or specular level: Corona derives the base
  reflection from the IOR alone (and the edge color for metals, already a named issue; iorMode 461 already an
  issue).
- **Strauss: 1.0.** The shader's parameters are diffuse, glossiness and metalness only (FORMAT.md): no specular
  level to read, so the reflection is the IOR's own Fresnel, as for Corona. A reflection-slot map still raises
  it through `max(specular, amount)`; 1.0 already is the clamp, so that has no effect any more on Strauss.
- **Left alone:** `_car_paint`'s `_num(m, 4, 0, 0.5)` is V-Ray's `base_reflection` parameter default, not this
  literal; VRayMtl's rule belongs to em3.118 / em3.119. The unknown-shader branch of Standard keeps 0.0 (its own
  decision, not a literal 0.5).
- **No oracle changes:** the `*.oracle.json` "specular" keys are 3ds Max parameter values (input), not import
  results.

## Unmeasured

No Corona render (no license here, em3.28 plan) and no scanline render of Strauss: the value is reasoned from the
IR convention em3.34 measured for V-Ray (1 = the IOR's Fresnel = Blender 0.5).
