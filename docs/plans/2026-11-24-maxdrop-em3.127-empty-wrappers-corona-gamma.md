# Empty wrappers in Corona and with the gamma on Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn maxdrop-em3.76's assumed cases (the gamma on, Corona) for an empty Output, RGB Tint and
VRayColor2Bump into measured ones, and draw what Corona renders where it differs: an Output whose map1Enabled is off
still renders its map in Corona.

**Architecture:** `convert/texmaps.py`: `TexmapConverter` takes the scene's renderer ClassID (`renderer=`, None:
unknown, today's rule); `_output_map` ignores map1Enabled when the renderer is Corona's. `reader/classids.py` gets
the renderer's ClassID; `ops.py` reads it from the summary stream (`metadata.read`, as the preflight does) and passes
it to both converters it builds. Docs: FORMAT.md 'Empty wrappers, measured', SUPPORT.md, CHANGELOG.md.

**Tech Stack:** Python 3.11 syntax, `unittest`; 3ds Max 2020 + V-Ray 5.2 + Corona 12 (`3dsmaxbatch`) for the
renders; Blender 4.2 / 4.5 / 5.2 headless for the smokes.

## Facts (renders 2026-11-24, scenes local in a folder of the bead's own, outside the repo)

3ds Max 2020, `3dsmaxbatch`. V-Ray 5.2 (linear color mapping, gamma 1, no GI, no default lights) and Corona 12
(tone mapping off, a pass and a time limit), each with the gamma off and on (the saved scenes read back as gamma off /
on through `convert.colors.of_scene`). Planes under an orthographic camera, black background, `getPixels ...
linear:true`, a 9 x 9 pixel mean. Color slot: VRayLightMtl / CoronaLightMtl texmap (color white). Data slot: the
opacity map of a self-illuminated white VRayMtl / CoronaLegacyMtl. "White map": a Checker of white; "red": a Checker
of (200, 50, 50).

| case | V-Ray off / on, color | V-Ray, opacity | Corona off / on, color | Corona, opacity (64 passes) |
|---|---|---|---|---|
| Output unset / switch off (red below) / over white | 1 / 1 / 1 | 1 | 1 / **0.784, 0.196, 0.196** / 1 | 1 / **0.392** / 1 |
| Output level 0.8, offset 0.1, amount 0.5: unset / off / white | 0.725 all | 0.450 all | 0.725 / **0.682, 0.564, 0.564** / 0.725 | 0.451 / **0.207** / 0.451 |
| RGB Tint identity: unset / off | 1 / 1 | 1 | 1 / 1 | 1 |
| RGB Tint (128,0,0 / 0,64,0 / 0,0,32): unset / off / white | 0.502, 0.251, 0.125 all | 0.293 | the same | 0.294 / 0.293 / 0.293 |
| VRayColor2Bump unset / over white | 0.5, 0.5, 1 / 1 | 0.667 / 1 | 0.5, 0.5, 1 / 1 | 0.668 / 1 |
| reference Checker (128, 128, 255) | 0.502, 0.502, 1 | 0.668 | the same | 0.669 |

- V-Ray: the gamma on gives the same pixels as the gamma off, every case, both slots: the em3.76 rule holds with the
  gamma on (no code change; the swatch rule already takes (0.5, 0.5, 1) as linear with the gamma on).
- Corona: the same as V-Ray for an unset Output or RGB Tint, an RGB Tint switched off, an unset VRayColor2Bump (Corona
  renders the V-Ray map). **An Output with map1Enabled off renders its map** (through its Output part:
  (0.784 x 0.8 + 0.1) x 0.5 seen at alpha 0.5 over the light's white gives 0.682); the file stores the switch off
  (read back in MAXScript, false). RGB Tint's switch is honored.
- Corona opacity: 4 passes left offsets up to 0.006 on every non-grey value, the reference Checker too; 64 passes
  bring them to the mean (sampling noise, not a rule).
- Measured with Corona's own materials (CoronaLightMtl, CoronaLegacyMtl); other materials under Corona assumed.
- Renderer ClassIDs (summary stream, `metadata.read`): Corona 12 (0x62A85DCC, 0x523C3604); V-Ray 5 update 2.1
  (0x73BAB286, 0x77F8FC0C).
