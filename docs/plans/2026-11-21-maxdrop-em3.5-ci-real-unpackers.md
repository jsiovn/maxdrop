# CI: run the UnRAR and 7-Zip real-tool tests Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Linux plain-test jobs install UnRAR 7.23 and 7-Zip 26.06 from their vendors (pinned by version and
SHA-256), and a switch `MAXDROP_REQUIRE_TOOLS` turns a missing real tool into a failure, so the real-tool tests of
`tests/test_intake_external.py` run on every CI run instead of printing SKIPPED.

**Architecture:** One workflow step on Linux downloads the two vendor tarballs over https, checks their SHA-256,
installs `7zz` and `unrar` into `/usr/local/bin` (a standard place of `external.candidates`), so the tests find
them through the real discovery (`find_tools`). The unit-test step sets `MAXDROP_REQUIRE_TOOLS=unrar,7z,bsdtar` on
Linux; the tests read it once and fail where a required program is missing. `maxdrop/intake/external.py` does not
change.

**Tech Stack:** GitHub Actions (bash), Python `unittest`.

Bead: maxdrop-em3.5

### Task 1: The switch in the tests

- [ ] `_required()` parses `MAXDROP_REQUIRE_TOOLS` (comma separated, spaces ignored, empty = none) into a set of
  flavor ids (`unrar`, `7z`, `bsdtar`); unknown names are kept so a test can name them.
- [ ] `RequiredToolTests.test_known_names` fails on an unknown name; `test_required_found` fails for each required
  flavor not in `REAL`, with `REAL_NOTES` in the message (a tool below its floor says so).
- [ ] `tools_for`: a missing required flavor -> `say(..., SKIPPED)` then `self.fail(...)`.
- [ ] `test_discovered_chain`: no program and something required -> fail.
- [ ] Unit test of `_required` on sample strings.

### Task 2: The workflow

- [ ] Step `UnRAR and 7-Zip` (if Linux), after bsdtar: `curl -fsSL --proto '=https'`, `sha256sum -c`, extract
  only `7zz` / `rar/unrar`, `sudo install -m 0755` into `/usr/local/bin`, print both banners.
- [ ] Unit test step: `MAXDROP_REQUIRE_TOOLS: ${{ runner.os == 'Linux' && 'unrar,7z,bsdtar' || '' }}`.
- [ ] Comments: drop "ubuntu-latest has no unrar ... those cases print SKIPPED".
