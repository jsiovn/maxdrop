# Narrow the per-object nets of the reader to MaxFileError Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every per-object net in `maxdrop/reader/` and `maxdrop/convert/` catches the reader's own errors
(`MaxFileError`, plus `OverflowError` / `ZeroDivisionError` / `MemoryError` where arithmetic or allocation on file
values needs it), so that an `IndexError`, `struct.error`, `TypeError`, `KeyError` or stray `ValueError` from a
reader defect surfaces in the fuzz campaign instead of becoming an issue line.

**Architecture:** Each except clause gets one written disposition (narrow, range check, keep with a reason). Gaps a
narrowed net used to cover become checked conditions at their source: math on non-finite file values gives a
non-finite matrix, which the existing `_finite()` check already turns into the `NON_FINITE` issue. New unit tests
prove (a) a mocked defect exception now propagates through each narrowed net, (b) the newly checked inputs still end
as issues. A deterministic fuzz pilot (3,000 cases per seed) before and after the change must give the same per-seed
ok/refused counts; then the full 100,000-case campaign.

**Tech Stack:** Python 3.11 syntax, plain `unittest`, `tests/unit/fuzz.py`, Blender 4.2 / 4.5 / 5.2 headless.

## Gaps the narrowed controller nets used to cover (fixed at the source)

`math.cos` / `math.sin` raise `ValueError` ("math domain error") on an infinite argument. A file's float can be
`inf`: an Euler angle (`_axis` via `euler_matrix`), a Look At roll (`look_frame`), a list weight
(`_weighted_quat`, `h = atan2(...) * weight`). Fix: a helper `_cos_sin(angle)` returning `(nan, nan)` for a
non-finite angle; `_weighted_quat` returns a NaN matrix when `h` is not finite (a NaN quaternion would read as the
zero quaternion, i.e. identity). The node's matrix is then non-finite and `_evaluate` / `matrix()` report the existing
`NON_FINITE` issue with identity: the same outcome as today (identity + an issue), clearer text.
