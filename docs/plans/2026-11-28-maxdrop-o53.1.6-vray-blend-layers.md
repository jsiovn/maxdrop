# VRayBlendMtl as layers Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** A VRayBlendMtl with a base and at least one coat that is set and on converts to its base's IR with each
coat as a Layer ("mix", or "add" in additive mode), drawn as one Principled BSDF per layer joined by a Mix Shader or
an Add Shader; bead maxdrop-o53.1.6. Folded in: maxdrop-o53.1.11 (landing pages: Checker and Noise drawn as nodes).

**Architecture:** `convert/materials/layered.py` gets one shared loop (`_layered`: base, Multi/Sub-Object issue,
`MAX_LAYERS`, `MAX_LAYER_BSDFS`, a layer that is no material, a layer's medium) used by `corona_layered_mtl` and the
new `vray_blend_mtl`, each giving its own per-layer weight. `MaterialConverter.blend_coats(m)` (beside
`corona_layers`) lists the coats that are set and on; `_mixes_layers` uses it so the peel and the rule agree.
`Layer` gets `mode` ("mix" / "add", last field). `build/materials/tree._Tree.layered` draws "add" as an Add Shader
over the coat scaled by its weight (a Mix Shader from nothing, labelled), "mix" as today.

**Tech Stack:** Python 3.11 (plain unittest), Blender 4.2 / 4.5 / 5.2 headless checks.

---

## Decisions

- Weight graph kind: MASK, not DATA (the bead's "DATA graph" predates `_swatch`: DATA keeps the stored mean, only
  MASK applies the scene's swatch rule, which the bead's weight rule and Verify name; Corona's layer mask is MASK
  too, "it mixes two shaded colors").
- Weight of coat k: no map: `swatches.channel(mean(clamped blend color))` as the Layer's amount. With a map:
  `texmaps.convert(MapRef(map, multiplier / 100), MASK, weight)` (`_slot`: `Mix(Constant(w), map, mult)` below 100 %,
  the map alone at 100 %, `Multiply` above), amount 1. No graph back (no TexmapConverter, an unusable map): the
  amount falls back to the swatch weight.
- A colored blend color (channels apart by more than half a step) where it is used is an issue line: V-Ray blends
  per channel, MaxDrop by the mean.
- Animated blend values: em3.152 is closed, they read at frame 0 like every parameter (no special case).
- The weights are "not measured" (code comment, docs/FORMAT.md, docs/SUPPORT.md) until maxdrop-o53.3.2.
