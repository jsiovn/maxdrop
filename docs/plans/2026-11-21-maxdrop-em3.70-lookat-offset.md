# LookAt Constraint Offsets Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A LookAt Constraint with Keep Initial Offset (`relative`) or a Set Orientation rotation gets the world
matrix 3ds Max computes, instead of the plain aimed frame and the issue "offset not applied".

**Architecture:** `reader/controllers.py` `_Eval._constraint` reads the constraint's own quaternion chunks and
composes them with the aimed frame (`constraint_frame`) before `_constrained` adds scale and position. No change
outside the reader but docs, the fixture and tests.

**Tech Stack:** Python 3.11 syntax, no bpy; 3ds Max 2020 through 3dsmax-mcp (own instance) for probes and the
oracle; Blender 4.2 / 4.5 / 5.2 headless for the fixture tests.

---

## What 3ds Max 2020 stores and computes (probed on scratch files outside the repo)

Probes: 24 boxes over three scenes, each evaluated in two states (as assigned, then targets moved and parents
turned), `node.transform` read in MAXScript and compared with the reader (all within 1e-5).

The constraint's chunks (each a Max quaternion `x, y, z, w`, as `quat_matrix` reads it):

| Chunk | Content |
|---|---|
| `0x1001` | the node's world rotation when the constraint was assigned (not used) |
| `0x1002` | the node's local rotation (relative to the parent) when the constraint was assigned |
| `0x1003` | the aimed frame when the constraint was first evaluated |
| `0x1004` | the Set Orientation rotation (identity until the node is turned with Set Orientation on) |
| `0x1005` | `u32`: the target count in every probe (not read) |

They are stored values: turning the parent or moving a target and saving again leaves them unchanged.

With `L` the aimed frame (rows, `constraint_frame`) and `Qn` the matrix of chunk `0x100n`, in the row-vector
convention (A * B applies A first):

- `relative` on: `R = Q2 * Q3^-1 * L` (the Set Orientation rotation is not applied, also when it is not identity
  and Set Orientation is on).
- `relative` off: `R = L * Q4`, whether Set Orientation is on or not (a rotation set with it on stays after it is
  turned off).

World = own scale * the parent's row lengths * R * translation(P), as before.

## Tasks

### Task 1: reader
- [x] `controllers.py`: `_LC_INITIAL_LOCAL = 0x1002`, `_LC_INITIAL_FRAME = 0x1003`, `_LC_USER = 0x1004`;
  `_constraint` composes as above. An issue (`CONSTRAINT_OFFSET`, reworded "not stored") when a chunk the
  composition needs is missing or shorter than 16 bytes: 0x1002/0x1003 with relative on, 0x1004 with Set
  Orientation on (0x1004 missing with it off: identity, silently). A non-finite quaternion ends as `NON_FINITE`.
  Module docstring updated.

## Outcome

- 24 probe boxes and lookat's 22 nodes within 1e-4 of 3ds Max (world and object transforms); without the reader
  change exactly the four new nodes (FixtureKeepOffset, FixtureSetOrientation, FixtureBothOffsets,
  FixtureOrientationOff) miss the oracle.
- `0x1003` is taken at the constraint's first evaluation, not at assignment: a box whose constraint is not
  evaluated before its target moves keeps no offset from that move (a probe; the fixture reads
  `keep.transform` before moving the target so the composition is tested). The new aim is a Dummy, so lookat's
  placeholder count (the Point) stays 1.
