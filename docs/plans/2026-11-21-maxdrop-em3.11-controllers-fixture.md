# Fixture for the transform controllers only the corpus or the SDK show Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A committed fixture, `controllers`, shows the transform controllers `maxdrop/reader/controllers.py` took
from the corpus or the 3ds Max SDK, and the reader matches its 3ds Max oracle on every node with no issue.

**Architecture:** `tools/fixtures/controllers.ms` saves 24 nodes (Point helpers and a Target camera) with Euler
orders, a scale axis, ScaleXYZ, Linear / TCB / Bezier Position, Rotation and Scale (static and keyed), lists with
50 % weights and an animated entry, Linear / TCB Float and a Float List under Position XYZ, a Bezier Float with
three keys, all saved with the time slider at frame 30. The probe shows the reader is wrong on 14 of them; the
fixes are in `controllers.py`: the saved value is a cache with a validity interval, key layouts per class, list
weights read through `pblock.ParamBlock2`, the Euler order stored as 100 + order, the float controllers.

**Tech Stack:** MAXScript (3ds Max 2020, `3dsmaxbatch.exe` with a wrapper that hides the ViewCube, the grid and
the gradient background before the save), plain Python `unittest`, Blender 4.2.23 / 4.5.16 / 5.2 headless.

Bead: maxdrop-em3.11

## Facts measured (probes and the fixture's first saves, outside the repo)

- A keyframe controller's value chunk (`0x2501` float, `0x2503` point, `0x2504` quaternion, `0x2505` scale) is
  the value at the time slider when saved; beside it `0x2500` = 2 x `i32`, the interval it holds for: `(-2^31,
  2^31-1)` (forever) without keys, `(4800, 4800)` (frame 30) with keys saved at frame 30, `(0, 0)` in the
  corpus files saved at frame 0. FixtureLinearKeyed: `0x2503` = (-48, 64, 13), 60 % between its keys; the oracle
  at frame 0 = the frame-0 key. `0x3003` = first and last key time; `0x3002` 0 (Linear) or 4 (TCB, Bezier).
- Corpus: every keyed controller of a transform has an interval holding 0 (scene A 259, scene B 326 + 450
  forever); the four whose key differs from the saved value: three Bezier Scales `(0, 0)` (saved used, as the
  oracle) and one Bezier Float with the empty interval `(-2^31, -2^31)` under a Noise modifier, not a transform.
  No keyframe controller lacks `0x2500`; every Euler order is 0.
- Key records, the value at byte 8 (after `i32` time, `u32` flags) in each: Linear Float `0x2511` 12 bytes,
  Linear Position `0x2513` 20, Linear Rotation `0x2514` 24 (quaternion), Linear Scale `0x2515` 36 (7 floats), TCB
  Float `0x2520` 40, TCB Position `0x2521` 64, TCB Rotation `0x2522` 92 (the absolute quaternion at byte 8, an
  angle-axis relative to the previous key later), TCB Scale `0x2523` 112, Bezier Float `0x2525` 28, Bezier Position
  `0x2526` 80, Bezier (Smooth) Rotation `0x2527` 88, Bezier Scale `0x2528` 148.
- Linear between keys (FixtureLinearBetween, keys at -10 and 40): position and scale linear (scale rows 1.1, 1.0,
  1.4); TCB keys at 10 and 50 (FixtureTCBBefore): frame 0 takes the first key.
- Class ids: Linear Float `(0x2001, 0)`, TCB Float `(0x442311, 0)`, Float List `(0x4B4B1000, 0)` (as the other
  lists), Bezier_Rotation = Smooth Rotation `(0x2009, 0)`; the SDK ids of controllers.py confirmed. Linear and TCB
  Float hold `0x2501` directly (no `0x7127`).
- Lists: weights are the list block's float table, param 0, stored as values (0.5, 0.5; Float List 0.5, 1.0), not
  controllers. Combination as the reader has it: Position / Float List weighted sum (25, 30, 15; 22), Scale List
  the product of `I + (S - I) * w` (1.5, 2, 0.75), Rotation List each entry's rotation scaled by its weight, a
  later entry applied first (Z 40 deg then X 15 deg).
- Euler `0x1003`: 0 for XYZ (also after switching back to it), 101..105 for XZY, YZX, YXZ, ZXY, ZYX, 106..108 for
  XYX, YZY, ZXZ.
- `3dsmaxbatch.exe` exits 127 on success: read the result file the wrapper writes. A batch save with the default
  viewport puts a thumbnail whose pixel bytes match check_fixture's network-path pattern: the wrapper turns the
  ViewCube, grid and gradient off in a `#filePreSave` callback.
