# The plain suite once without numpy: implementation plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a CI step that runs the plain suite once on a Python without numpy and expects `OK` with skips, so a
test that reaches numpy without its skip (as `GzipSeedTest.test_it_reads_like_its_fixture` did before
`maxdrop-em3.96`) fails the PR instead of the next local run without numpy (bead `maxdrop-em3.154`).

**Architecture:** every plain job of `.github/workflows/test.yml` pip-installs numpy before the suite, so the
skips are never taken in CI. The new step runs in one matrix entry (Linux, Python 3.11 / numpy 1.24.3, the entry
without the Ruff step) **before** the `numpy` step, on the bare `actions/setup-python` interpreter: numpy is
really absent, child processes (the fuzz slices run cases in a child each) see the same interpreter. A
`sys.modules` block in a wrapper was rejected: the children would not inherit it, and `-I` ignores
`PYTHONPATH`, so no shadow package either. A test under `tests/` that re-runs discovery was rejected too: it
would discover itself and double the local suite (about 105 s). The step's first command fails when numpy is
importable, so a runner image that one day ships numpy cannot turn the check into a second run with numpy.

**Tech Stack:** GitHub Actions (bash), `python -I -m unittest`.

### Task 1: the step

**Files:** Modify: `.github/workflows/test.yml` (the plain job: header comment, matrix comment, a new step
right before `numpy`).

- [ ] Header comment: name the run without numpy in the list of what the plain job runs.
- [ ] Matrix comment ("without numpy their tests skip"): say one entry checks those skips (the step's name).
- [ ] New step before `- name: numpy`:

```yaml
      # Once, before numpy is installed (the order is the point): the suite on the bare interpreter, so a test
      # that reaches numpy without its skip fails here instead of on a contributor's Python without numpy. The
      # interpreter itself, not a block in a wrapper: the fuzz slices run their cases in child processes. The
      # first command refuses an interpreter that already has numpy: the run would prove nothing.
      - name: The plain suite without numpy (once)
        if: runner.os == 'Linux' && !startsWith(matrix.numpy, '2.')
        run: |
          set -euo pipefail
          python -I -c 'import importlib.util as u, sys; sys.exit("numpy is importable" if u.find_spec("numpy") else 0)'
          python -I -m unittest discover tests
```

- [ ] No CHANGELOG line: the changelog lists what users get; CI-only changes (the macOS entry of part D) have
  none.
- [ ] Commit: `Run the plain suite once without numpy in CI`.
