# Empty Output / RGB Tint / VRayColor2Bump as an issue Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** an Output, RGB Tint or VRayColor2Bump whose own map is unset (or switched off) is named in the import
report instead of leaving the input its own value without a trace.

**Architecture:** the three `_PEEL` rules in `maxdrop/convert/texmaps.py` check `conv._on(...)` first; without a
used map they raise one issue on the wrapper (`"<Class> 'name': no map (or its map off), not drawn"`) and return
None. Counters (`peeled`, `unsupported`) and `approximated` stay untouched. What 3ds Max draws there is not
measured (the bead's batch epic needs no 3ds Max session), so no Constant is invented. `tex.stats.issues` already
reaches the report (`convert/report.py` `add_materials`, also when `convert()` returns None).

**Tech Stack:** plain Python 3.11, unittest.

---

### Task 1: tests first (red)

**Files:** `tests/unit/test_texmaps.py` (class `LostMaps`)

- [ ] `test_empty_wrappers_are_named`: per class (Output pids 0/1, RGB Tint 3/4, VRayColor2Bump 0/no switch):
  map unset (`Ref(None)`) and map off (`Ref(2)`, switch 0, a real `_bitmap(2)` below; not for VRayColor2Bump,
  which has no switch): `convert` is None, `peeled` and `unsupported` empty, exactly one issue, starting with
  `"<Class> 'name'"` and holding "no map".
- [ ] dedup: the same empty wrapper converted as COLOR then DATA gives one entry in `stats.issues`.
- [ ] no double report: `test_peeled_wrappers_give_nothing` asserts `len(tex.stats.issues) == 1` (a set map that
  is lost gives the lost issue only).
- [ ] nested: Mix 0.5 with an empty Output on side 1 and a bitmap on side 2 gives the bitmap, approximated, with
  the Output's issue and the Mix's lost issue; Mix amount 1.0 with the empty Output on the hidden side stays an
  exact Mix (not approximated).
- [ ] run `python -I -m unittest tests.unit.test_texmaps` -> the new cases fail.

### Task 2: implementation

**Files:** `maxdrop/convert/texmaps.py`

- [ ] helper `_wrapped(conv, m, map_pid, on_pid, kind, walk, depth, chain)`: `conv._on(...) is None` -> issue
  `"%s %r: no map (or its map off), not drawn" % (class name, m.name)`, None; else `conv._sub(...)`.
- [ ] `_output_map`, `_rgb_tint`, `_color2bump` use it.
- [ ] module docstring: the "Peeled to" and "converts to nothing" bullets say an empty or switched-off one gives
