# Real-World flag: a damaged 0x2150 is off, in one place — Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A damaged 0x2150 under an object or a modifier turns only the Real-World Map Size flag off; a standard
primitive no longer becomes a placeholder for it (bead maxdrop-em3.78).

**Architecture:** The guard moves into `reader/realworld.flag()`: it catches `chunks.ChunkError` from the walk of
the chunk tree (children scans) and returns False. The try blocks in `convert/extrude.py` and `convert/uvwmap.py`
`read_params` go, with their dead `struct.error` (every `Chunk.unpack` is length-checked and raises ChunkError) and
the then-unused `import struct`. `convert/primitives.read_params` needs no change. `scene.chunk(i)` stays outside
the guard: the reader's scene pre-parses object chunks and raises only IndexError on a bad index.

**Tech Stack:** plain Python 3.11, unittest.
