# CI: numpy in the plain Python job Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The plain Python CI job runs the numpy tests (`test_chunks` TestArrays, `test_geometry`,
`test_convert_scene`, `test_convert_materials`, `test_report`) instead of skipping them for "numpy missing", on the
oldest and the newest numpy a supported Blender ships.

**Architecture:** `.github/workflows/test.yml`, job `python`: a second matrix axis `numpy` with the versions
Blender bundles at both ends of the range (4.2.23: 1.24.3, 5.2: 2.3.4; 4.5.16's 1.26.4 lies between), a step that
pip-installs the pinned numpy and fails unless `python -I` imports exactly that version, then the unit tests as
before. Ruff runs once per OS (on the 2.x entry only). The tests stay numpy-optional; their `except ImportError`
comment ("the plain CI job has no numpy") is updated. The `Plain Python` gate job needs no change
(`needs.python.result` covers every matrix entry).

**Tech Stack:** GitHub Actions YAML, pip, Python 3.11.

Bead: maxdrop-em3.9
