# Curve material slots Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A shape node built as a Blender curve gets its 3ds Max material in a material slot, as a mesh does.

**Architecture:** `convert.materials.assign` returns a `Slots` dict (mesh key -> MeshSlots, unchanged for callers)
that also carries `curves` {curve key: MeshSlots}: one slot keyed by the material each user gets for material ID 1
(`material_for(mat, 0)`, so a Multi/Sub-Object resolves by ID, wraps, and an off / empty entry gives none), no
entry when no user has a material. Curve keys and mesh keys are both `(base, offset)` tuples, so they live in
separate dicts. `build.objects` appends the slot to the Curve (one material for every user) or links it per object
(users with different materials), with the same code as meshes; `steps_of` counts curve plans too.

**Tech Stack:** Python 3.11 (plain for convert, Blender 4.2 / 4.5 / 5.2 for build), 3ds Max 2020 for the fixture.
