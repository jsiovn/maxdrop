# A reflection weight that scales the whole Fresnel curve Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a grey or colored reflection (the IR's specular weight between 0 and 1, or a map) reflects
weight x F(theta) at every angle, as V-Ray renders it, instead of a Specular IOR Level that scales only the
head-on reflection while the curve still rises to 1 at grazing.

**Architecture:** `build/materials.py` draws such a weight as a Mix Shader (label `Reflection weight`) between a
specular-free twin of the filled Principled BSDF (label `Without reflection`, Specular IOR Level 0, every other
input copied: the same links, the same values) and the Principled itself at Specular IOR Level 0.5 (the IOR's full
Fresnel); the factor is the weight (a constant, or the map's mean: 1/3 per channel). Result:
w x (F x spec + (1 - F) x diffuse) + (1 - w) x diffuse = w F spec + (1 - w F) diffuse, V-Ray's split. The lone
Principled stays where the twin changes nothing: a constant weight of 0 or at least 1 (Specular IOR Level
0.5 x w as before), a constant Metallic of 1 (a metal ignores Specular IOR Level) and a constant Transmission
Weight of 1 (measured: Specular IOR Level 0 does not remove the reflection of a transmissive Principled in Cycles).
Every class follows (VRayMtl, Standard, Physical, CoronaLegacyMtl, CoronaPhysicalMtl's level is 1): the rule
lives in build/, on the IR's weight. Layers: each layer's BSDF gets its own twin; `fill` / `layered` hand back
the top shader socket.

**Tech Stack:** Blender 4.2 / 4.5 / 5.2 headless (EEVEE, Cycles), plain Python unittest.

### Task 1: the twin in build/materials.py

**Files:** Modify `maxdrop/build/materials.py` (module docstring Inputs paragraph, `float_input`, `fill`,
`layered`, `build`; new `float_value`, `specular`, `reflection_weight`, labels `TWIN_LABEL`, `WEIGHT_LABEL`).

- [ ] `float_value(inp, graph, scale)`: the body of `float_input` without the socket (node output or constant);
  `float_input` = bsdf_input + float_value + feed.
- [ ] `specular(ir)` (called after Metallic and Transmission Weight are filled): lone path (`float_input` x 0.5)
  when Metallic or Transmission Weight is an unlinked constant >= 1; else the weight from `float_value` (scale 1);
  a constant <= 0 or >= 1 sets 0.5 x w and returns None; otherwise Specular IOR Level 0.5, returns the weight.
- [ ] `reflection_weight(bsdf, weight)` at the end of `fill`: the twin (copy links / values, distribution,
  subsurface method; Specular IOR Level 0), the Mix Shader (factor: the weight; 1: twin, 2: bsdf); returns its
  output. `fill` returns (shader socket, alpha info); `layered` returns the top socket always; `build` links it.
