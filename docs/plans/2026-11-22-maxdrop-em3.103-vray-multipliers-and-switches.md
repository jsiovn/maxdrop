# V-Ray map multipliers and sub-material switches Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The VRayFastSSS2 and car-paint rules take each map slot's multiplier as its amount and FastSSS2's
specular_amount scales its specular; the wrapper peel skips a VRayOverrideMtl or Double Sided sub-material whose
switch is off.

**Architecture:** `MaterialConverter.map_ref` already reads a percent multiplier; the two rules pass the
multiplier ids (docs/FORMAT.md, fixture vray_more) and `map_ref` gains a `default` for a missing multiplier
(FastSSS2's bump: 30). The peel's `WRAPPER_SWITCHES` (today only CoronaRaySwitchMtl) gains the two classes: a
switched-off slot is an empty slot, so the peel goes on to the next sub-material in getSubMtl order, as it does for
an empty one.

**Tech Stack:** Python 3.11, plain unittest (no Blender for the rules; Blender smoke runs for the build).

---

## Decision: what a switch that is off means

- Double Sided: 3ds Max's help: "Use the checkboxes to turn the materials on or off"; MAXScript `map1Enabled`
  "Turn on/off display of the facing material" (default true). A material that is off is not there: the same as an
  empty slot.
- VRayOverrideMtl: V-Ray's page (documentation.chaos.com, VRayOverrideMtl) says what each slot is for ("Base
  material – The material V-Ray uses while rendering the object"; GI, reflect, refract, shadow: the ray types) and
  shows a scene where "only the Base material is active", but not what renders when the base is off.
- Rule: a switched-off slot is read as empty, as CoronaRaySwitchMtl's switches already are; the peel takes the
  next set sub-material that is on (an empty base already falls through to the GI material today). Unmeasured: what
  V-Ray and 3ds Max render with the base / facing material off (no render in this lane): written into the bead.
