# V-Ray material classes only a probe covered: fixture vray_more Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A committed fixture, `vray_more`, holds one box per material class that `convert/materials.py` had rules
for from an SDK probe only (VRayLightMtl, VRayFastSSS2, VRayCarPaintMtl, VRayCarPaintMtl2, VRayOverrideMtl,
VRayMtlWrapper, DoubleSided, Shellac); their ClassIDs move into `reader/classids.py` and the rules are checked
against the file.

**Architecture:** `tools/fixtures/vray_more.ms` saves eight Editable Poly boxes, each with one of the classes, every
parameter a rule reads set to a distinct value, maps (Checker, Noise: no file paths) in the map slots, one map slot
switched off per class that has a switch. The wrappers hold distinct VRayMtls in every sub-material slot. The
generic raw-parameter parity (`test_materials.py`) checks the reader against the oracle; a new
`test_convert_materials.py` class checks each IR against values computed by hand from the script and each wrapper's
peel. The two owner-slot entries of `reader/owner_slots.py` for VRayOverrideMtl and VRayLightMtl become fixture
facts (their `0x0013` tables).

**Tech Stack:** MAXScript (3ds Max 2020 + V-Ray 5.2, `3dsmaxbatch.exe` with the ViewCube / solid-background
wrapper), plain Python `unittest`, Blender 4.2 / 4.5 / 5.2 headless.

Bead: maxdrop-em3.21

## Facts measured (3ds Max 2020 + V-Ray 5.2, probe outside the repo)

- Every class exists in the local V-Ray 5.2, VRayCarPaintMtl2 included. DoubleSided's MAXScript class is
  `DoubleSided`. ClassIDs and block-0 ids as in `docs/plans/2026-11-16-maxdrop-arp.3-vray-material-rules.md`;
  the probe adds: VRayFastSSS2 `scatter_radius` (0) is type 0 (a plain float, not `TYPE_WORLD`), default 1.0;
  `scale` (22) default 1.0; VRayCarPaintMtl `coat_strength` (31) type 0, default 0.05; VRayOverrideMtl has
  `baseMtl_on` / `giMtl_on` / ... (1, 3, 5, 7, 9), default on; Shellac 2 `shellacColorBlend` (type 6, percent).
- V-Ray's documentation (documentation.chaos.com, VMAX space): VRayFastSSS2 "the Scatter radius value is always
  specified in centimeters (cm) regardless of 3ds Max' current working unit" and "is multiplied by the Scale to
  calculate the effective depth of scattering": the rule (radius = scatter_radius * scale / 100 m) stands.
  VRayCarPaintMtl coat strength: "the strength ... of the coat reflections when the surface is viewed directly from
  the front": the coat's normal-incidence reflectance; the rule (full coat, IOR from f0) stands. VRayCarPaintMtl2
  coat amount: "0 does not add a coat layer, while higher values blend the coat gradually": a weight, as the rule.
- Not in this bead (debt): the light, SSS and car-paint rules take every map at amount 1; their classes have
  `*_multiplier` parameters (percent) that VRayMtl's rule uses as the amount.
