# Oracle: map channel 1 corners of extruded meshes Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The oracle gives every corner of map channel 1 (object-space position, face normal, map vertex) of a node
whose stack has an Extrude, and `tests/unit/test_extrude.py` compares the extrude fixture's mapped nodes with it
corner by corner, so a U running the wrong way along a spline fails a test (bead maxdrop-em3.100).

**Architecture:** `eval_mesh.map_channel_1` gains `corners`: `null` unless a modifier of the node is an Extrude,
else one `[x, y, z, nx, ny, nz, u, v, w]` per corner of every triangle of the evaluated mesh in face order, in
object space (the vertices of `snapshotAsMesh` taken back by the inverse object transform, as `material_ids` does;
the normalized winding normal, `[0, 0, 0]` for a degenerate triangle). Only Extrude nodes: any modifier would bloat
every oracle (a TurboSmooth of 64,512 triangles) and slow corpus dumps. Layout 11; every oracle regenerated.

**Tech Stack:** MAXScript in 3ds Max 2020 (`3dsmaxbatch.exe`, its exit code is meaningless: the result is read
from a file the script writes); plain Python + numpy.
