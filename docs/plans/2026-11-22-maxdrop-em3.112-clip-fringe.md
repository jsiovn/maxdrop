# Clipped axis beside a repeating one: no fringe Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Bitmap that repeats (tile or mirror) on one axis and clips on the other, or a placed crop on a
repeating axis, shows no dark half-texel line at its tile and mirror lines (bead maxdrop-em3.112).

**Architecture:** `maxdrop/build/materials.py` only. Where an axis repeats and something must still clip (a clipped
axis, or a placed crop), the Image Texture uses the EXTEND extension and the clipping is a mask: per clipped axis a
Math COMPARE (|x - 0.5| <= 0.5) of the image coordinate fed to the node, multiplied (labelled "Clip") into the
node's Color and Alpha before anything else reads them. The CLIP extension stays only where nothing repeats.

**Tech Stack:** Blender shader nodes (4.2 to 5.2), tests/blender/run.py, a scratch render probe (EEVEE, Cycles).

---

## Rendered before the change (Blender 5.2, 2026-11-22)

Probe (scratch, not committed): a 2 x 2 plane, orthographic camera over it, 512 x 512, film filter 0.01, Standard
view, emission of the Image Texture's output, EXR read back. A uniform white 64 px image (any value below 1 inside
the image is a fade toward black) and an edge image (red first column, blue last, green between: half a texel
either side of a seam must be one pure edge colour).

| case | EEVEE | Cycles |
|---|---|---|
| tile U (tiling 2), clip V | 4 px dark per tile line, edge colour 0.39 | the same, 0.34 |
| mirror U, clip V | 4 px dark per mirror line, 0.39 | 0.35 |
| tile V, clip U | the same along V | the same |
| crop at the image edge (u 0, w 0.5), tile or mirror U, clip V | 0.32 at the crop's image edge | 0.29 |
| crop u 0, w 1, tile U, clip V | as without a crop | as without |
| placed, w 1, tile U (clip V or tile V) | as without a crop | as without |
| reference: tile both (REPEAT) | no dark px | no dark px |

The fringe is there in both engines. The first probe measured r + g + b of the edge image, which Cycles also darkens
at every colour border of an 8 bit image (it interpolates sRGB bytes): the white image is the darkness test.

Why the mask and not a half-texel inset of the repeating axis: the inset needs the image's pixel size, which the
builder never reads (Image.size decodes the file: image_has_data's reason), and a missing image has none.
