# Light shadow switches and the VRayIES light shape Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a standard, photometric or VRayIES light whose shadows are off in 3ds Max casts none in Blender, and a
VRayIES with an overridden light shape gets a spot radius from it (bead maxdrop-em3.72).

**Architecture:** convert/lights.py reads the switch and the shape into its values dict, `LightDescription` gets
`shadow` (bool), the IES shape lands in the existing `radius`; build/lights.py sets `Light.use_shadow`. No new
module, no compat entry (`Light.use_shadow` exists on 4.2 and 5.2: checked by the Blender fixture run).

**Tech Stack:** Python 3.11 syntax, plain unittest, Blender 4.2 / 4.5 / 5.2 headless, 3ds Max 2020 + V-Ray 5.2
through 3dsmax-mcp for the fixtures.

---

## Probe results (3ds Max 2020, V-Ray 5.2, own session, scratch saves + tools/maxdiff.py)

- `light.castShadows` in MAXScript is the **node's** Cast Shadows render flag (node `0x099C` bit `0x200`); the
  light's own switch is `light.baseObject.castShadows`. Lights made by MAXScript start with shadows off.
- Standard lights (Omni, Spot, Direct): chunk `0x2570` (u16) of the light object, 1 shadows on, 0 off; written in
  both states. Missing: 0 (a new light's value).
- Photometric: block 0 id 3 `castShadows` (ParamBlock2 default 0).
- VRayIES: block 0 id 4 `cast_shadows` (default 1); 5 `use_light_shape` (0 no, 1 for shadows only, 2 for
  illumination and shadows; default 1), 21 `override_shape`, 22 `shape`, 23 height, 24 width, 25 length, 26
  diameter (world units), 35 `shape_actual` (-1 without a file; not used).
- VRayIES shape list (UI combo order = value): 0 point, 1 rectangle, 2 circle, 3 sphere, 4 vertical cylinder, 5
  horizontal cylinder (length), 6 horizontal cylinder (width), 7 ellipse (length), 8 ellipse (width), 9 ellipsoid
  (length), 10 ellipsoid (width), 11 elliptic cylinder, 12 hor. elliptic cylinder (length), 13 hor. elliptic
  cylinder (width), 14 vertical circle, 15 vertical ellipse, 16 cuboid. Sizes each enables (H W L D): 0 none; 1,
  7..13, 16 H W L; 2, 3 D; 4 H D; 5 L D; 6 W D; 14 W; 15 H W.
- VRaySun (V-Ray 5.2) has no shadow switch (only `cast_atmospheric_shadows`): nothing to read; documented.

## Rules

- `shadow` False when the switch is off -> `Light.use_shadow = False`. No issue: Blender does the same.
- VRayIES radius: 0 unless use_light_shape != 0 and override_shape on (without the override V-Ray takes the IES
  file's shape, which is not read). Then: point 0; sphere diameter / 2 (exact); any other shape a sphere of half the
  largest size it uses (abs, meters), an issue `its VRayIES <shape> shape is a sphere %g m across`.

**As shipped (deviations from the tasks below):** a switch that is not stored reads as **on** (the standard
light's chunk and the photometric parameter default 1, not a new light's 0: a file version that does not store it
would otherwise lose every shadow); the values key is `shadow`, not `cast_shadows`; the report line is `its <shape>
light shape is a sphere <x> m across`.

## Tasks

### Task 1: convert/lights.py

- `_IES_PARAMS` += cast_shadows (0, 4, 1), use_shape (0, 5, 1), override_shape (0, 21, 0), shape_type (0, 22, 0),
  height (0, 23, 0.0), width (0, 24, 0.0), length (0, 25, 0.0), diameter (0, 26, 0.0).
- `_PHOTOMETRIC_PARAMS` += cast_shadows (0, 3, 0).
- `_read_standard`: "shadow": `_u16(chunk, _SHADOW, 0)`, `_SHADOW = 0x2570`.
- `LightDescription.shadow` (slot, kwarg, default True); set by the three describers; the IES radius by
  `_ies_radius(v, meters, issues)`.
- Module docstring: the switch and the shape.

### Task 2: build/lights.py

- `light.use_shadow = ld.shadow`; docstring.

### Task 3: unit tests (tests/unit/test_lights_families.py)

- `standard()`, `photometric()` helpers get the new keys; tests for shadow off/on per family, the IES radius
  rules (no override, use_light_shape 0, point, sphere, rectangle, cylinder, negative size), the fixtures' shadow
  and radius values.

### Task 4: fixtures

- lights_standard.ms: `baseObject.castShadows = true` on StdOmni (and so its instance), StdSpot, StdTargetDirect;
  the others stay off. lights_photometric.ms: on for PhPoint and PhSpot; IesPower an overridden rectangle 200 x 400
  mm (radius 0.2 m, an issue); IesOverride cast_shadows off, an overridden sphere 100 mm across (radius 0.05 m).
- Run both in the own Max session (gamma off, mm), sanitize, check, copy to tests/fixtures, regenerate both
  oracles with `MaxDropOracle.dumpFile`.

### Task 5: tests/blender/run.py

- `STOCK_SHADOWS`: the names whose light casts shadows; `check_stock_light` compares `light.use_shadow`.

### Task 6: docs

- docs/FORMAT.md "Standard and photometric lights": chunk 0x2570, block 0 id 3, VRayIES 4 / 5 / 21..26 and the
  shape list, VRaySun has no switch, the MAXScript node-flag trap. docs/SUPPORT.md, CHANGELOG `[Unreleased]`.

### Task 7: verify

See Verification.
