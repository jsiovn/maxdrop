# Scene camera fallback as an info line Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A scene saved with a non-camera view active reports its scene camera fallback in the report's render line,
not as an issue; a damaged Config stream gets a reason of its own.

**Architecture:** `convert.cameras.render_camera` returns `(node, issue, note)`: the note (the first camera, the view
3ds Max renders looks through no camera) when the saved views were read, the issue when they were not (no Config
stream or layout, a damaged one, a view index out of range). `saved_views` returns a `SavedViews` whose `damaged`
field holds the reason when the Config stream cannot be read. `SceneDescription.camera_note` carries the note,
`Report.scene_camera_note` prints it after the scene camera's name.

**Tech Stack:** plain Python (convert/ is bpy-free), unittest, Blender 4.2 / 4.5 / 5.2 smoke tests.

Bead: maxdrop-em3.74

## Chunk 1: cameras, scene, report

### Task 1: `convert/cameras.py`

**Files:** Modify `maxdrop/convert/cameras.py`; test `tests/unit/test_cameras.py`

- [ ] `SavedViews = namedtuple("SavedViews", "viewports active damaged", defaults=(None,))`; `saved_views(cf)`:
  no Config stream -> None; layout missing -> None (views_of); a ChunkError / KeyError / ValueError / OSError ->
  `SavedViews([], None, str(exc))`.
- [ ] Messages: `NO_VIEW` (issue: "no saved view: the first camera, %s, is the scene camera"), `DAMAGED_VIEWS`
  (issue: "the saved views cannot be read (%s): the first camera, %s, is the scene camera"), `NOT_A_CAMERA` (note,
  no name: "the first camera: the view 3ds Max renders (viewport %d) looks through no camera").
- [ ] `render_camera(settings, views, cameras, names)` -> `(node, issue, note)`:
  - no cameras -> `(None, None, None)`
  - `views.damaged` -> `(first, DAMAGED_VIEWS % (reason, label), None)`
  - views None, or no view index, or index past the viewports -> `(first, NO_VIEW % label, None)`
  - camera view on a built camera -> `(node, None, None)`
  - otherwise -> `(first, None, NOT_A_CAMERA % (view + 1))`
- [ ] Tests: update `test_render_camera` to 3-tuples, add a damaged case; `test_saved_views_of_a_file_without_them`:
  Broken -> `damaged == "damaged"`, `viewports == []`; NoConfig -> None.
