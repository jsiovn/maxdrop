# Report: class names by the class directory, a count of patterns drawn approximately — Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** The import report names a material class without a rule by its class-directory name (cut and cleaned)
instead of a bare `ClassID(...)`, and counts procedural maps drawn with Blender's own pattern in a third line of the
"Approximated" block.

**Architecture:** A cleaner for names that come from the file (`materials/values.py: class_label`), used by
`materials/values.class_name` (new optional `directory` argument); `MaterialConverter._class_name(m)` reads the object's class-directory entry from the graph's scene (none for a graph
without one) and passes its name. A new counter `TexmapStats.approximated` flows through `report.add_materials` into
`Report.maps_approximated`, counted in `Report.approximated` and printed when not empty; `tools/first_open.py`'s report
dict moves into a pure function `report_counts(rep)` that carries it, so a plain test can pin it.

**Tech Stack:** Python 3.11, unittest, Blender 4.2 / 4.5 / 5.2 headless smoke runs.

Bead: maxdrop-o53.1.1. Base: `6954f55b36b1639bb082b625f8ad2a2a75318e0e`.

  ```python
  # materials/values.py
  MAX_CLASS_NAME = 64  # characters of a class-directory name the report shows: the name comes from the file
  _HIDDEN = frozenset(("Cc", "Cf", "Cs", "Zl", "Zp"))  # control, format, surrogate, line and paragraph separators

  def class_label(text):
      """A class-directory name as the report shows it: hidden characters as blanks, blanks collapsed and stripped,
      cut to MAX_CLASS_NAME characters ("..." at the end); "" for a name of nothing else."""
      text = " ".join("".join(" " if unicodedata.category(c) in _HIDDEN else c for c in text or "").split())
      return text if len(text) <= MAX_CLASS_NAME else text[:MAX_CLASS_NAME - 3] + "..."
  ```

  `class_label(directory)`, else `ClassID(...)`. `MaterialConverter._class_name(m)`: the entry of `m.index` in
  `getattr(self.graph, "scene", None)` (none -> `""`), then `class_name(m.superclass, m.class_id, entry.name)`; every
