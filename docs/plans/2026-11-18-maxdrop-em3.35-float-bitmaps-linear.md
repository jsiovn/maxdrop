# Float files under automatic gamma as linear (Bitmap, CoronaBitmap) Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Bitmap or CoronaBitmap with automatic gamma whose file is an EXR or HDR gives gamma 1.0 (Non-Color,
no Gamma node), as 3ds Max and Corona read float files, and as maxdrop-arp.12 already does for VRayBitmap.

**Architecture:** One module-level helper in `maxdrop/convert/texmaps.py`, `_auto_gamma(gamma, name)`: an
automatic gamma (None) on a file name ending in `FLOAT_IMAGES` becomes 1.0, anything else is kept. `_image`
(Bitmap) and `_corona_image` call it on their gamma before `colorspace()`. An explicit override is kept as it is.
"Automatic" is what the readers already return as None: a Bitmap without the override flag (or an unreadable
BitmapInfo, whose default is automatic), a CoronaBitmap gamma of -1 or outside 0.1 to 10. `_vray_gamma` keeps its
own logic (its explicit sRGB transfer function must stay sRGB).

**Tech Stack:** Python 3.11, unittest; Blender 4.2 / 4.5 / 5.2 smoke.

```python
def _auto_gamma(gamma, name):
    """A Bitmap's or CoronaBitmap's gamma: automatic (None) reads a float file (EXR, HDR) as linear, as 3ds Max
    and Corona do; an override is kept."""
    return 1.0 if gamma is None and name.lower().endswith(FLOAT_IMAGES) else gamma
```

`_image`: `gamma = _auto_gamma(self._gamma(m), entry.name)`; `_corona_image`: `gamma = _auto_gamma(gamma if
0.1 <= gamma <= 10.0 else None, entry.name)`.
