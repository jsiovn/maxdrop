# Standard shaders and Physical ids only a probe covered: fixture standard_shaders Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A committed fixture, `standard_shaders`, holds one Standard box per shader (Anisotropic, Blinn, Metal,
Multi-Layer, Oren-Nayar-Blinn, Phong, Strauss, Translucent) and two Physical Material boxes that set the ids no
fixture set (5 roughness_inv, 37 thin_walled, 52 emit_luminance, 61 coat_color, 63 coat_roughness_inv, the maps
101-133, their switches 151-183, 230 bump_map_amt); the shader ClassIDs move into `reader/classids.py` and the
rules are checked against the file.

**Architecture:** `tools/fixtures/standard_shaders.ms` saves ten Editable Poly boxes. Each Standard material sets
diffuse, specular color, specular level, glossiness, self-illumination amount *and* color to its own values, with
`useSelfIllumColor` on for Blinn, Metal, Oren-Nayar-Blinn and Translucent and off for the others (so both
branches of the rule run); Multi-Layer's second layer and Translucent's translucent color hold look-alike values
the rule must not read. The Physical boxes: `FixturePhysicalMaps` (every map slot the rule reads, the
transparency map switched off, roughness and coat roughness inverted, thin-walled, an emission color map,
luminance away from 1500, a bump amount) and `FixturePhysicalEmit` (an emission weight map). Maps are Checker /
Noise (no file paths). The generic raw-parameter parity (`test_materials.py`) checks the reader against the
oracle; new `test_convert_materials.py` classes check each IR against values computed by hand from the script, and
check that the ids of `SHADERS`, Strauss and `physical_mtl` name the expected parameters in the fixture's oracle
(independent of `SHADERS`, so a wrong id fails).

**Tech Stack:** MAXScript (3ds Max 2020, `3dsmaxbatch.exe` with the ViewCube / solid-background wrapper), plain
Python `unittest`, Blender 4.2 / 4.5 / 5.2 headless.

Bead: maxdrop-em3.23

| Strauss `(0x2857F450, 0)` | 0 | | | 1 | | | | 2 metalness |

Physical Material block 0: 5 roughness_inv, 37 thin_walled, 52 emit_luminance (default 1500), 61 coat_color,
63 coat_roughness_inv, maps 100-133 (`*_map`), switches 150-183 (`*_map_on`, default on), 230 bump_map_amt
(default 0.3, a factor). `emission` defaults to 1.0 with a black emit_color.

Not in this bead (debt): the rule ignores diffuseLevel (Anisotropic, Multi-Layer, Oren-Nayar-Blinn,
Translucent), and the defaults it takes for a missing shader parameter are Blinn's for every shader (the other
shaders default to diffuse 127.5 grey, glossiness 25 / 50 / 25 / 30 / 20 %, Anisotropic and Multi-Layer level 5 %).
The fixture keeps diffuseLevel at 100.
