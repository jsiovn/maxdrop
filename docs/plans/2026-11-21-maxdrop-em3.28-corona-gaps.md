# Corona gaps: layers, SSS, sheen, translucency, CoronaMix operations, Skin Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the Corona gaps maxdrop-arp.7 left: each scope bullet of bead maxdrop-em3.28 ends as a measured rule
with a fixture, a specific named issue (where Principled has no equivalent), or a debt bead (where it cannot be
measured here).

**Architecture:** `convert/materials.py` gains rules (CoronaLayeredMtl as a material with layers, Corona SSS,
sheen, edge color, complex IOR, CoronaSkinMtl, the CoronaRaySwitchMtl / CoronaSelectMtl wrappers) and named issues;
`MaterialIR` gains `sheen_*`, `specular_tint` and `layers`; `build/materials.py` draws sheen / specular tint by
socket name and a layered material as Principled BSDFs chained by Mix Shader nodes. `convert/texmaps.py` gains a
`Blend` node (CoronaMix add, subtract, divide, min, max, difference, in gamma 2.2 when mixInSRgb is on) and
Corona's own Kelvin table; the layer multipliers and offsets become an Adjust. Two new fixtures, `corona_more` and
`corona_mix_ops`; the existing `corona_*` fixtures stay as they are.

**Tech Stack:** Python 3.11 syntax, standard library, `unittest`; 3ds Max 2020 + Corona 12 (`3dsmaxbatch`) for
probes, fixtures and oracles; Blender 4.2 / 4.5 / 5.2 headless.

Bead: maxdrop-em3.28
