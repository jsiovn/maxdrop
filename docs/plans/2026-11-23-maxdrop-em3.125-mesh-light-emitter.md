# VRayLight mesh light emitter; CoronaBitmap on a dome Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** A VRayLight mesh light becomes an emissive mesh object (its mesh at the light node's transform, the
strength V-Ray gives it); a CoronaBitmap on a dome keeps its report line, now saying what V-Ray does with it.

**Architecture:** `convert/lights.py` (no bpy) reads the mesh light's flip (35) and its own mesh object (reference
1) and describes an `EmitterDescription` (radiance in W/m²/sr from the units over the object-space mesh area, sides,
switches). `convert/scene.py` resolves the mesh (own object, else the node parameter 34 names), builds a
MeshDescription of its base mesh with the light node's offset and turns the light node into a MESH node with
`node.emitter`; no mesh → the empty and the report line as before. `build/emitters.py` makes the Emission material
(strength × Light Strength, a Backfacing mask for one side) and sets the object's ray visibility; `build/objects.py`
gives an emitter mesh that material only.

**Tech Stack:** Python 3.11 syntax; 3ds Max 2020 + V-Ray 5.2 (3dsmaxbatch for renders, an own interactive 3ds Max
for the UI pick and the fixture); Blender 4.2.23 / 4.5.16 / 5.2 headless.

- Seen by the camera (visible, facing it): 11.3833 = (1 / (π 0.04)) × 1.4305 (W 1): the radiance in pixel units at

## Rules

- Mesh object: the light's reference 1 when it holds an object, else the object of the node parameter 34 names;
  neither (none picked, its node deleted, an unreadable record) → the empty and a report line. Its base must be a
  mesh MaxDrop reads (Editable Mesh / Poly, a primitive built here), else the empty and a line naming the class.
  Modifiers on its stack: the base mesh is used, a line naming them (shape and, in W and lm, brightness differ).
- Mesh: the base mesh in object space with the **light node's** offset baked (key `(EMITTER, light base,
  mesh base, offset)`: two lights picking one mesh get a mesh each, each with its own material), users the light nodes; area a = its object-space polygon area in m² (no offset).
- Radiance L (W/m²/sr): default m·1500/(683π); lm/m²/sr m/683; W/m²/sr m; W m/(π a); lm m/(683 π a), with a doubled
  when double-sided in W and lm. Double-sided in the radiance modes: L on both sides. a = 0 in W or lm → 0, a line.
- Emission strength = L × Light Strength, color = light_color. One side: Mix by Geometry Backfacing, the back
  black (flip: the front black). Double-sided: both sides emit.
- Object: off → hidden; invisible → camera off and shadow off (visible → seen and shadowing, as measured);
  diffuse / glossy rays as a light's; texture, directional, contributions ≠ 1, cast shadows off → lines.
- One EmitterDescription per light object (users its nodes); the report counts it with the lights.
