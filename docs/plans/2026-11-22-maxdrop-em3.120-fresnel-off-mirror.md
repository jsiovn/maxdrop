# VRayMtl Fresnel off: a reflection weight without Fresnel Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a VRayMtl with Fresnel off reflects its reflection weight (a dim swatch, or a reflection map such as the
black to white Falloff) at every angle, as V-Ray renders it, instead of that weight times Blender's dielectric
Fresnel curve (about 20 times too little head-on for a 0.2 swatch).

**Architecture:** `MaterialIR` gets `fresnel: bool = True`; `vray_mtl` sets it from `reflection_fresnel`.
`build/materials.py` draws a weight with `fresnel` off, where em3.119's twin would apply (a weight map that converts,
or a constant strictly between 0 and 1 without a reflection map; no constant Metallic or Transmission Weight of 1),
as a Mix Shader (`Reflection weight`, factor the weight) between the filled Principled BSDF at Specular IOR Level 0
(the diffuse side, no Fresnel reflection) and a copy of it labelled `Mirror reflection`: Metallic 1, Base Color white
(both unlinked), every other input copied. A white metal reflects 1 at every angle (em3.34's control S4 matched V-Ray
within 0.2 % in Cycles), so the mix gives w x 1 + (1 - w) x diffuse, V-Ray's Fresnel-off split. The metal rule
(Fresnel off, the swatch's shown share >= METAL_REFLECTION) stays as it is: Metallic 1 keeps the lone BSDF. A
reflection map that does not convert (`ir.specular.map` set, no graph) keeps today's drawing (the swatch through the
twin), so a hidden bright swatch never becomes a near mirror.

**Tech Stack:** 3ds Max 2020 + V-Ray 5.2 (`3dsmaxbatch`), Blender 4.2 / 4.5 / 5.2 headless (EEVEE, Cycles), plain
Python unittest.
