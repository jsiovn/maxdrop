# Pack Folder Preview Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The import popup names the exact folder a scene pack unpacks into (or is read from), recomputed when the
Scene field changes.

**Architecture:** `archive.preview()` runs `_destination()`, the code path `unpack()` uses, and returns
`(mode, .max path)` for every outcome: `"unpacked"` (the first free candidate folder), `"reused"` or `"in_place"`.
It writes nothing. It replaces `existing_folder()` (which answered only the last two). `ops.py` keeps the preview
per (pack, chosen scene) in `_TARGETS`; `invoke()` fills it for the scene known at invoke time, and the popup's
`draw()` computes it once when `pack_scene` names another scene (read-only, cached; the parent-folder probe that
creates a folder stays in `invoke()`).

**Tech Stack:** Python 3.11 stdlib, Blender 4.2 / 4.5 / 5.2 UI (`layout.label`).

- [ ] Implement:

```python
def preview(path, scene, several, dest_parent=None, references=None):
    """(mode, .max path) of what unpack() of the scene would do now, writing nothing: "unpacked" into the first
    free folder, "reused" (an earlier unpack) or "in_place" (a copy extracted by hand). None when the archive
    cannot be read or no folder name is free. unpack() may still take the next free name when another process
    makes that folder first."""
    path = os.path.abspath(path)
    dest_parent = os.path.abspath(dest_parent or os.path.dirname(path))
    entry = Entry(scene)
    try:
        found = _destination(path, dest_parent, entry, several, _ident(path, os.stat(path)), references)
    except (OSError, PackError):
        return None
    if found[0] == "free":
        return ("unpacked", os.path.join(found[1], entry.base))
    return found
```
