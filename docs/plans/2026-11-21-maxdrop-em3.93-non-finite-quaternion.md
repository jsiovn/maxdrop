# Non-finite stored quaternion Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A NaN or infinite quaternion stored in a `.max` file (a TCB / Linear / Bezier rotation value, a scale
axis, a node's pivot rotation) is reported as `NON_FINITE` instead of read as a silent identity rotation.

**Architecture:** `quat_matrix` tests the squared norm `n` once: not finite gives `_NAN_MATRIX` (which every caller
already funnels into a `_finite` check: `Transforms._evaluate`, `controllers.matrix`), `n <= 1e-30` still gives
`IDENTITY` (a zero-length finite quaternion is unchanged). `Transforms.offset`, which until now turned a non-finite
offset into identity without a word, appends `Issue(i, None, None, None, NON_FINITE)`; that also reports a
non-finite pivot position or pivot scale, which were silent too. `convert/scene.py` copies `t.issues` after every
`t.offset()` call, so the new issue reaches the report as `transform: non-finite transform`.

**Tech Stack:** plain Python, `unittest`.

Bead: maxdrop-em3.93
