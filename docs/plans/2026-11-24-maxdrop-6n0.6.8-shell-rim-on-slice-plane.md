# Symmetry above a Shell whose rim lies on the slice plane Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Shell below a Symmetry whose rim lies on the slice plane imports as 3ds Max 2020 shows it: the Mirror is
moved below the Solidify, where it welds the cut shut before the shell is made (no rim faces inside the seam, no false
rim-corner line); where that is not exact, a report line (bead maxdrop-6n0.6.8).

**Architecture:** `convert/scene.py`: `_seam(converted)` finds the lowest Shell with only Mirrors converted below it
and the run of Mirrors directly above it; `lowered(md, below, above, unit)` (numpy, no bpy) says how many of those
Mirrors to move below the Shell and whether one of them leaves a rim on its plane that is not converted;
`_mapped_mesh` decides once per mesh key (the key holds the candidate Mirrors) and records it on the
MeshDescription; `describe` reorders the node's converted modifiers, passes the moved Mirrors to the rim's sharp edges
(`_rim_edges`) and to `rim_issues` (caller side), and names the report line. Build adds the modifiers in that order.

**Tech Stack:** Python + numpy (convert/), MAXScript in 3ds Max 2020 (probe, fixture), Blender 4.2/4.5/5.2.

Bead: maxdrop-6n0.6.8

- 3ds Max's slice drops the Shell's rim faces lying on its plane (within 1e-4 system units: 1e-3 off, they stay,
  doubled), only with the slice on (off: doubled) and the weld on (off: dropped, the seam left open, which Blender
  cannot make). The Mirror moved below the Solidify gives 3ds Max's counts where the rim lies on the plane.
- A rim off the plane (slanted faces at the cut, gizmo off or turned) matches neither order: a report line.
- Rule: per Mirror of the run directly above the lowest Shell (only Mirrors below it), on the mesh with the copies of
  the Mirrors below or moved: the open edges with both ends within PLANE_TOLERANCE (1e-4 file units) of its plane.
  None: stop. Moved when the Mirror slices and welds those ends and every face at them is perpendicular to the plane
  (|n . axis| <= NORMAL_TOLERANCE 1e-5: the rim stays within 1e-4 of the plane for a shell up to 10 units); else a
  report line, stop.
- An emitter mesh (V-Ray mesh light) keeps 3ds Max's order: the rim faces inside its seam's wall emit nothing seen.
