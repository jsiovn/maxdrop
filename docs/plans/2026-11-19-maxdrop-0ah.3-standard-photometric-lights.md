# Standard and Photometric Lights, VRaySun, VRayIES Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The remaining light classes of interior scenes become Blender lights: 3ds Max's standard lights (Omni,
Free / Target Spot, Free / Target Direct), the photometric lights (Free / Target Light in all six shapes), VRaySun
and VRayIES, with the same power pipeline and the same Light Strength as the VRayLights of maxdrop-0ah.2; Skylight
and a VRaySky stay a line in the report.

**Architecture:** `convert/lights.py` (no bpy) grows a class dispatch: `light_class(scene, i)` names the family of a
light object by ClassID, `read_params(scene, i, assets)` reads its parameters (VRayLight, VRaySun, VRayIES and the
photometric lights from their ParamBlock2s by parameter id, the standard lights from their old ParamBlock by index
and their own chunks) into a values dict tagged with its family, and `describe()` turns them into the
`LightDescription` (now also SPOT and SUN). `convert/scene.py` calls it for every light family (it already does for
VRayLight) and passes the scene's asset table on for the IES file names; `build/lights.py` sets the spot cone and
the sun angle.

**Tech Stack:** Python 3.11 syntax; 3ds Max 2020 + V-Ray 5.2 through 3dsmax-mcp (own instance) for the probes, the
fixtures, their oracles and the calibration renders; Blender 4.2 / 4.5 / 5.2 headless.

## What 3ds Max 2020 + V-Ray 5.2 store (probed on scratch scenes)

- Standard lights, superclass 0x30: Omni `(0x1011, 0)`, Target Spot `(0x1012, 0)`, Free Direct `(0x1013, 0)`, Free
  Spot `(0x1014, 0)`, Target Direct `(0x1015, 0)`. Reference 0 = old ParamBlock by index: Omni 0 color (0..1), 1
  multiplier, 8 decay start; Spot / Direct 0 color, 1 multiplier, 4 hotspot, 5 falloff (degrees; a Direct's in
  world units, its beam), 6 aspect, 11 decay start. Chunks of the light object: 0x2580 u16 on; 0x25D0 u16 decay
  (0 none, 1 inverse, 2 inverse square; absent = none); 0x2573 u16 cone shape (1 circle, 0 rectangle); 0x2575
  present = overshoot; 0x25B0 present = affect diffuse off; 0x25B1 present = affect specular off; 0x2600 present =
  ambient only.
- Photometric lights, superclass 0x30, one class per shape: Free Light (point) `(0x32375FCC, 0x0B025CF0)`, Free
  Line `(0x78207401, 0x357F1D58)`, Free Rectangle `(0x36507D92, 0x105A1A47)`, Free Disc `(0x5BCC6D42, 0x0C4F430E)`,
  Free Sphere `(0x7CA93582, 0x1ABB6B32)`, Target Light (point) `(0x658D4F97, 0x72CD4259)`, Target Cylinder
  `(0x7C8B5B10, 0x4BD33E86)`; the other Target / Free shapes are read from the fixture's class directory. Five
  ParamBlock2s by block id: block 0: 1 distribution (0 isotropic, 1 spotlight, 2 uniform diffuse, 3 web), 2 on, 5
  filter color, 6 intensity (always cd, whatever the units shown), 8 Kelvin, 10 use Kelvin, 18 use dimmer, 19
  dimmer (%), 21 use far attenuation; block 2: 0 hotspot, 1 falloff (degrees); block 3: 0 web file (an asset);
  block 4: 4 affect diffuse, 5 affect specular, 6 ambient only, 11 length (line, rectangle along local Y,
  cylinder), 12 width (rectangle, local X), 13 radius (disc, sphere, cylinder). Without Kelvin the lamp color is a
  preset that MAXScript does not reach: white is taken.
- VRaySun `(0x732C0383, 0x7D993776)`: block 0: 0 enabled, 2 intensity multiplier, 3 size multiplier, 9 invisible,
  14 / 19 affect diffuse / contribution, 15 / 20 affect specular / contribution, 17 filter color, 18 color mode
  (0 filter, 1 direct, 2 override).
- VRayIES `(0x2EAF2F07, 0x7EC44F31)`: block 0: 0 enabled, 1 IES file (an asset), 7 color temperature, 8 color, 9
  color mode (1 temperature), 10 power (lm), 14 / 30 affect diffuse / contribution, 15 / 31 affect specular /
  contribution, 32 intensity type (0 lm, 1 cd), 33 intensity value, 34 override intensity.
- Skylight `(0x7BF61478, 0x522E4705)`: not built (World is later work). VRaySky is a map `(0x48480B4E,
  0x62FF5A90)`; the environment map is RenderEnvironment's reference 5: a VRaySky there -> one report line.
- All of them shine along their local -Z, as Blender's spot, area and sun lights: the node transform stays (a target
  light's is the Look At of maxdrop-0ah.1).

## Calibration (V-Ray 5.2 renders, scratch scene, not committed)

A white floor (VRayMtl), each light alone 1 m above it pointing down, V-Ray linear, gamma off, no GI, the 8 x 8
center pixels: V-Ray's pixel is the illuminance in lx / 1500 for every class (a 1 W VRayLight sphere 0.0362 =
683 / (4 pi) / 1500; Free Light 1000 cd isotropic, spotlight and diffuse 0.667; a VRayIES of 1000 lm isotropic
0.0531; standard Omni, Spot, Direct of multiplier 1 1.0 at 1 m without decay, 1.0 with inverse-square decay from 1 m,
0.25 from 0.5 m, 0.5 inverse from 0.5 m; VRaySun multiplier 1 at the zenith 68.5 = 102.7 klx). Cycles (Blender 5.2):
a 1 W point light at 1 m 0.02526 (1 / 4 pi^2), a sun of strength 1 0.3176 (1 / pi), a 1 W disk 0.1010 (1 / pi^2).
So Light Strength 1.43 = pi 683 / 1500 (1.4305) is exactly what makes watts in flux (lm / 683) match V-Ray, for
every class, and the rules below follow from it:

- photometric: cd x dimmer -> isotropic, spotlight, web: `4 pi cd / 683` W (the rules source's); diffuse: `pi cd /
  683` W (the flux of a Lambertian emitter of that on-axis intensity) on an area light.
- standard Omni and Spot: the intensity V-Ray gives at distance d is 1500 m d^2 cd: d = the decay start for inverse
  square (exact past it) and inverse (exact at it), 1 m without decay (an issue: Blender's lights fall off); then
  as photometric.
- standard Direct: 1500 m lx -> sun strength `1500 m / 683` W/m^2.
- VRaySun: the rules source's `146.4 m` W/m^2 (100 klx / 683; 102.7 klx measured at the zenith), angle 0.53 degrees x
  size multiplier; its filter color.
- VRayIES: lm = power, or the override (lm, or cd x 4 pi): `lm / 683` W, a spot of 170 degrees, hotspot 100
  (the rules source's wide spot), an issue with the IES file's name.

## Mapping

| 3ds Max | Blender | Approximations (issues) |
|---|---|---|
| Omni | POINT, radius 0 | decay none / inverse; ambient only |
| Free / Target Spot | SPOT, size = falloff, blend: full intensity out to the hotspot (cosine space, after the review) | rectangle cone, overshoot, decay |
| Free / Target Direct | SUN, angle 0 | its beam (falloff radius) is not imported |
| photometric isotropic | POINT, radius of a disc, sphere, cylinder | a line or rectangle shape |
| photometric spotlight | SPOT, cone of block 2, same radius | same |
| photometric diffuse | AREA: rectangle RECTANGLE (width x length), disc DISK, others DISK of 2 r / RECTANGLE of the line | point, line, sphere, cylinder shapes |
| photometric web | SPOT 170 degrees | web file named; far attenuation |
| VRaySun | SUN | the sky model's color / intensity |
| VRayIES | SPOT 170 degrees | IES file named |
| Skylight | EMPTY | not imported |

Off -> hidden; affect diffuse / specular off -> not seen by diffuse / glossy rays; V-Ray contributions as for
VRayLight. A negative multiplier or intensity -> 0 W (an issue). Instances share one light (key (base, 1)).
