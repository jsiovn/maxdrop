# The exposure factor of a VRayPhysicalCamera, measured in V-Ray 5.2 Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** one formula, in docs/FORMAT.md "Cameras", that turns a VRayPhysicalCamera's ISO, shutter speed and
f-number (or its stored exposure value) into the factor V-Ray scales the image by, written as stops for Blender's
`scene.view_settings.exposure`.

**Architecture:** a 3dsmaxbatch probe (outside the repo, `C:\maxdrop_fixtures\probe\o53_2_2\`) renders the
calibration floor of docs/FORMAT.md through a VRayPhysicalCamera looking down, into float bitmaps with V-Ray's
output clamp off; a scratch Python script fits k in `k · ISO · t / N²` and recomputes every row. The setup, the
pixel table, the formula and what is left out go into docs/FORMAT.md. No `maxdrop/` code.

**Tech Stack:** MAXScript (3ds Max 2020, V-Ray 5.2, `3dsmaxbatch.exe`), plain Python.

Bead: maxdrop-o53.2.2 · Base: 9ad53e1
