# baseline.py: material problems Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `tools/baseline.py` counts the `N material problem(s)` part of the operator's `Imported ...` line as
`import_report["material_problems"]` (0 when absent).

**Architecture:** `Report.summary()` (`maxdrop/convert/report.py`) lists `_plural(material_problems, "material
problem")` among the left-out parts since maxdrop-em3.18; `LEFT_OUT` / `LEFT_OUT_KEYS` in `tools/baseline.py`
gain the word `material problem` -> key `material_problems`. `read_log` initialises every `LEFT_OUT_KEYS` value
to 0, so the new key is 0 when the line has no such part.

**Tech Stack:** Python 3.11, `unittest`, no Blender for the tests.

Bead: maxdrop-em3.66
