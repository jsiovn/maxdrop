# Gamma-off images with their own decode Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In a scene saved with the gamma off, draw a VRayBitmap (Auto, sRGB, None, inverse gamma) and a float
image (Bitmap, VRayBitmap From 3ds Max or Auto on an EXR / HDR) on a color input or a mask the way V-Ray shows it:
their own decode, then decoded once more for the display-referred scene.

**Architecture:** The rule lives in `convert/texmaps.py`: with the gamma off a map's internal value v shows as
`srgb_to_linear(v)` in Blender. A map whose internal value is `pixel ^ g` gets the Image gamma `2.2 g` (2.2 itself:
the sRGB color space, exact); one with the sRGB curve as its own decode gets `SRGB_TWICE = 5.0` (the sRGB curve
applied twice is within 0.008 of `x ^ 5` over 0..1; `2.2 x 2.2` would be within 0.019). Data inputs keep the map's
own decode (maxdrop-em3.122). The builder already draws a Linear Rec.709 image with a Gamma node; `build/world.py`
gets the same Gamma node, so a dome texture keeps its gamma (it ignored a non-2.2 gamma until now).

**Tech Stack:** Python 3.11 standard library; 3ds Max 2020 + V-Ray 5.2 (`3dsmaxbatch`) probes; Blender 4.2 / 4.5 /
5.2 headless.

## The rule (gamma off, COLOR and MASK kinds; DATA, NORMAL, BUMP and gamma on / unknown unchanged)

- Bitmap, any file: as stored, shown decoded -> None (sRGB). Today an EXR / HDR is 1.0 (linear).
- VRayBitmap From 3ds Max, any file: the same (None). Today a float file is 1.0.
- VRayBitmap None and Auto on a float file: own 1.0 -> 2.2 (sRGB).
- VRayBitmap sRGB (any file) and Auto on an 8-bit file: own sRGB curve -> 5.0 (Linear Rec.709 + Gamma node).
- VRayBitmap inverse gamma G: own `1 / G` -> `2.2 / G` (sRGB at G = 1).
- CoronaBitmap and CoronaColor HDR: unchanged. Whether a Corona render shows them as V-Ray does is the Corona half
  of this bead (no Corona render so far: maxdrop-em3.115's notes); a debt bead under maxdrop-em3 keeps it.

Fixture effect (every fixture but gamma_swatches is gamma-off): vray_texmaps' Auto images become Linear Rec.709 +
gamma 5.0, vtx_linear.png (None) sRGB, vtx_invgamma.png (inverse 2) gamma 1.1; vray_dome's Auto dome image gamma
5.0 (a Gamma node in the World). The found-textures check's "a linear color image" points at an Auto image.
