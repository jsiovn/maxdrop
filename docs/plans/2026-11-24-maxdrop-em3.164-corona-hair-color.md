# CoronaHairMtl color measured on Corona 12 renders Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CoronaHairMtl's base color comes from Corona 12 renders of the material on a mesh (the surface MaxDrop
builds), in place of the color Blender's Principled Hair BSDF gives a strand (`hair_color`, maxdrop-em3.116), with the
diffuse and transmission colors combined as Corona combines them.

**Architecture:** `maxdrop/convert/materials.py` only (bpy-free): `hair_color` and `corona_hair_mtl` and their
constants. The build is unchanged (one Principled layer). Docs and the unit tests follow.

**Tech Stack:** Python 3.11, 3ds Max 2020 + Corona 12 (3dsmaxbatch probes, local, outside the repo), Blender 5.2 Cycles
for the side-by-side furnace.

## Measurements (done before the plan; Corona 12, 3dsmaxbatch, white furnace: white environment, no light, tone
## mapping off, gamma off, linear readout, a top orthographic camera; probe folder local, outside the repo)

- Planes with CoronaHairMtl: the furnace is 1.0; melanin 0 reads 0.995. Turned 90 degrees about the normal: the same;
  tilted 60 degrees: 1% darker. Glossiness (0.2 / 0.9), softness (0 / 0.5), colorless glossiness (0.5 / 1), highlight
  shift (0 / 5) and GI simplification change nothing (within 0.005); they shape the highlight only.
- Melanin 0.5 (the default): 0.396 / 0.232 / 0.099 (hair_color draws 0.031 / 0.011 / 0.002: far too dark).
- A colorless floor: melanin 1 reads 0.081 / 0.070 / 0.070; the colorless specular black removes it (melanin 0:
  0.929, melanin 1: 0.011 / 0 / 0). So albedo = R + P0 x exp(-u) per channel, R = 0.070, P0 = 0.929.
- u per channel is Cycles' pigment absorption shape: channel ratios 1 : 1.67 : 3.25 at pheomelanin 0 (Cycles'
  eumelanin 0.506 / 0.841 / 1.653 = 1 : 1.66 : 3.27) and 1 : 2.2 : 5.7 at pheomelanin 1 (Cycles' pheomelanin 0.343 /
  0.733 / 1.924 = 1 : 2.14 : 5.61), constant over melanin. Pheomelanin is the fraction of the melanin that is red
  (melanin 0 with pheomelanin 0.6 = melanin 0; u mixes linearly: melanin 0.5 pheomelanin 0.6 predicted 0.701, read
  0.7025), as Blender's Melanin Redness, but weaker: Corona's pheomelanin absorbs 0.685 x Cycles' coefficients.
- Fit over melanin 0 ... 1 (12 steps) at pheomelanin 0 and 1: u_c = (7.68 m^2 + 1.2 m^3) x ((1 - p) EU_c + 0.685 p
  PH_c); largest error 0.009; nine held-out mixes (pheomelanin 0.2 ... 0.8, melanin 0.3 ... 0.8) within 0.006.
- Tint (grey sweep at melanin 0, colorless specular off): 0.25 -> 0.837, 0.5 -> 0.905 of 0.929; u = 0.054 x ln(t)^2
  (Chiang's color parametrization). Black tint: only the floor. A tint map (CoronaColor) renders as the same swatch
  would: added to the melanin's u, not in place of it (melanin 0, 204/128/51: 0.995 / 0.980 / 0.887, not the map's
  0.8 / 0.5 / 0.2).
- Diffuse: grey d mixes as d + (1 - d) x hair, exact (0.5 at melanin 0.5, 0.25 by levelDiffuse 0.5, 0.25 at melanin
  0.8). A colored d weighs the hair part by about 1 - its largest channel (204/128/51: 0.32 at melanin 0.5, 0.39 at 0.8;
  pure red 0.39, pure blue 0.09); exact weight not resolved.
- Transmission color multiplies the pigment part (0.5 grey at melanin 0: 0.567, at melanin 0.5: 0.237 / 0.152 /
  0.085; 255/128/64: 0.996 / 0.568 / 0.350); black leaves the floor (0.078). Colored specular black: 0.945 at melanin
  0 (TRT is small on a plane). IOR moves both the floor and the color (1.3: 0.398 / 0.223 / 0.074; 2.0: 0.412 /
  0.267 / 0.156). Glint 1 brightens (0.433 / 0.278 / 0.149), randomize melanin 0.5 too (0.447 / 0.368 / 0.293).
- Hair and Fur strands: not measured; not established whether Corona shades Hair and Fur strands with this material.
  Strands grown on a plane whose own faces are black, tip and root colors white, no hue or value variation, seen
  from the side in the furnace, read 0.4935 grey for every melanin, pheomelanin and tint (on the plane carrying the
  material and with Hair and Fur's MR_ApplyShader on alike; setting MR_Shader to the CoronaHairMtl raised an access
  violation). An earlier end-on view with Hair and Fur's default colors followed the melanin, but its window held
  the growth plane, which carries the material.
  maxdrop-6n0.6.30 holds it.

## Rule

- `hair_color(melanin, pheomelanin, tint)` = exp(-u), u as above (HAIR_MELANIN = (7.68, 1.2), HAIR_PHEOMELANIN_SCALE
  0.685, HAIR_TINT 0.054, the tint floored at HAIR_FLOOR); the Cycles roughness-scale constants go.
- `corona_hair_mtl`: h = hair_color x transmission color (152); base = d + (1 - max(d)) x (0.070 + 0.929 h - 0.043) /
  0.957 (Corona's colorless floor and pigment share against the Principled's own floor 0.043 at IOR 1.55, roughness
  0.5, measured in a Cycles furnace after the first implementation read 0.026 dark), d = colorDiffuse x
  levelDiffuse, at most 1. The tint map (112) is no longer drawn: a named issue ("tint map not converted"), the
  swatch tint used. randomizeMelanin (143) above 0 is a named issue (review). The transmission map (155) stays named.
- Specular stays 1. Ids 143 and 150-152 checked on a scratch save read by MaxDrop's reader (152 = transmission).
