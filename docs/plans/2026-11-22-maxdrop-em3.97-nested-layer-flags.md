# Hidden and Frozen Parent Layers Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A committed fixture, `layers_nested`, shows what 3ds Max saves for a hidden and a frozen parent layer and
a three-level nest, so the importer's rule (a hidden layer's collection excluded leaves out the layers below it, a
frozen one's hide_select reaches them) is checked against a 3ds Max oracle instead of a hand-changed description.

**Architecture:** No reader, converter or builder change: the probe shows 3ds Max keeps the flag on the parent
layer only, and its own answer (MAXScript `isHidden` / `isFrozen`, the oracle's layer flags) is the inherited
state, which Blender's collection exclude and hide_select give the nested collections too. Tests compare the
reader's own bits, OR-ed up the parent chain, with the oracle.

**Tech Stack:** 3ds Max 2020 (`3dsmaxbatch.exe`, probes in a folder of the bead's own outside the repo), plain
Python `unittest`, Blender 4.2.23 / 4.5.16 / 5.2 headless with an isolated profile.

---

## Probe (2026-11-22, 3dsmaxbatch, scenes built by script and saved, read back with the reader)

- A hidden parent layer: `0x1020` = `0x100000` on the parent, `0` on its child; a frozen parent: `0x200000` on the
  parent, `0` on the child. A hidden top of a three-level nest: the bit on the top only. The nodes' `0x0960` keep
  `0x800` (no hidden or frozen bit).
- MAXScript: the child layer's `isHidden` / `isFrozen` answer true (also the grandchildren, also after reload, also
  after `child.isHidden = false` while the parent stays hidden); the nodes' `isHidden` / `isFrozen` too;
  `INode.IsObjectHidden` / `IsObjectFrozen` false. .NET `ILayer.IsHidden(false)` is the own flag,
  `IsHidden(true)` the inherited one: MAXScript answers the latter.
- Scanline: a node on the child of a hidden parent layer renders no pixel.
- A non-rendering parent layer: `0x1050` = `0x0B005600` on the parent only; the child's `renderable` and its
  node's stay true. Whether 3ds Max renders that node cannot be told here: a node made by script does not render
  By Layer (maxdrop-em3.145), so even a non-rendering child layer renders it. Not in the fixture; stays under Open.
- Blender 5.2 / 4.2: `hide_select` on a collection makes the objects of its child and grandchild collections
  unselectable (`selectable_objects`, `select_set`).

## Decisions

- New fixture (not layers_more extended): its checks stay as they are.
- Oracle layout stays 13: its layer `hidden` / `frozen` are the inherited state (that is what checks the rule);
  the file's own bits are pinned by a records test. ORACLE.md says so.
- `check_hidden_parent_layer` (hand-changed layers_more description) is replaced by a layers_nested check driven
  by the oracle.
- No CHANGELOG / SUPPORT line: nothing imported changes.
