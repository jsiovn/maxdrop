# Noise as nodes in object XYZ Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Noise map converts to a Mix of its two sides by a Noise leaf (Blender's Noise Texture on the object's
coordinates at 3ds Max's size, levels and thresholds), counted as approximated, instead of "no bitmap below".

**Architecture:** A new rule module `convert/texmaps/maps_xyz.py` (the 3D maps placed by an XYZGen part) holds
`_noise` (in `_KEEP`), the bpy-free derived numbers the builder copies (`noise_placement`, `noise_detail`) and the
provisional constants. `ir.py` gets the leaves `Coordinates(source, channel, offset, tiling, angle)` and
`Noise(coords, size, phase, levels, low, high, kind)`, lengths in meters (`TexmapConverter(meters=...)`).
`build/materials/textures.py` draws it: Texture Coordinate Object -> Mapping (POINT) -> Noise Texture (FBM,
normalize, detail) -> (turbulence: MULTIPLY_ADD 2, -1 and ABSOLUTE) -> Map Range (low, high, clamp).

**Tech Stack:** Python 3.11, Blender 4.2 / 4.5 / 5.2 shader nodes, unittest.

## Probe (done, 2026-11-28, scratch script, three versions)

Socket identifiers identical on 4.2.23, 4.5.16, 5.2.0: Noise Texture inputs `Vector, W, Scale (5.0), Detail (2.0),
Roughness (0.5), Lacunarity (2.0), Offset, Gain, Distortion`, outputs `Fac` (named Factor on 5.2), `Color`;
`noise_dimensions` 1D..4D, `noise_type` (MULTIFRACTAL, RIDGED_MULTIFRACTAL, HYBRID_MULTIFRACTAL, FBM, HETERO_TERRAIN;
FBM default), `normalize` True. Map Range inputs `Value, From Min, From Max, To Min, To Max, Steps, ...`, output
`Result`, `clamp` True, `interpolation_type` LINEAR. Texture Coordinate output `Object`. Every input set explicitly.

## Decisions (bd notes)

- Lengths in meters in the IR: Noise.size = size x meters, Coordinates.offset = offset x meters (meters per file
  unit: `TexmapConverter(meters=)`, the pipeline's; None: the file's own unit, 0.0254 when it says none).
- Placement (not measured, maxdrop-o53.3.10): q = NOISE_SCALE R(angle) (tiling * (p - offset)) / size with p the
  Blender object coordinate in meters, angle in radians (as a UVGen's old ParamBlock), R as Blender's Mapping (XYZ
  Euler): Mapping POINT scale = NOISE_SCALE tiling / size, location = -R (NOISE_SCALE tiling * offset) / size.
  NOISE_SCALE = 1.0.
- Coordinate source: drawn as Object XYZ (the XYZGen's source is not decoded: maxdrop-o53.2.6 / o53.3.3), channel 1.
- Kind: 0 regular (detail 0: 3ds Max uses levels only for fractal and turbulence), 1 fractal (FBM, detail levels -
  1, clamped 0..15), 2 turbulence (the same FBM folded: |2 fac - 1|; Blender has no turbulence type). Another
  value: regular, an issue. Roughness 0.5, lacunarity 2, distortion 0, normalize on.
- Phase: 4D with W = phase when not 0, else 3D. A controller on size / phase reads its default (params.frame_zero).
- Thresholds: clamped to 0..1, high at least low + THRESHOLD_SPAN (1e-3); Map Range LINEAR, clamp.
- Size not finite or not above 0: 3ds Max's default 0.635 m (25 inches, whatever the file's unit), an issue
  (review: 25 file units was 25x too fine in a millimeter file). Coordinates' vectors: a Point3 of finite numbers, else
  the default.
- Gamma off: Noise in MASK_MIXES and DISPLAY_MIXES (computed on stored values, as a Falloff; not measured).
- Its Output part: `_own_output` (an Adjust when it changes anything), as a Falloff's.
- Bump input with black / white sides, no side map and no Output change: the Bump of the leaf itself; else the Mix.
  Normal map's normal slot: None and an issue, not counted (as a Checker).
- Counted in stats.approximated (walk.approximated), only when a graph is drawn; a lost side map peels (counted
  peeled instead, `_count` counts once).
