# Scene.object_stack follows 0x2033 Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A node whose stack holds a world-space modifier (a binding, superclass 0x820) arrives as its base
object's mesh, not as a placeholder: `Scene.object_stack` and `Scene.is_derived` follow the world-space derived
object (special id 0x2033) as they follow 0x2032.

**Architecture:** `reader/scene.py` keeps one set of derived ids (0x2032 and 0x2033, each only when the class
directory does not claim it); `reader/modifiers.py` asks `Scene.is_derived` instead of keeping its own rule, and
re-exports the three names `tools/census.py` imports. `convert/scene.py` needs no change: it takes the base and
the modifier names from `Scene.object_stack`. A new fixture `stack_wsm` (3ds Max 2020) pins it against the oracle.

**Tech Stack:** plain Python 3.11 (reader, tests), MAXScript (fixture), Blender 4.2 / 4.5 / 5.2 (smoke).

- `MapScaler` is the binding (`superclassOf` = SpacewarpModifier, class (0x0DADADA2, 0), superclass 0x820);
  `MapScalerOSM` is its object-space sibling.
- FixtureWSM (Editable Poly, UVW Map, Map Scaler): slot 1 = object 395, id 0x2033, references
  `[MapScaler, 394]`; 394 = 0x2032 `[UVW Map, Editable Poly]`. FixtureWSMOnly (Editable Poly, Map Scaler): slot
  1 = 0x2033 `[MapScaler, Editable Poly]`: a 0x2033 can reference the base object directly.
- A 0x2033 holds `0x2034`, `0x204B`, one `0x2500` per modifier slot (`0x2510` identity, `0x2511` the box,
  `0x2513` = `00 01 04 00`) and an empty `0x2501`, like a 0x2032.
- The binding keeps `0x39BF{0x0100: empty}` (name = class directory's, "MapScaler"); 3ds Max shows "Map Scaler
  Binding" (`m.name`, the oracle's `name`). Its references: `[-1, -1, a Map Scaler object]`.
- The oracle (layout 10, unchanged) writes `context_tm`, `context_bbox_min` and `context_bbox_max` as `null` for
  a world-space modifier: `getModContextTM` answers `undefined` for it. The modifiers are listed top first, the
  binding above the UVW Map.
- Red run with the fixture and no code change: 12 failures, 2 errors (scene/geometry/convert base = the 0x2033
  object; the tables keyed by fixture name; test_oracle's context lengths; test_classdir's id rule; test_census's
  derived-object count; test_modifiers' world_space/name/context checks).
