# Pack popup: long error lines on two labels Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Scene Pack panel puts the folder of its two error messages on a label of its own (Blender labels do not
wrap), the on-disk gate of the pre-flight read is covered by a test, and invoke() forgets a pack it cannot key.

**Architecture:** `prefs.pack_parent` raises a `ValueError` subclass that also carries the message as labels;
`ops._target` stores those labels as the pack's problem in `_TARGETS`; `ops.import_pack` draws them one per label, and
draws a "none" preview as "No free folder for <archive> in" + the parent folder (the parent the preview was asked
about: `archive.preview` raises its PackError only with that folder). `execute()` keeps the full one-line messages
(`str(e)` is unchanged). `invoke()` pops the `_TARGETS` entry when `_key()` fails.

**Tech Stack:** Blender Python (4.2 / 4.5 / 5.2), headless smoke tests.

Bead: maxdrop-em3.80
