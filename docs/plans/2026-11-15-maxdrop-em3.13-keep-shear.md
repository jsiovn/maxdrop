# Keep the shear of a node's local matrix Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A node whose local matrix has shear (a Bezier Scale along a rotated axis) gets the same world matrix in
Blender as in 3ds Max, with or without a parent.

**Architecture:** convert/scene.py flags such a node (`NodeDescription.sheared`, from `sheared(local)`) instead of
reporting it. build/objects.py sets `matrix_basis = L` as before; for a sheared node it reads back the basis
Blender kept (`B`, location / rotation / scale) and puts the residual `L @ B^-1` (computed in doubles) into
`matrix_parent_inverse`, so `world = parent world @ (L @ B^-1) @ B = parent world @ L`. Children use the node's
`matrix_world`, so they inherit the shear. A basis Blender cannot invert (a zero scale) falls back to basis
identity and parent inverse `L`.

A parentless object cannot hold shear (Blender ignores `matrix_parent_inverse` without a parent), so a sheared
top-level node is parented to one helper empty per build, `MaxDrop Shear`, at the identity, linked to the file's
collection. Why not bake the residual into the mesh: in corpus scene A 24 of the 26 sheared top-level nodes are
empties (placeholders), which have no mesh to bake into, and baking leaves the object's own `matrix_world` off
the oracle (the M1 gate compares world matrices) and gives each such node its own mesh copy. The helper keeps
instancing, keeps the world matrix exact and costs one object, made only when a file needs it. `Built.helpers`
lists it and `Built.roots()` yields every parentless object, so the operator's axis conversion turns the helper
too. Nothing is left that cannot be kept, so the issue "shear in the local matrix, not kept" goes away.

**Tech Stack:** plain-Python convert layer, Blender Python (bpy, mathutils, numpy) build layer.

**Measured before (2026-11-15, convert only):** scene A 83 sheared of 746 nodes (57 with a parent, all parents
empties; 26 top-level, 24 of them empties, none with children, no shared mesh); scene B 10 of 2,251 (8 with a
parent, 2 top-level meshes).
