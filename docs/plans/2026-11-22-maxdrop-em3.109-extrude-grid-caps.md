# Extrude grid caps Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Extrude with Cap Type Grid (parameter 4 = 1) gets the caps 3ds Max 2020 makes: the grid points 3ds Max
puts inside each cap, so the vertex and triangle counts equal 3ds Max's, instead of morph caps and a report line
(bead maxdrop-em3.109).

**Architecture:** `convert/extrude.py` gains a grid per solid (`_grid`): a regular grid over the solid's box, its cells
that lie wholly inside the solid (outline minus holes) become quads, and the band between those cells and the outline
is triangulated with the existing nesting (`_nest`) and ear clipping (`triangulate`). The grid points are extra
vertices of each cap level, after the side vertices. Guards fall back to a morph cap with a report line.

**Tech Stack:** Python + numpy (convert/, no bpy), MAXScript in 3ds Max 2020 for the probes and the fixture.

Bead: maxdrop-em3.109

---

## Facts (3ds Max 2020, `3dsmaxbatch`, `snapshotAsMesh`, 7 probe runs of about 60 shapes, outside the repo)

- **Per solid** (an outline with its holes, as the even-odd nesting gives; an island in a hole is a solid of its
  own, overlapping outlines are two solids): a grid over the box of the outline's interpolated points, W x H.
- **Divisions** per axis: N = 20, raised by each hole of the solid to floor(0.95 x W / (s / 2)), s the hole's extent
  on that axis (its interpolated points), at most 50; the outline itself, open splines, islands and other solids do
  not count. Per axis (a hole 10 x 0.7: N 20 across, 50 up); W per axis (60 x 20 with a 3 x 3 hole: 38 x 20). The
  computation is on the float32 values of the points: exact ratios fall either way by their float noise (a 2-wide
  hole at 2.3f .. 4.3f in a 40 box: 37.99999 -> 37; a 3-wide hole at 18.8f .. 21.8f in a 60 box: 38 -> 38).
- **Grid points**: x_i = x0 + 0.025 W + (0.95 W / N)(i + 0.001), i = 0 .. N; the same for y. Size-independent
  (30 x 20, 300 x 200, 3 x 2 all 21 x 21).
- **Cells**: a cell is filled when it lies wholly inside the solid: its four corners inside, no outline or hole edge
  crossing it (a slit between two grid columns drops the cells it crosses), no hole inside it (a hole smaller than a
  cell drops its cell; a hole across a cell edge drops both cells). The cap's interior vertices are exactly the
  corners of the filled cells (a grid point inside the cap but in no filled cell is dropped: a triangle's apex).
  Each filled cell is two triangles, the diagonal from its top-left to its bottom-right corner.
- **Counts**: per cap of n outline and hole points, k grid points and h holes, n + 2k + 2h - 2 triangles (any
  triangulation of that vertex set gives it): Rect 30 x 20: 4 + 882 - 2 = 884 per cap, 890 vertices, 1776 faces.
  Only the caps that exist get grid points (Cap Start only: 449 vertices). A solid without a filled cell gets the
  morph cap (a thin diagonal band: 8 vertices, 12 faces).
- **Interior edges** are all hidden: 3ds Max shows the cap as one polygon. Smoothing group 16, material IDs 1 / 2 as
  on morph caps; the cap's map is the same planar box mapping (grid point u = 0.02505 on a 30-wide box).
- **Z**: the grid points lie at z 0 and z amount (each level: amount x level / segments), whatever the shape's z: a
  rectangle at z 3 gets its outline at 3 and 5, its grid at 0 and 2 (3ds Max's own; MaxDrop does the same).
- No local scene has grid caps (2026-11-21: 443 scenes, 95 Extrudes).

## Design decisions

- Grid only for `cap_type == 1`; any other value is a morph cap (unchanged).
- Inside test per grid row: the x crossings of every loop edge with the row (numpy), even-odd by `searchsorted`.
  Cells crossed: for each loop edge, the cells its box covers, clipped against the segment (Liang-Barsky, numpy).
- Band: the boundary loops of the filled cells (directed so the band is on the left, turning right at a vertex where
  two cells touch only at a corner: each loop hugs its cells), nested with the outline and holes by `_nest`; each
  band region is triangulated with `triangulate` (the shared clip budget). Cells are quads (two triangles in the
  counts, as 3ds Max).
- Guards, each a morph cap and one issue line: a solid with more than MAX_CAP_POINTS outline and hole points; the
  grid work (point-edge and cell-edge tests) past MAX_GRID_TESTS for the mesh; grid vertices that would take the mesh
  past MAX_VERTICES; a band that cannot be triangulated (CapError). The report line `grid caps are made as morph
  caps` goes.
