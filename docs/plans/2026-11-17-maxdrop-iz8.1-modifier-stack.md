# Modifier stack reader Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read, for every node, the modifiers of its stack (class, name, flags, parameter blocks, modifier context)
bottom first down to the base object, count them in the census, and report modifiers by outcome.

**Architecture:** `maxdrop/reader/modifiers.py` (no bpy) walks derived objects (`0x2032`, and the world-space
`0x2033`) from a node's object reference, pairs each modifier reference with its `0x2500` context, reads the
modifier's `0x39BF` (name, flag chunks) and its parameter blocks through `pblock.py`. `tools/census.py` gains a
modifier table read through it; `convert/report.py` keeps its modifier counter as "ignored" and gains "applied"
and "converted to a Blender modifier" counters (empty until the next beads). Oracle layout 3 adds each modifier's
context and flags.

**Tech Stack:** Python 3.11 syntax, standard library, unittest; 3ds Max 2020 via 3dsmax-mcp for the fixture and
the oracle.

## Facts found while planning (stack_basic, modifier_pivot, a scratch WSM probe, corpus scenes A and B)

- Derived object `0x2032{0x2034 refs, 0x204B, 0x2500 per modifier slot, 0x2501, 0x2502?}`: refs = modifiers top
  first, then the base (another derived object for a reference: FixtureNestedRef -> FixtureNested's).
- `0x2500{0x2510: 12 x f32 matrix rows + u32 Matrix3 flags (7 identity, 6 translated), 0x2511: 6 x f32 box
  min, max (+1e30 .. -1e30 = not computed), 0x2512 (corpus only, not read), 0x2513: 4 bytes unknown}`, the k-th
  `0x2500` belongs to reference slot k (counts equal in every file seen).
- Modifier `0x39BF{0x0100: UTF-16 name (empty = the class name), 0x0110: present = off, 0x0120: off in
  viewport, 0x0130: off in renderer}` (stack_basic FixtureFlags, against the oracle).
- An instanced modifier (FixtureSharedA/B): one modifier object in two derived objects, each with its own
  context (translations (-10, 0, -10) and (10, 0, -10), one box -15..15).
- World-space modifier (scratch probe, not committed): node slot 1 -> `0x2033` refs [Map Scaler (superclass
  0x820), the 0x2032 derived object]. `Scene.object_stack` does not follow 0x2033: debt bead.
- Parameter blocks: Bend, TurboSmooth ParamBlock2; UVW Map, Taper, Twist, Noise the old ParamBlock. Gizmo:
  reference of superclass 0x9008.
