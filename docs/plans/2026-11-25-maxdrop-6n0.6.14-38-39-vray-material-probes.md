# Diffuse Level gamma on, Color Correction saturation, Fresnel-off metalness Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** settle three measured rules in one cycle: the Standard Diffuse Level product with the gamma on
(maxdrop-6n0.6.14), a Color Correction's saturation above 0 % (maxdrop-6n0.6.38) and a VRayMtl with Fresnel off and
a metalness above 0 (maxdrop-6n0.6.39).

**Architecture:** .14 is docs only (the measured product is what MaxDrop already draws). .38 adds a lower clamp at 0
to the builder's HSL saturation step when the factor is above 1 (`build/materials.py` `saturate`). .39 is convert only
(`convert/materials.py` `vray_mtl`): outside the Fresnel-off metal rule a constant metalness scales the diffuse by
(1 - metalness) and the material keeps Metallic 0, so build's existing mirror drawing gives V-Ray's law.

**Tech Stack:** 3ds Max 2020 (3dsmaxbatch: Default Scanline, V-Ray 5.2), Python 3.11 unittest, Blender 4.2.23 /
4.5.16 / 5.2 headless.

### .14: Diffuse Level with the gamma on (Default Scanline, gamma 2.2, files in 2.2)

255; color 200 100 50), center pixel read linear. Same numbers on the four shaders. A swatch is its stored value
(reference 0.392 0.235 0.117 = 100 60 30 / 255), a Checker grey 128 level map 0.502 (as with the gamma off), the PNG
grey 128 level map 0.2192 (= (128 / 255)^2.2: the image is decoded), grey 64 PNG 0.0470, a 128 PNG at amount 50 and
level 50 0.3594 (lerp(0.5, 0.2195, 0.5)), the color PNG as a level map 0.2470 (the mean of its decoded channels);
a grey 128 PNG diffuse map at level 50 0.1096 (0.2195 x 0.5), the color PNG at level 80 0.4685 0.1019 0.0219
(decoded x 0.8), color PNG diffuse at 50 % with grey 128 PNG level map at 50 % and level 50 0.1757 0.0651 0.0259,
level 40 with the color PNG at 61 % and grey 64 at 62 % 0.0925 0.0307 0.0113. Every case is lerp(swatch, diffuse
map, Ad) x lerp(level, mean(level map), Al) on linear values (swatches as stored, images decoded): what MaxDrop
draws with the gamma on (level as is, the level map a MASK graph, an image decoded). No code change.

### .38: Color Correction saturation and hue (V-Ray 5.2, VRayLightMtl planes, gamma on, internal values)

Six VRayColor inputs (200 100 50, 230 128 26, 40 80 200, grey 128, 250 20 120, 20 200 120) and the color PNG;
saturation -100 / -50 / +50 / +100, hue 30 / 120, hue 30 with saturation +50. Every value is lerp(L, c, 1 + s),
L = (max + min) / 2, after the hue shift (HSV hue rotation, which keeps max and min), and a channel below 0 is 0;
above 1 the readout clamps (getPixels reads a VRayColor 0.6 at multiplier 2 as 1.0), so `cc2.ms` halves the light
(200 100 50 at +100: 0.539 = 1.078 / 2, not clamped) and mixes with white (0.5: the low channel was 0, not -0.098),
and `cc3.ms` checks the controls: a Mix keeps a negative input (Output offset -0.5 over 0.2 mixed with white 0.35),
an Output offset +0.2 over the correction gives 0.2 on the low channel (the correction gave 0). Today's builder
(maxdrop-6n0.6.18's HSL step) renders every row within 0.0005 of V-Ray (EEVEE 5.2, `cc_render.py`), except the 9
rows with a channel above 1 (the readout clamp: ours is V-Ray's internal value) or below 0 (EEVEE shows a negative
emission as 0; in a graph it would carry). The PNG rows differ by the decode (sRGB against 2.2, at most 0.014).

## Decisions

- .14: docs only: docs/FORMAT.md's "gamma on not rendered: assumed the same product on linear values" replaced in
  place by the numbers; the plan's numbers are the close note's.
- .38: `saturate(v, s)` adds Vector Math MAXIMUM (0, 0, 0) after the lerp when s > 1 (a factor up to 1 cannot leave
  0..1 on inputs in 0..1, so its graphs stay as they are); no upper clamp (measured). The hue step is unchanged
  (measured equal). The convert side is unchanged: a Color Correction in a mask already takes the color
  (maxdrop-6n0.6.18), so the case the bead notes name is settled.
- .39: in `vray_mtl`, Fresnel off, outside the metal rule (a reflection map with a bright share, or a channel of 1
  or more), not refracting (transmission 0), with no metalness map: ir.metallic = 0 and the base color's value
  times k = 1 - m, its map's `MapRef.scale` k (the map dropped at m = 1: black). k goes through the swatch rule as
  em3.150's level does (gamma off: `srgb_to_linear(k)`; not rendered with the gamma off). build's mirror then gives
  w x mirror + (1 - w) x k d: exact for a grey swatch, a black diffuse and m = 1; a colored swatch keeps the known
  tinted-mirror gap (metal05 M3: 0.9097 0.5174 0.1404 against 0.9097 0.5801 0.4541). Left as today: the metal rule,
  a metalness map, a refracting material (not measured).
