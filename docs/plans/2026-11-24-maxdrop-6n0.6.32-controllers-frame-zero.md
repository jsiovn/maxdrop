# Controllers at frame 0: report lines, old blocks, dome, LookAt weight list, Output map1 Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bead maxdrop-6n0.6.32 (merged from 6n0.6.17, 6n0.6.15, 6n0.6.3): a LookAt weight held by a Float List
with no readable entry takes the 50 fallback; a material or map parameter read through a controller gives its
issues to the import report and marks the texture graph approximated; an animated Coordinates / Output parameter
(old ParamBlock) and the dome's VRayBitmap rotation resolve at frame 0; an Output map's map1 in a block without
0x0013 is read from owner slot 0.

**Architecture:** Reader: `_Eval._scalar` (Float List) returns None to a caller that asked for no value when no
entry gives one; `ParamBlock` (old) records which entries a controller holds and their reference slot;
`owner_slots.OUTPUT_MAP` gains pid 0. Convert: `params.frame_zero` / `FrameZero` / `FrameZeroGraph` take a
`report(owner index, line)` callback; the converters pass theirs (materials: once per owner and line; texmaps: into
the current walk, approximated); `params.old_value` resolves an old block's controller; `lights.dome_texture`
wraps its graph with its own report.

**Tech Stack:** Python 3.11 syntax, plain unittest, headless Blender 4.2 / 4.5 / 5.2.

  shader blocks): the entry holds `0x0003` index, `0x0004` (animatable: also on entries that are not animated)
  and a value chunk `0x0200 + type` with an empty payload (no value), instead of `0x0100 + type`. The block's own
  references (0x2034, position = slot) hold the controllers in index order of the animated entries only: Noise's

- No fixture animates a UVGen or TexOutput: the Coordinates / Output case is synthetic (as the bead allows).

  is in `_Eval.unknown`. A Float List of only unknown entries reads 0 today (sum of `scalar(entry, 0.0)`).
- ops builds one MaterialGraph; MaterialConverter and TexmapConverter each wrap it (`at_frame_zero`), so each
  can have its own report. `ops._dome_texture` hands the raw graph to `lights.dome_texture`.
- Report: `report.py` lists `conv.stats.issues` and `tex.stats.issues` as `("object %d", reason)`.
