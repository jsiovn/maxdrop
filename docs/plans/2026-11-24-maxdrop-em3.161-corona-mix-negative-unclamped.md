# CoronaMix: negative layers in sRGB mode, unclamped dodge, burn, exclusion Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CoronaMix in sRGB mode takes the magnitude of each layer before its 1 / 2.2 power, as Corona does, and
color dodge, color burn and exclusion over maps follow Corona's unclamped formulas instead of Blender's Mix types.

**Architecture:** convert/texmaps.py `blend_value` (two constants) raises abs(layer) in sRGB mode; the CoronaMix gamma
operation takes the magnitude of its top exponent and of a constant bottom. build/materials.py `arith` puts a Vector
Math ABSOLUTE before each map side's Gamma node (a constant side: abs in Python) and draws dodge, burn and exclusion
with Vector Math nodes. Bead: maxdrop-em3.161. Code only: the em3.117 probe numbers are the reference.

**Tech Stack:** Python 3.11, Blender shader nodes (4.2 to 5.2).

## Node forms (build)

Vector Math DIVIDE is a safe divide (0 where the divisor is 0), MULTIPLY_ADD is A x B + C.

- K(x, d) = MAXIMUM(SUBTRACT(nz, DIVIDE(x, d)), 0), nz = CEIL(MINIMUM(ABSOLUTE(d), 1)) (1 where d != 0, 0 at d = 0):
  K = max(0, 1 - x / d) for d != 0, 0 at d = 0. Six nodes.
- burn(a, b) = K(1 - a, b): max(0, 1 - (1 - a) / b), 0 at b = 0 (Corona's). 1 - a by MULTIPLY_ADD(a, -1, 1). 7 nodes.
- dodge(a, b) = 1 - K(a, 1 - b): min(1, a / (1 - b)), 1 at b = 1 (Corona's; also black under white, which Blender's
  DODGE leaves at 0). 8 nodes.
- exclusion(a, b) = MULTIPLY_ADD(b, MULTIPLY_ADD(a, -2, 1), a) = a + b - 2ab. 2 nodes.
- Burn is never below 0: joins NON_NEGATIVE_BLENDS (no closing ABSOLUTE).

Cost accepted: dodge and burn over a map are rare, 7 to 8 cheap Vector Math nodes, and the exact form also fixes the
in-range black-under-white dodge. sRGB mode: one ABSOLUTE per map side (a constant side: abs folded in Python).
