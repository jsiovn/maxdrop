# Standard shaders: Diffuse Level and per-shader defaults Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Standard rule scales the diffuse swatch by the Diffuse Level of Anisotropic, Multi-Layer,
Oren-Nayar-Blinn and Translucent Shader, and falls back to each shader's own defaults for a missing or animated
diffuse, glossiness or specular level.

**Architecture:** `convert/materials.py` only: a `diffuse_level` id in `ShaderIds` (None for Phong, Blinn, Metal), a
`SHADER_DEFAULTS` table beside `SHADERS` (Strauss included), `MaterialConverter.rgb` gains a `scale` applied to the
stored swatch before the swatch rule. Fixture `standard_shaders` gets four materials appended after its last node.

**Tech Stack:** plain Python (convert/, unittest), MAXScript fixture (3ds Max 2020), Blender 4.2 / 4.5 / 5.2 smoke.

---

## Measured (3ds Max 2020, Default Scanline, gamma off; probe scenes outside the repo)

- A plane lit head-on, swatch (200, 100, 50): the pixel scales linearly with the Diffuse Level on all four shaders
  (50 % half, 25 % at light 1.0 = 50 % at light 0.5, 200 % exactly double: the product is not clamped). Blinn
  ignores the property.
- Self-illumination amount 100 % (light off): the pixel is the unscaled swatch at level 50 and 100; at 50 % amount
  the mix is 0.5 x unscaled diffuse + 0.5 x lit (scaled) part. So emission keeps the unscaled diffuse.
- A diffuse map (flat Checker) at amount 100 or 50: the level scales the mapped diffuse too. MaxDrop's `Input` has no
  multiplier for a map: a mapped diffuse is not scaled (debt bead under maxdrop-em3, with the unread Diffuse Level
  map channel).
- Defaults of a fresh material: diffuse 127.5 grey (Anisotropic, Multi-Layer, Oren-Nayar-Blinn, Translucent,
  Strauss), 149.94 (Blinn, Phong, Metal); glossiness 25 / 50 / 25 / 30 / 20 / 10 %; specular level 5 % (Anisotropic,
  Multi-Layer), 0 otherwise; Diffuse Level 100 %.
- The value is stored as a fraction (oracle: 1 for 100 %).
- Order: the gamma-off internal value v is `srgb_to_linear(v)` in Blender (docs/FORMAT.md, gamma), the shader's
  internal diffuse is swatch x level, so the level applies to the stored swatch and the swatch rule (which clamps
  to 0..1) after it. Opposite of CoronaLegacyMtl / Physical, which multiply after the rule (different renderers).
