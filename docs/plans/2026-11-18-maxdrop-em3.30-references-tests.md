# Two-phase unpack tests (external tools, smoke import) Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CI covers `archive.unpack(references=...)` through UnRAR / 7-Zip / bsdtar and through the operator's
`_referenced_maps`, so a regression in external.py's second `extract()` call or in the operator's filter fails a test.

**Architecture:** Tests only (bead `maxdrop-em3.30`, Files: `tests/test_intake_external.py`,
`tests/smoke_import.py`). No product code changes.

**Tech Stack:** Python 3.11 unittest, Blender headless smoke.

---

### Task 1: real-tool references test (`tests/test_intake_external.py`, `RealToolTests`)

- [ ] `test_references_unpack_only_the_named_maps`: for each pack (`normal.rar`, `solid.rar`, `plain.7z`) and each
  available tool of `CASES` (SKIPPED line per missing tool, RAN per case), `archive.unpack(pack,
  references=refs)` where `refs(max_path)` records the path, checks it is the staged scene (bytes
  `MAXDROP TEST SCENE`, inside the pack's folder, not the final folder) and returns `["wood.jpg"]`.
- Expect: folder files `{scene.max, wood.jpg: b"near wood"}`; `unwanted == 2` (`my map.png`, `light.IES`);
  `collided == ["pack/other/wood.jpg"]`; `written == 2`; `backend == tool.label` (one label for both phases);
  marker `wanted == ["wood.jpg"]`; `refs` called once; case folder holds only the pack and its unpack folder.

### Task 2: cumulative watcher test (`StandInTests`)

- [ ] `test_watcher_counts_the_scene_phase`: Python stands in for UnRAR. Phase 1 (list file names `scene.max`)
  writes 700 KiB `scene.max` and exits; phase 2 writes 700 KiB `wood.jpg`, flushes and sleeps 60 s. Declared sizes
  are 3 bytes, so `_check_space` passes; `Limits(total_bytes=1 MiB, free_margin=0)`: each phase alone is under the
  limit, the sum is over it. Expect `PackError "unpacks to more than"` within 10 s (only a watcher seeded from the
  budget stops phase 2 before its 60 s sleep ends), `refs` called (phase 1 passed), nothing left beside the pack.
- [ ] Red check: temporarily seed the watcher with `0, 0` instead of `budget.files, budget.total` and see the test
  fail (time over 10 s), then restore.

### Task 3: smoke import (`tests/smoke_import.py`, `as_pack`)

- [ ] Add one image the scene does not use (`maxdrop_smoke_unused.png`, a few bytes, written into the scratch
  folder) to every generated zip. `as_pack` gets `ops`; when `ops._referenced_maps(max_path)` is not None:
  check the unused image is not in the pack folder and the report text holds
  `"  Files the scene does not use, left out: N"`, N = the zip's image/.ies entries whose `name_key` is not among
  the referenced names (1 for every fixture: they carry no images). When it is None, print that the check is
  skipped (a corpus file without an asset list).
- [ ] Update the module docstring.
