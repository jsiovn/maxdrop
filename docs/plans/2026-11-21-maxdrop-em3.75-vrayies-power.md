## Measurement (done before the plan, scratch scene outside the repo)

The calibration setup of FORMAT.md "Power, measured" (white VRayMtl floor, VRayIES 1 m above, V-Ray 5.2 linear,
gamma 1, no GI, mean of the 8 x 8 center pixels; pixel = lx / 1500). Isotropic LM-63 files of 100 cd (integrated
flux 1256.6 lm), the header's rated lumens 1256.6, 500 and -1 (absolute):

| file header | override | power (stored, param 10) | pixel | reads as |
|---|---|---|---|---|
| 1256.6 | off | 1256.6 (set on load) | 0.06669 | 100 cd |
| 1256.6 | off | 1000 | 0.05307 | 1000 lm |
| 500 | off | 500 (set on load) | 0.06669 | 100 cd = file |
| 500 | off | 1000 | 0.1334 | 200 cd = file x 1000 / 500 |
| -1 | off | 1256.64 (set on load: the integral) | 0.06669 | 100 cd |
| -1 | off | 1000 | 0.05307 | 1000 lm |
| any | off or on | 0 | 0.0 | dark |
| 500 | on, lm | 1000 | 0.05307 | 1000 lm (true flux) |
| 500 | on, cd 100 | 500 (panel: cd x header / peak) | 0.02654 | 500 lm (true flux) |
| 1256.6 | on, cd 100 | 1256.6 (saved: param 10 = 1256.6) | 0.06669 | 100 cd |

Findings:

1. Override off: V-Ray scales the file's candelas by power / the file's rated lumens. Power is the flux only when
   the rated lumens are the file's flux (or -1). The file is not read: a report line says so.
2. Power 0 renders dark (override on or off): IES_ZERO's "V-Ray takes the IES file's own intensity" is wrong; 0 W
   stays, the line's text changes.
3. Override on: param 10 is the flux in lumens in both intensity types (the panel converts cd to lm with the
   file); the code's 4 pi factor for the cd type is wrong. The fixture's IesOverride (a file never loaded) stored
   300, which V-Ray's panel converts with a ratio of 1.
