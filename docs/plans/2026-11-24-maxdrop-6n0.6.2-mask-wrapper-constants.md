# A color wrapper in a mask tints the color, not its grey Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** in a MASK graph (a Mix, CoronaMix or Composite mask in a color graph) an RGB Tint or an Output that changes
anything acts on the color below it, and the mask is the mean of the result, decoded with the gamma off, as V-Ray 5.2
renders it (bead maxdrop-6n0.6.2).

**Architecture:** convert side only (`maxdrop/convert/texmaps.py`). A Tint's or Output's input in MASK is converted
in COLOR with the gamma on (linear = what V-Ray holds) and in STORED with it off (swatches, rows and a Bitmap as
stored), and with the gamma off the wrapper's node goes under `Decode(Tint(node, MEAN_ROWS))`: the mean first (a Tint
of rows 1/3, as `_leveled` uses), then the display decode. A Tint over a Constant is folded exactly to
`Constant(swatches.channel(mean))`. No builder change: Decode and Tint are drawn as today.

**Tech Stack:** 3ds Max 2020 + V-Ray 5.2 (`3dsmaxbatch`, scratch MAXScript), Python 3.11 `unittest`, Blender 4.2.23 /
4.5.16 / 5.2 headless.

## Decisions

- Decoded channels and rows (a MASK_RGB of decoded values) give 0.044 for TintDV against 0.0251: worse than today.
  Stored, mean, then decode is exact: chosen.
- Color Correction stays as it is in MASK (its input the rule of the mean, a grey): V-Ray's saturation is not the
  builder's HSV Hue/Saturation (CCSat over a colored constant would draw about 0.62 against 0.474; CCSatCBm already
  draws 0.41 against 0.28). Debt bead.
- `_mask_input(conv, kind)`: MASK -> COLOR with the gamma on, STORED with it off; else `rgb_kind(kind)`. `_rgb_tint`
  (rows: COLOR in COLOR, else that kind) and `_output_map` use it.
- `_mask_mean(conv, node, kind)`: MASK with the gamma off -> a Tint over a Constant folded to
  `Constant(swatches.channel(mean of the tinted color))`, else `Decode(Tint(node, *MEAN_ROWS))`; otherwise the node.
- An image below such a wrapper in a mask gets its RGB output (a color), not the mono one (not measured, as em3.128).
- Out of scope, filed P4 tech-debt in maxdrop-6n0.6: a colored image as a gamma-off mask (RefCBm 0.2456 against
  0.1768: mean of decoded, not decoded mean); an RGB Tint (and Output) at a gamma-off color root (TintXVE r/g/b
  0.334 / 0.057 / 0.048 against 0.365 / 0.122 / 0.100); Color Correction's saturation against V-Ray's.
