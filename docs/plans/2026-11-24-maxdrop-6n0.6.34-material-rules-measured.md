### Task 3 (6n0.6.6): CoronaLegacyMtl levels scale the maps in their slots

The diffuse (121), reflection (122), refraction (123) and opacity (127) levels multiply the map in the slot as
well as the color (Corona's documentation): the slot's MapRef gets `scale = level` (`dataclasses.replace`, as
Standard's Diffuse Level; `texmaps._slot` already multiplies the map before the amount mixes it with the swatch,
which carries the level: level x lerp(color, map, amount)). Linear, as the swatch side (the level applies after
`conv.rgb`). A level of 0 leaves no map (`None`: Corona renders the slot black / nothing, no zero-weight graph).
Level 1: the MapRef unchanged. The metal branch (Fresnel IOR >= 10) reuses the scaled reflection MapRef as the
base color map. Self-illumination (128) already scales its map as the emission strength.

Tests first: level 0.5 with a diffuse, reflection, refraction, opacity map -> each MapRef's scale 0.5, amount kept;
level 1 -> scale 1; level 0 -> map None; metal branch base color map scaled; levelReflect missing (0) with a
reflection map -> no map. matparity (scenes A and B, local) checked before (A 214/214, B 220/220) and after: it runs

### Task 5 (6n0.6.16): VRayMtl Fresnel off, colored reflection as a tinted mirror copy

**Files:** `maxdrop/convert/materials.py` (MaterialIR.mirror_color, vray_mtl, NEUTRAL_REFLECTION removed, module
docstring), `maxdrop/build/materials.py` (reflection_weight + docstring + module docstring), `tests/blender/run.py`
(check_mirror, _weight_mix, check_specular's call, check_builder_fresnel_off rows),
`tests/unit/test_convert_materials.py` (VRayMtlRules, VRayBasic), `docs/SUPPORT.md` VRayMtl row (in place),
`CHANGELOG.md` (one Fixed line).

Rule in vray_mtl, Fresnel off, the swatch's shown share >= METAL_REFLECTION:
- no reflection map and max(R) < 1: the mirror drawing with weight max(R) (`ir.specular = Input(max R)`) and
  `ir.mirror_color = R / max(R)`: R_c + (1 - max R) d_c per channel, between the metal and V-Ray's R_c + (1 - R_c)
  d_c in every channel, equal to the white mirror for grey (no cliff: NEUTRAL_REFLECTION and the grey predicate
  go), equal to the metal for a black diffuse; at max(R) = 1 it equals the metal.
- otherwise (a reflection map that shows the swatch, or max(R) >= 1): the metal in the reflection color, as now.
- below METAL_REFLECTION: as now (white mirror, the mean as weight). The C3 numbers decide it: a dim colored swatch
  (102 51 13 over grey) is closer white (max error 0.09) than tinted (0.175).
- review leftover (1): a reflection map at 0 % amount is dropped (`reflection_map = None`): the swatch alone, as
  V-Ray renders it and as the map switched off; no MapRef left in `ir.specular`, so build never takes the twin.
- review leftover (2): a constant metalness 1 keeps em3.153's drawing for grey and now for colored too (build's
  specular() draws the lone metal in the diffuse color); unmeasured against V-Ray: a P4 tech-debt child of
  maxdrop-6n0.6 (needs a V-Ray render: the code lane may not). Pinned by a unit case.

Build: `reflection_weight(bsdf, weight, mirror=False, color=WHITE)`: the copy's Base Color is `color + (1,)`
(MIRROR_INPUTS stays the white default; `fill` passes `ir.mirror_color` when the mirror is drawn). The copy is
the only change; refracting glass keeps its refraction twin under it.

Tests (red first): unit — `test_fresnel_off_colored_reflection_is_a_tinted_mirror` (C2-like 0.9 0.5 0.1: specular
0.9, mirror color (1, 0.556, 0.111), metallic unchanged, base the diffuse; C6-like; near grey 0.509 0.5 0.491: weight
0.509), `test_fresnel_off_full_or_colored_reflection_is_metal` renamed / narrowed (max >= 1: metal; a colored swatch
below METAL_REFLECTION: neither), `test_fresnel_off_grey_reflection_keeps_diffuse` (weight max), the map at 0 %,
metalness 1 colored, VRayBasic (FixtureVRay 151 162 173: specular 0.417885, mirror color R / 0.417885, base color
the glass mix of diffuse, metallic the stored metalness). Blender — `check_mirror` compares the copy's Base Color
