# Fixture for hidden, frozen, non-rendering and nested layers Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A committed fixture, `layers_more`, shows the layer and node flags docs/FORMAT.md lists under Open, and
the reader's layer code is checked against its 3ds Max oracle instead of scratch saves.

**Architecture:** `tools/fixtures/layers_more.ms` saves seven layers (`0`, a hidden, a frozen, a non-rendering
layer, FixtureParentLayer without a node and its child FixtureChildLayer set with `setParent`, a layer named
`FixtureLäyer中`) and eight Editable Poly boxes (one per layer that holds one, a frozen node, a hidden
parent with a visible child). The oracle gets layout version 7: each layer's `parent` (the parent layer's name,
`null` at the top), and the node `hidden` / `frozen` become what docs/ORACLE.md already says they are, the node's
own flags. A probe showed MAXScript's `isHidden` / `isFrozen` also answer true for a node on a hidden or frozen
layer (`renderable` does not); the SDK's `INode.IsObjectHidden` / `IsObjectFrozen` give the node's own flag (the
file's `0x0960` bits). Every committed oracle is regenerated.

**Tech Stack:** MAXScript (3ds Max 2020: an own `3dsmax.exe -q -silent -U MAXScript` for the save,
`3dsmaxbatch.exe` for the oracle), plain Python `unittest`, Blender 4.2 / 4.5 / 5.2 headless.

Bead: maxdrop-em3.15

## Facts measured (3ds Max 2020, probes outside the repo)

- Reader on the sanitized save: node `0x0960` flags `0x800` on the nodes of the hidden, frozen and non-rendering
  layers (no `0x0975` / `0x0976`), `0x200800` + empty `0x0976` on FixtureFrozen, `0x100800` + empty `0x0975` on
  FixtureHiddenParent, `0x800` on its visible child; `0x099C` `0x0F00D600` on every node.
- Layers: `0x1020` `0x100000` (hidden layer), `0x200000` (frozen layer), `0x1050` `0x0B005600` (non-rendering
  layer, `0x0B00D600` elsewhere); FixtureChildLayer `0x1090` = `01`, `0x10A0` = `FixtureParentLayer` UTF-16LE,
  `0x10B0` = `0x236` = FixtureParentLayer's object index; the text layer's `0x1010` is
  `46 69 78 74 75 72 65 4c c3 a4 79 65 72 e4 b8 ad` (UTF-8).
- MAXScript: `isHidden` true on FixtureOnHiddenLayer, `isFrozen` true on FixtureOnFrozenLayer, `renderable` true
  on FixtureOnNoRenderLayer. SDK: `IsObjectHidden` / `IsObjectFrozen` true only on FixtureHiddenParent /
  FixtureFrozen; `IsNodeHidden` and `IsFrozen` include the layer.
