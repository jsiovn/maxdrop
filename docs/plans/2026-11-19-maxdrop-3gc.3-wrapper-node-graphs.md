# Node graphs for the remaining map wrappers Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The wrapper maps that are still peeled to their first bitmap (Falloff, Composite with blend modes or
masks, Output, RGB Tint) and the Color Correction channel rewiring become node graphs, in census order.

**Architecture:** `convert/texmaps.py` gets the rules and three IR nodes (`Facing`, `Adjust`, `Tint`), a
`CompositeLayer` with blend mode and mask, and a `rewire` field on `ColorCorrect`; `build/materials.py` draws them
(Layer Weight / Fresnel / Geometry, Mix blend types, Separate / Combine Color, Vector Math). A mode the rules do not
handle falls back to the M2 peel and is counted. One new fixture, `texmap_wrappers`, authored in 3ds Max 2020.

**Tech Stack:** Python 3.11 syntax, standard library, `unittest`; 3ds Max 2020 + V-Ray 5.2 (`3dsmaxbatch` probes
and fixture, local only); Blender 4.2 / 4.5 / 5.2 headless.

## Facts measured (3ds Max 2020, `3dsmaxbatch`, probes outside the repo)

- **Composite** (renderMap of two constant layers, bottom (.3 .5 .8), top (.6 .2 .4), values linear as swatches
  are): result = lerp(bottom, blend(bottom, top), opacity x mask), clamped to 0..1 at the end; the bottom layer is
  over transparent black whatever its mode (lerp(0, layer, opacity)); a mask's weight is the mean of its color.
  Modes: 0 normal, 1 average, 2 addition, 3 subtract, 4 darken, 5 multiply, 6 color burn (1 - (1 - b) / t),
  7 linear burn, 8 lighten, 9 screen, 10 color dodge (b / (1 - t)), 11 linear dodge (add, clamped before the
  opacity), 12 spotlight (2 b t), 13 spotlight blend (b + b t), 14 overlay (on the bottom), 15 soft light
  (Photoshop's, not Blender's), 16 hard light (overlay on the top), 17 pin light, 18 hard mix, 19 difference,
  20 exclusion, 21 hue, 22 saturation, 23 color, 24 value (HSV, as Blender's). Blender's own factor is not a
  plain lerp for burn / dodge: the blend is drawn at factor 1, then a Mix by the opacity.
  Handled: all but 7, 15, 17, 18 (none in the corpus): those peel the Composite as before.
- **Falloff** (render of a sphere, viewing direction, ortho-like camera): type 1 = 1 - |N.V| (Blender Layer
  Weight Facing at blend 0.5, exact to 1e-3); type 0 = half of that, (1 - N.V) / 2; type 2 = dielectric Fresnel
  of the IOR within 0.025 (3ds Max darker facing the camera: 0.028 vs 0.053 at 1.6, equal at grazing). Side k =
  lerp(color k, map k, amount k) when map k is used (white map, amount 50 over black: 0.499). The mix curve
  (MixCurve) is not read: drawn linear (a debt bead). Types 3, 4 and directions other than 0 peel as before.
- **Color Correction:** rewire codes per channel 0 R, 1 G, 2 B, 3 A, 4..7 their inverse, 8 monochrome (the mean of
  R, G, B), 9 one, 10 zero; mode 1 stores (8, 8, 8, 3), mode 2 (4, 5, 6, 3), mode 3 the channels set. Rewiring
  comes before hue, saturation and brightness. Param ids 3..6 rewireR..A, 14 exposureMode, 15..17 enableR..B.
- **RGB Tint:** out = R x red + G x green + B x blue (a 3 x 3 matrix); defaults are the identity.
- **Output (TexOutput):** level x c + offset, then x amount (amount also scales alpha); inverted: level x (1 - c)
  - offset (the builder had + offset: fixed, it is the same part on a Bitmap). Clamp changed nothing in renderMap.

## Chunk 1: code and unit tests

### Task 1: IR nodes (texmaps.py)

- [ ] `Facing(mode, ior)`: mode `PERPENDICULAR`, `TOWARDS`, `FRESNEL`; a leaf (0 facing, 1 grazing / away).
- [ ] `Adjust(input, output: TexOutput)`; `Tint(input, red, green, blue)` (linear RGB constants).
- [ ] `CompositeLayer(node, opacity=1.0, blend=0, mask=None)`; `Composite.layers` holds them.
- [ ] `ColorCorrect.rewire = (0, 1, 2)`.
- [ ] `_children` for all of them.

### Task 2: rules (texmaps.py), tests first in tests/unit/test_texmaps.py

- [ ] Falloff -> `_KEEP`: type 0 / 1 / 2 with direction 0: `Mix(side1, side2, 0, mask=Facing)`, side k = its map,
  `Mix(Constant(color k), map, amount)` below 100, or its color without a map; Fresnel IOR from 12 (override 11
  off: an issue, 12 kept); its own Output part as `Adjust` when it changes anything. A used map that is lost:
  the other side's map (peeled, counted) or nothing. Other type or direction: the old peel, counted, an issue.
- [ ] Composite: masks (on, set) as `CompositeLayer.mask` (DATA; lost: approximated, left out); modes above; a
  layer in 7, 15, 17, 18 or unknown: the whole map peeled (counted, as before).
- [ ] Color Correction: rewire from the mode (3: params 3..5, each 0..10 else identity and an issue; alpha codes
  3 / 7 drawn as one / zero, an issue). Tint strength stays an issue.
- [ ] Output -> `_KEEP`: `Adjust(map, its Output)` (no Adjust when it changes nothing); RGB Tint -> `_KEEP`:
  `Tint` (no Tint for the identity). Without a used map: an issue and nothing (as before).
- [ ] Update the texmap_rules / vray_texmaps / synthetic expectations the Falloff and Output changes move.

### Task 3: builder (build/materials.py)

- [ ] `Facing`: Layer Weight Facing (blend 0.5); Fresnel node with the IOR; towards: dot(Normal, Incoming) of a
  Geometry node, `(1 - d) / 2`.
- [ ] `Composite`: each layer: blend at factor 1 (Mix node blend type, or the spotlight / hard light / average
  forms), then Mix(result, blended, opacity x mask x image alpha), clamped for a non-normal mode; built in color.
- [ ] `ColorCorrect` rewire: identity none, (4, 5, 6) Invert, (8, 8, 8) the mean, else Separate / Combine Color.
- [ ] `Adjust`: the output() helper (fixed invert sign); `Tint`: Separate Color, three scales, two adds.
- [ ] `tests/blender/run.py`: `_fold` for Facing, Adjust, Tint, the new layers and rewire; `texmap_wrappers` in
  `UV_LAYERS`, in check_found_textures with node-type checks per wrapper; the builder's hand-made IR covers the new
  nodes.
