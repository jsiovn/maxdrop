# maxdrop-6n0.6.4: empty wrapper slots, rendered

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** make the wrapper peel stop where the renderer does not fall through to the next sub-material: an empty
first slot of VRayOverrideMtl, Double Sided and VRay2SidedMtl, and CoronaRaySwitchMtl's direct material empty or
switched off. VRayBlendMtl keeps its coat with a report line; Shellac keeps the fall-through (measured).

**Architecture:** `maxdrop/convert/materials.py` only: `WRAPPER_SWITCHES` gives way to `WRAPPER_STOPS` (class ->
the first slot's name, its switch parameter or None, what the renderer shows); `_sub` returns `(None, reason)` for a
stop, which `convert` already turns into the grey material with the reason in the report. `peel`, `convert`,
`_grey` and `source_for` are not changed.

**Tech Stack:** Python 3.11 syntax, `unittest`; 3ds Max 2020 + V-Ray 5.2 + Corona 12 (`3dsmaxbatch`) for the renders.

## Decision

- Stop (the grey material, the reason in the report): VRayOverrideMtl base empty ("V-Ray renders it black"), Double
  Sided material1 empty ("V-Ray renders that side not at all, the scanline black"), VRay2SidedMtl front empty ("V-Ray
  renders that side not at all"), CoronaRaySwitchMtl direct empty or switched off ("Corona renders nothing to the
  camera"). The later slots of those classes are not reached.
- VRayBlendMtl base empty: still its first set coat, with a report line once per wrapper object (V-Ray renders the
  coat over nothing, transparent where the blend is below white): hue right, coverage not drawn.
- Shellac base empty: the coat, as both renderers show it (no change).
- Not measured, unchanged: VRayMtlWrapper (one slot), CoronaLayeredMtl without a base, Shell, CoronaSelectMtl.
- `WRAPPER_SWITCHES` is removed: its one entry left (CoronaRaySwitchMtl) only fell through, which Corona refutes.
