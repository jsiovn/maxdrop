# CI: the fixture tests always run; the fixture scan is recursive Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A missing `tests/blender/run.py` fails the Blender job instead of skipping the fixture tests, and the CI
fixture scan covers every file under `tests/fixtures/`, subfolders and extensionless files included.

**Architecture:** Drop the `hashFiles` gate of the "Fixture tests" step in `.github/workflows/test.yml` and the
"once it exists" wording around it (workflow comments, `CONTRIBUTING.md`). `tools/check_fixture.py` expands its
glob arguments recursively and skips directories a pattern matches, so CI passes one pattern,
`tests/fixtures/**/*`.

**Tech Stack:** GitHub Actions YAML, Python 3.9+ standard library (`glob.glob(..., recursive=True)`).

```python
def _expand(arg):
    """The files a command-line argument names: a pattern (`**` included) expands to the files it matches,
    directories left out; anything else is taken as it is."""
    if not glob.has_magic(arg):
        return [arg]
    return [p for p in sorted(glob.glob(arg, recursive=True)) if os.path.isfile(p)]
```

  `paths = [p for arg in argv[1:] for p in _expand(arg)]`; docstring usage line shows `"tests/fixtures/**/*"`.
