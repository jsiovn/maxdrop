# Extrude: Use Shape IDs Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Extrude with Generate Material IDs and Use Shape IDs gives each side face the material ID of the spline
segment it comes from, as 3ds Max does; grid caps stay morph caps (no scene shows them).

**Architecture:** `reader/shapes.py` reads each knot's segment material ID (the high 16 bits of the trailing `u32`
of the 52-byte knot record); `convert/extrude.py` carries one ID per polyline point (the segment leaving it)
through interpolation, duplicate removal and the turn of clockwise solids / counter-clockwise holes, and the sides
take them when both flags are on. Caps keep IDs 1 / 2.

**Tech Stack:** Python 3.11 (plain for reader / convert), 3ds Max 2020 for the fixture and the oracle, Blender
4.2 / 4.5 / 5.2 for the fixture checks.

---

## Findings (3ds Max 2020 probes, 2026-11-21; scratch scenes outside the repo)

- Knot record `0x290A`, trailing `u32`: high 16 bits = zero-based material ID of the segment that starts at the
  knot (Line, IDs 1 4 7 2 -> `0x0`, `0x30000`, `0x60000`, `0x10000`); low 16 bits 0; the last knot of an open
  spline 0 (no segment).
- Extrude, Generate Material IDs + Use Shape IDs: each side face (interpolated steps included) takes its segment's
  ID; caps stay 1 (facing +Z) and 2 (facing -Z), also for a negative amount, a clockwise outline (per-segment IDs
  kept on the right faces) and a hole (its own segments' IDs).
- Use Shape IDs without Generate Material IDs: every face ID 1.
- Parametric shapes (Rectangle, Circle, NGon, Arc, Ellipse) under Use Shape IDs: sides ID 1 (their segments are
  ID 1).
- Census for grid caps: 443 local `.max` scenes (corpus included), 95 Extrudes in 5 of them: all morph caps, none
  with Use Shape IDs. The bead's condition for grid caps is not met: they stay morph caps with their report line,
  and a debt bead under `maxdrop-em3` keeps the gap.
