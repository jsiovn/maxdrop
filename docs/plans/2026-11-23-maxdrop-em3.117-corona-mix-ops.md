# CoronaMix operations 7 and 9-20 Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Name and measure CoronaMix operations 7 and 9-20 and draw the ones a Blender node draws as Corona computes
them; the rest stay peeled, the issue naming the operation.

**Architecture:** convert/texmaps.py: `Blend` gets new ops (screen, overlay, hard light, color dodge, color burn,
linear burn, linear light, exclusion), `CM_BLENDS` maps the operations to them, the closing gamma of a Blend in
Corona's sRGB mode takes the result's magnitude (measured). Gamma (7) with a grey top that is its color becomes a
`ColorCorrect` gamma, two constants fold. build/materials.py `arith()` draws the new ops with Mix node blend types.

**Tech Stack:** plain Python (convert), Blender bpy (build), 3ds Max 2020 + Corona 12 renderMap (measurements,
fixture).

---

## Measurements (renderMap, CoronaColor HDR layers, 3ds Max 2020 + Corona 12)

Probes in `C:\maxdrop_fixtures\probe\em3_117` (local): probe1 (every operation, six layer pairs incl. HDR and
negative layers, mixInSRgb on and off, wrapped as (v + 4) x 0.05 to read -4..16), probe2 (corners). Names from
Corona's docs ("Corona Mix Map", Mix Operation), a = bottom, b = top, per channel:

| op | name | Corona (linear mode; sRGB mode: on a' = abs(a)^(1/2.2), b', result abs(r)^2.2) | drawn |
|---|---|---|---|
| 7 | Gamma | a^(1/b) | grey constant top: ColorCorrect gamma b (sRGB b^(1/2.2)); two constants folded; else peeled |
| 9 | Screen | 1-(1-a)(1-b), unclamped | Mix SCREEN, exact |
| 10 | Overlay | a<0.5: 2ab, else 1-2(1-a)(1-b) | Mix OVERLAY (A = bottom), exact |
| 11 | Color Dodge | a/(1-b), at most 1, b = 1 -> 1, negative kept | Mix DODGE: equal for layers within 0..1 but black under white |
| 12 | Color Burn | max(0, 1-(1-a)/b), b = 0 -> 0, no upper clamp | Mix BURN: equal for layers within 0..1 |
| 13 | Linear Burn | max(0, a+b-1) | Mix ADD, minus 1, floored at 0: exact |
| 14 | Linear Light (Add Sub) | a+2b-1, unclamped | Mix LINEAR_LIGHT, exact (sRGB: abs before the closing Gamma) |
| 15 | Soft Light | Photoshop's (Blender's is Pegtop) | peeled |
| 16 | Hard Light | overlay(b, a) | Mix OVERLAY, sides swapped, exact |
| 17 | Vivid Light | no Mix type | peeled |
| 18 | Pin Light | no Mix type | peeled |
| 19 | Hard Mix | no Mix type | peeled |
| 20 | Exclusion | a+b-2ab, unclamped | Mix EXCLUSION (floored at 0): equal for layers within 0..1 |

The amount lerp is linear in both modes for 9-14, 16, 20 (amounts 0.5, 0.25: within 3e-4). Linear light in sRGB
mode: black over black renders 0.998 (abs(-1)^2.2): the result's magnitude, not a negative.
Corona takes the magnitude of a negative layer in sRGB mode too (P5); MaxDrop's Gamma node keeps the sign: a debt
bead (existing add / subtract / difference as well).
