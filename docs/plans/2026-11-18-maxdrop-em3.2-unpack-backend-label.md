# UnpackResult.backend names the unpacking program — Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `UnpackResult.backend` names the program(s) that wrote the files, and `ExternalBackend` keeps no
per-pack mutable state (bead `maxdrop-em3.2`).

**Architecture:** Return-value route. `backend.extract()` returns the label of the program that wrote the
files (`ZipBackend`: `"zipfile"`). `ExternalBackend.name` becomes a fixed description (the program chain) that
`names()` / `extract()` never reassign; the program that listed a pack is read from the entries it listed
(`ExternalBackend.listed_by(entries)`: each entry's key holds its tool). `archive.unpack()` starts the result
with the lister (what a reused or in-place result reports, nothing being written) and replaces it with the
label(s) `extract()` returned; when the scene and its maps were written by different programs (the
`references` path runs `extract()` twice) both are named, joined by `" and "`. `list_pack()` names the lister.

**Tech Stack:** Python 3.11 stdlib, `unittest`.
