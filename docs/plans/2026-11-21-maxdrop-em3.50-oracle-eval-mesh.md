# Oracle: per-face material IDs and map channel 1 of evaluated meshes Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The oracle says which material ID each evaluated triangle of a modified node carries (by the way it
faces) and what map channel 1 of that mesh holds, so the Extrude rules (cap +Z = ID 1, -Z = ID 2, sides 3;
mapping 0..1 or real-world units) are checked against 3ds Max, not against the code's own rules.

**Architecture:** `tools/oracle/dump_scene.ms` gets layout version 9: a node key `eval_mesh`, `null` unless the
node has a modifier and evaluates to a mesh (`eval_faces` not null). Then `material_ids`: per material ID (1-based,
as 3ds Max shows it), ascending, `[id, up, down, side]` triangle counts of `snapshotAsMesh` by the sign of the
face normal's z in object space (the three vertices taken back by the inverse object transform; |z| <= 1e-4 of
the unit normal, or a degenerate face, is `side`); `map_channel_1`: `null` without channel 1 support, else
`count` (`meshop.getNumMapVerts`), `min`, `max` (`[u, v, w]` over the map vertices the map faces use). Every
oracle regenerated. `tests/unit/test_extrude.py` compares every extruded node against it.

**Tech Stack:** MAXScript (3ds Max 2020, `3dsmaxbatch.exe`), plain Python `unittest`, Blender 4.2 / 4.5 / 5.2
headless (no Blender code changes; the smoke runs are the build-and-test contract).

Bead: maxdrop-em3.50

## Facts measured (3ds Max 2020, probe outside the repo, extrude.max)

- Histograms by world normal (`getFaceNormal` of the snapshot), by object-space winding normal and of `node.mesh`
  agree on all 7 extruded nodes, the mirrored one included: the fixture cannot choose the space. Object space is
  taken: the Extrude rule and the reader's MeshData live there, and "facing +Z" of a mirrored node is ambiguous
  in world space.
- `[id, up, down, side]`: Rect `[1,2,0,0] [2,0,2,0] [3,0,0,16]`; L `[1,4,0,0] [2,0,4,0] [3,0,0,12]`; Hole
  `[1,32,0,0] [2,0,32,0] [3,0,0,64]`; Island `[1,10,0,0] [2,0,10,0] [3,0,0,24]`; Open `[3,0,0,16]`; Mirror
  `[1,30,0,0] [2,0,30,0] [3,0,0,64]`; Adaptive (no material IDs) `[1,126,126,256]`.
- Map channel 1 only on Rect (23 map vertices, all used, 0..1, w 0) and Adaptive (514, all used, u 0..37.6954,
  v 0..12, w 0). The reader's MeshData gives the same counts, ranges and histograms today: the test passes on its
  first run; a local swap of `TOP_ID` / `BOTTOM_ID` must make it fail.
- `3dsmaxbatch.exe` returned 127 although the script ran: success is read from the file the script writes, never
  from the exit code.
- Not covered (count and range cannot see it): a U reversed along a spline. Debt bead under `maxdrop-em3`.
