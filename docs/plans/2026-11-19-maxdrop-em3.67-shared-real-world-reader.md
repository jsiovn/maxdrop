# One shared Real-World Map Size reader Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `convert/extrude.py`, `convert/uvwmap.py` and `convert/primitives.py` read Real-World Map Size through
one bpy-free helper, `reader.realworld.flag(chunk, class_id)`, instead of three private `_real_world` copies.

**Architecture:** The flag is file layout (the u32 `0x0130` of the `0x2150 {0x0110}` entry whose `0x0120` names
the object's or modifier's own ClassID, docs/FORMAT.md), so the helper lives in `maxdrop/reader/realworld.py`,
next to the chunk index it walks. It imports nothing (it only calls `first`, `find_all`, `container`,
`payload_size` and `unpack` on the chunk it is given) and never raises on a damaged entry. The three convert
modules call it; their `_real_world` functions and their `0x2150 / 0x0110 / 0x0120 / 0x0130` constants go, and so
do `_CLASS_KEY` / `_U32` where nothing else uses them. Behaviour is unchanged: the first entry naming the class
decides (a short `0x0130` there is off), a leaf `0x0110` or a short `0x0120` is skipped, no `0x2150` is off.

**Tech Stack:** Python 3.11, `unittest`, no Blender for the unit tests.

Bead: maxdrop-em3.67

- [ ] **Step 1: failing test.** Synthetic chunks built with `reader.chunks.index` (the builders of the two
  existing `test_real_world_is_the_entry_of_its_own_class` tests): another class's entry alone -> False; other
  then own (own 1 -> True, own 0 -> False); own then other (own 1, other 0 -> True; own 0, other 1 -> False); a
  short `0x0130` (2 bytes) -> False even with a later own entry at 1; a short `0x0120` skipped; a leaf `0x0110`
  skipped; no entry -> False; no `0x2150` -> False; a leaf chunk -> False; a ClassId and a plain tuple both match.
- [ ] **Step 2: red check.** `python -I -m unittest tests.unit.test_realworld` -> ModuleNotFoundError.
- [ ] **Step 3: implementation.**

  ```python
  HOLDER, ENTRY, CLASS, VALUE = 0x2150, 0x0110, 0x0120, 0x0130

  def flag(chunk, class_id):
      if not chunk.container:
          return False
      holder = chunk.first(HOLDER)
      if holder is None or not holder.container:
          return False
      key = tuple(class_id)
      for entry in holder.find_all(ENTRY):
          if not entry.container:
              continue
          cls = entry.first(CLASS)
          if cls is None or cls.payload_size < 8 or cls.unpack("<II") != key:
              continue
          value = entry.first(VALUE)
          return value is not None and value.payload_size >= 4 and value.unpack("<I")[0] != 0
      return False
  ```

- [ ] **Step 4:** the test passes.
