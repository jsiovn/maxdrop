# Cancel inside one long node of the read Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Esc during a modal import's read ends the worker within `ops._READ_WAIT` also when the node being read is
one huge mesh (bead maxdrop-em3.89).

**Architecture:** `convert.scene.describe()` turns its `cancel` callable into a `check()` that raises
`convert.scene.Cancelled`, and passes it into `reader.geometry.read_mesh(scene, i, check=None)` and
`convert.scene.mesh_description(..., check=None)`. The reader only calls it (it never names the exception, so
`reader/` does not import `convert/`): every `CHECK_EVERY` records of the per-record loops (`_poly_faces`, and the
slow paths of `_poly_positions` and `_poly_map_faces`), through an outer block loop (no per-record cost), and
between map channels. `mesh_description` calls it between its numpy phases.

**Tech Stack:** Python 3.11, numpy; Blender 4.2 / 4.5 / 5.2 only for the end-to-end checks.

---

## Measured before (scene B, Blender 5.2, scratch scripts in the session scratchpad)

- `describe()` 6.62 s; the longest gap between two node checks 1.87 s (the largest mesh, 5.6 M face corners, an
  Editable Poly): `read_mesh` 1.2 s, of it `_poly_faces` 1.05 s (a Python loop per face, 1.4 M faces);
  `mesh_description` 0.64 s, of it `valid_faces` 0.31 s and `sharp_edges` 0.31 s.
- Esc 2 s into the read (3 runs): `close()` 0.51-0.53 s, close to the worker's end 1.29-1.58 s. Esc 0.2 s into
  the largest mesh's read: close to the end 1.68-1.71 s.

## Decisions

- The check raises; the reader does not catch it. `read_mesh` nets only `MaxFileError`, `MemoryError` and
  `OverflowError`, and the `except struct.error` in the record loops only struct errors: `Cancelled` passes them
  and `describe()`'s `except geometry.GeometryError` / `ChunkError` nets.
- `CHECK_EVERY = 1 << 16` records (about 50 ms of `_poly_faces`). The first block is not checked: describe()
  asked just before the node, and the call counts of a small mesh stay those of em3.82 (once per node and walk).
- `mesh_description` checks only for a mesh of more than `CHECK_EVERY` face corners, for the same reason: before
  `valid_faces`, before `sharp_edges` (moved out of the constructor call) and before each UV layer. Leaves
  stretches of about 0.3 s, under `_READ_WAIT` (0.5 s); `valid_faces` / `sharp_edges` are split further only if
  the measurement after asks for it.
- The material conversion (0.59 s on scene B) stays checked only before and after (em3.82): out of scope.
