# M3 gate (version 0.0.5) Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove milestone M3 (room shells and UVs) against 3ds Max on corpus scene A (and measure scene B), look
at scene A rendered, and prepare release 0.0.5, not pushed.

**Architecture:** No engine, operator or test-runner code changes. The gate measurement and the render are throwaway
scripts in the session scratch folder (they take local paths, and their logs name scene objects); their numbers
(counts, class names) go into the bead notes and `docs/BASELINE.md`. The repository changes are the version bump,
the CHANGELOG section and the docs that must be true for 0.0.5 (SUPPORT, BASELINE, README, site and its test).

**Tech Stack:** Blender 5.2 headless (`--background --factory-startup`, isolated `BLENDER_USER_RESOURCES`),
`tools/census.py`, `tools/baseline.py`, the layout-2 oracle dumps of scenes A and B made at the M2 gate (local, outside
the repository; they carry `bbox_min/max`, `eval_verts`, `eval_faces` and `modifiers` per node), `python -m http.server`.

  22 / 9 / 18, Extrude 20 / 20 / 20, FFD 2x2x2 9 / 7 / 9, Edit Poly 4 / 4 / 1, TurboSmooth 2, Edit Spline 1,
  Shell 1, Symmetry 1. Base classes: 20 SplineShape, 5 Rectangle, 4 Line among 746 nodes.

  digits on 16 (the other 4 carry an Edit Mesh or FFD above); UVW Map 23 of 29 objects evaluated (6 sit above an
  Edit Mesh or FFD, which MaxDrop does not evaluate by design: base object + a report line).
- The oracle's `eval_verts` / `eval_faces` count the triangles of 3ds Max's world-state mesh after every modifier;
  `bbox_min/max` is the tight world box after every modifier, in file units, 6 significant digits.
- Imported objects pair with oracle nodes by walk order (`tests/blender/run.py` `objects_of`: the k-th node of a name
  is `<name>.<k:03d>` in an emptied scene).
- "Supported stack": a MESH node whose `node.modifiers` (what is left neither applied nor converted) is empty.
- Released versions: 0.0.1 to 0.0.3 (tags local), 0.0.4 is on main's epic merge pending; the upgrade test uses
  the build-and-test recipe (v1 = this build, v2 = the same package with patch + 100).
