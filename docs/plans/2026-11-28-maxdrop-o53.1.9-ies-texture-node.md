# The IES Texture node in Blender, measured: Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A compat helper that gives a light its node tree (Emission and Light Output) on Blender 4.2, 4.5 and 5.2,
a fixture-test check of it, and the IES Texture node measured in Cycles and EEVEE on the three versions, written into
docs/FORMAT.md with the two rules maxdrop-o53.1.3 implements.

**Architecture:** `compat.light_nodes(light)` builds on `compat.node_tree` (4.x needs `use_nodes`, 5.x always has
a tree) and finds the nodes by type (the active `ShaderNodeOutputLight`, the Emission linked to its Surface), making
what is missing. `tests/blender/checks_lights.py` checks it on a new point and spot light (suite.py runs it). The
measurement is a scratch script outside the repo (it stands in for a behavior test: the committed tests render
nothing, CI has no GPU); only its numbers enter the repo, in docs/FORMAT.md.

**Tech Stack:** Blender Python (bpy), Cycles CPU, EEVEE, OpenEXR float renders.

Base: `3196511`. Probe already done (2026-11-28, the three versions): a new 4.2 / 4.5 light has `use_nodes` False
and no tree, setting it gives Emission + Light Output; 5.2 has the tree at once and warns on reading `use_nodes`;
`ShaderNodeTexIES` has `mode` (INTERNAL / EXTERNAL), `ies` (Text), `filepath` on all three; its output is `Fac` on
4.2 / 4.5 and `Factor` on 5.2; `exposure` and `normalize` exist on 4.5 and 5.2 only.

### Task 2: Measure the IES Texture node (scratch, outside the repo)

Script `$S/ies/measure.py`, run headless (`--factory-startup`, `BLENDER_USER_RESOURCES=$S/profile-ies-<tag>`) on
B42, B45, B52; output JSON lines into `$S/ies/<tag>.log`. Scene: Cycles CPU, 16+ samples, denoise off, bounces 0
where a ceiling is sampled, World black, a 200 x 200 m Diffuse BSDF floor of 1.0 at z 0, the light at z 1 (radius
0, camera-invisible), an orthographic camera (ortho scale 0.05, 64 x 64) looking down at the sample point; render to
float EXR, load, mean of the 8 x 8 center pixels. IES files written by the script (LM-63, type C, as
tests/unit/test_ies.py writes them), loaded into a Text (`mode` INTERNAL), the node's output into the Emission's
Strength.

- [ ] **Step 1: Baseline:** 1 W point, node off, nadir -> ~0.02526 on each version (else fix the scene).

- [ ] **Step 3: Downlight file** (vertical 0 to 180 in 22.5 degree steps, distinct values above the horizon): on/off

- [ ] **Step 5: Watts:** 4.5 / 5.2 defaults (exposure 0, normalize on) give the baseline; normalize off on a point of
