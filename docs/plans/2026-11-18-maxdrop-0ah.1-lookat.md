# Look At Controllers and Target Nodes Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Target cameras, target lights and other objects aimed by a Look At controller or a Look At constraint
get the world matrix 3ds Max computes at frame 0; their target nodes are empties, not placeholders; the import
option "Keep Targets" aims them with a Track To constraint instead of the baked rotation.

**Architecture:** `reader/controllers.py` evaluates the Look At controller `(0x2006, 0)` (a Matrix3 controller) and
the LookAt Constraint `(0x2021, 0)` (a rotation controller under a PRS) as a **world** matrix, from the world
positions of other nodes (`Transforms.world`), then turns it into the local matrix the rest of the pipeline uses.
`convert/scene.py` carries the look-at (target node, Blender track axis) on the NodeDescription and builds Target
objects as empties (a conversion, like Dummy). `build/objects.py` adds the Track To constraints when asked;
`ops.py` has the option.

**Tech Stack:** Python 3.11 syntax, no bpy in reader/convert; 3ds Max 2020 through 3dsmax-mcp (own instance) for
the probes, the fixture and its oracle; Blender 4.2 / 4.5 / 5.2 headless.

## What 3ds Max 2020 stores and computes (probed: scratch files outside the repo, then the fixture)

### Look At controller `(0x2006, 0)`, superclass `0x9008`

- References: 0 = the target node (empty: none), 1 = position controller (Position XYZ), 2 = roll (Bezier Float,
  radians), 3 = scale (Bezier Scale).
- Chunks: `0x0100` u32 axis (0 X, 1 Y, 2 Z; 2 = a target camera's), `0x0110` present = flip, `0x0201` u8 1 =
  use the target as up node (maxdiff of saves that changed one setting each).
- World position `P` = position * parent world (the parent's scale and rotation move the point, they do not
  reach the rotation: FixtureCamChild's rows are unit length under a Dummy scaled 1.5).
- Frame (rows): `n` = unit vector from `P` to the target's world position (the origin without a target);
  `z = -n`; `x = normalize(up x z)`, `y = z x x`, `up` = world Z, or the target's world Z row with "use target as
  up node". `z` parallel to `up`: `x = (1, 0, 0)` (target straight above: rows X, -Y, -Z; below: identity).
  `P` on the target: `z = (1, 0, 0)`.
- Then flip `(x, y, z) -> (-x, y, -z)`, then roll about `z` (`x' = c x + s y`, `y' = -s x + c y`), then the
  axis: 2 = `(x, y, z)`, 0 = `(z, y, -x)`, 1 = `(x, z, -y)`.
- World matrix = scale (its axis included) * frame * translation(P).

### LookAt Constraint `(0x2021, 0)`, superclass `0x900C`, in a PRS's rotation slot

- One reference: a ParamBlock2. Ids (checked by values and by saves of one change each): 0 weights (float
  table), 1 targets (node table), 2 relative (keep initial offset), 3 viewline length, 4 set orientation, 5
  target axis (0..2), 6 target axis flip, 7 up node axis, 8 up node is the world, 9 up node (node), 10 source
  up axis, 11 source up axis flip, 12 viewline length absolute, 13 up node control (0 look at, 1 axis
  alignment). Chunks `0x1001`-`0x1004` (4 x f32 each) and `0x1005` hold the offsets of relative / set
  orientation: not read (an issue when either is on).
- Target point = the weighted average of the targets' world positions. Look axis `a` = row `a` = `n` (`-n`
  flipped). Up vector `u`: control 1 = row (up node axis) of the up node's world matrix (the world: the unit
  axis); control 0 = from `P` to the up node's world position (the world: the origin). Source up axis `s`
  (`a != s`) = `u` minus its `n` part, normalized (negated when flipped); the third axis by right-handedness
  (`row[t] = row[t+1] x row[t+2]`, cyclic).
- World matrix = scale * frame * translation(P), P the PRS position * parent world, as above.

## Tasks

### Task 1: fixture and oracle
- [x] `tools/fixtures/lookat.ms`: 17 nodes (target cameras: plain, rolled, straight above its target, under a
  rotated and scaled Dummy; a target spot; boxes with a Look At controller: X axis flipped + target as up node +
  scale, Y axis + roll; boxes with a constraint: two weighted targets + Y flipped + scale, up node looked at +
  source up flipped, up node axis-aligned under the Dummy). Sanitized, checked, copied; `lookat.oracle.json`
  by `MaxDropOracle.dumpFile`.

### Task 2: reader
- [ ] `classids.py`: `LOOK_AT`, `LOOKAT_CONSTRAINT`, `TARGET_OBJECT` with their class directory names.
- [ ] `controllers.py`: `look_frame()`, `constraint_frame()`; `_Eval` gets the Transforms; `Transforms.local`
  evaluates a world-driven node (Look At, PRS with a constraint) as world, keeps it (`world()` uses it) and returns
  world * parent^-1; `Transforms.look_at(i)` -> `LookAt(target, axis, flip, roll, target_up)` of a Look At
  controller node. Guards: a look-at cycle or chain deeper than `MAX_LOOK_AT_DEPTH` and a parent that cannot be
  inverted give an issue; a constraint without targets or with zero total weight, relative / set orientation, a
  constraint outside a PRS: issue. `matrix(scene, i)` (gizmos) keeps "unknown class" for both.
- [ ] `tests/unit/test_controllers.py`: synthetic Look At trees (axis, flip, roll, up node, no target, straight
  above / below, on the target, parented, cycle, depth), synthetic constraints (weights, axes, up controls, zero
  weight, relative), `look_at()`; the fixture loop already checks lookat within 1e-4.

### Task 3: convert and build
- [ ] `convert/scene.py`: Target objects are empties that are no placeholder; `NodeDescription.look_at` =
  `LookAtDescription(target, track, up, target_z)` for a Look At controller node whose target is a node: Blender's
  `track` and `up` (`TRACK_NEGATIVE_Z`/`UP_Y` for a camera), `None` when no Track To gives Max's frame (a roll, Y
  axis), with the reason.
- [ ] `build/objects.py`: `track_targets(desc, built)` adds a Track To to each such object, returns the nodes it
  could not aim (reason).
- [ ] `ops.py`: `keep_targets` BoolProperty (default off) in the Transform panel; after the axis conversion,
  `track_targets`; report line for the ones kept baked and when the axis conversion is not identity.
- [ ] `tests/unit/test_convert_scene.py`, `tests/blender/run.py` (Keep Targets on lookat: constraints and
