# cfb._inflate member boundary across input pieces: Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cover the refill loop in `maxdrop/reader/cfb.py` `_inflate` (it reads the next `_INFLATE_PIECE` piece
when fewer than 3 bytes follow a member's end) with tests in `tests/unit/test_cfb.py` `Gzip`.

**Architecture:** Test only; no change to `cfb.py`. A gzip member of an exact compressed length is written by hand
from stored deflate blocks (`gzip.compress` block sizes depend on the zlib build), so its end can sit 0, 1, 2
(and, as a control, 3) bytes before the end of the first `_INFLATE_PIECE` piece of the Scene stream. What follows
it: a second member, padding, or a second member whose magic is intact and the rest damaged.

**Tech Stack:** Python 3.11 `unittest`, `zlib.crc32`, `struct`; no Blender.

Bead: maxdrop-em3.90

- [ ] **Step 1: helper**

```python
def stored_member(size, seed=0):
    """A gzip member of exactly size bytes, its data in stored deflate blocks: (member, data)."""
    # 10 header + 8 trailer bytes, 5 per block of at most 65535: try each block count m
    n = next(n for m in range(1, size // 65535 + 2) for n in [size - 18 - 5 * m]
             if n >= 0 and max(1, -(-n // 65535)) == m)
    data = payload(n, seed)
    blocks = [data[o:o + 65535] for o in range(0, n, 65535)] or [b""]
    body = b"".join(struct.pack("<BHH", k == len(blocks) - 1, len(b), len(b) ^ 0xFFFF) + b
                    for k, b in enumerate(blocks))
    head = b"\x1f\x8b\x08\0\0\0\0\0\0\xff"
    return head + body + struct.pack("<II", zlib.crc32(data), n & 0xFFFFFFFF), data
```

(A size no block count reaches raises StopIteration; the sizes used here, about 1 MiB, are reachable.)

```python
    def test_member_ends_at_a_piece_end(self):
        piece = cfb._INFLATE_PIECE
        b = payload(5000, 6)
        for k in (0, 1, 2, 3):
            a_member, a = stored_member(piece - k, 5)
            with self.subTest(k=k):
                for tail, want in ((gzip.compress(b), a + b), (b"\0" * 300, a), (b"\0" * k, a)):
                    data, _ = self.build(raw=a_member + tail)
                    with cfb.CompoundFile(data) as cf:
                        self.assertEqual(cf.open("Scene").read(), want)
                damaged = gzip.compress(b)
                damaged = damaged[:3] + bytes(x ^ 0x55 for x in damaged[3:40]) + damaged[40:]
                data, _ = self.build(raw=a_member + damaged)
                with cfb.CompoundFile(data) as cf:
                    with self.assertRaises(CfbError):
                        cf.open("Scene")
```

`b"\0" * k` is padding that ends exactly at the piece end (k = 0: none at all): the refill finds no more pieces.
