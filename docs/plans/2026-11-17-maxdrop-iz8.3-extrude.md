# Extrude Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evaluate the Extrude modifier on a shape, so that the room shell of an interior scene is a closed mesh
with outward normals, material IDs, smoothing and generated mapping coordinates as 3ds Max makes them.

**Architecture:** `maxdrop/convert/extrude.py` (no bpy; numpy when called) turns a reader `Shape` plus the
Extrude modifier's parameters into a `reader.geometry.MeshData`: each spline becomes a polyline the way 3ds Max
interpolates it (steps per segment, optimize, adaptive), the sides are quads between `segments + 1` levels, the
caps are the closed splines nested even-odd (solid / hole), kept as one n-gon when a solid has no hole and
ear-clipped after bridging its holes otherwise. Every solid outline is turned counter-clockwise and every hole
clockwise (seen from +Z) before the sides are made, and a negative amount reverses the winding, so the normals
point out whatever the spline direction. `convert/scene.py` applies an Extrude that is the bottom modifier of a
shape node's stack: the node becomes a MESH keyed `(base, offset, extrude modifier index)`, the offset and meters
are baked by `mesh_description` as for every mesh, and `node.applied` names it for the report (the modifiers above
it stay listed as not applied).

**Tech Stack:** Python 3.11 syntax, standard library + numpy, unittest; 3ds Max 2020 via 3dsmax-mcp for the
fixture and the oracle; Blender 4.2 / 4.5 / 5.2 headless for the build.

## Tasks

### Task 1: probe and fixture
- [ ] In an own 3ds Max 2020 instance: Extrude's ClassID and superclass, its parameter block (old or PB2, slot,
  parameter ids for amount, segments, cap start, cap end, cap type, output, mapping, generate material IDs, use
  shape IDs, smooth, real-world map size); the vertex / triangle counts Max gives for steps, optimize and adaptive.
- [ ] `tools/fixtures/extrude.ms`: FixtureExtRect (Rectangle, capped, mapping, material IDs), FixtureExtL (an
  L-shaped Line, corner knots, a negative amount, 2 segments), FixtureExtHole (a Rectangle and a Circle in one
  Editable Spline: a cap with a round hole), FixtureExtOpen (an open Line: no caps), FixtureExtMirror (an extruded
  Rectangle on a mirrored node), FixtureExtAdaptive (adaptive Circle); a Standard material on every node.
- [ ] sanitize, check (`clean`), copy to `tests/fixtures/extrude.max`, regenerate every oracle
  (`MaxDropOracle.dumpFolder`).

### Task 2: convert/extrude.py (TDD)
- [ ] `tests/unit/test_extrude.py`: every Extrude node of every fixture: bbox within 1e-3 of the oracle,
  vertex count and triangle count (sum of face sizes - 2) equal `eval_verts` / `eval_faces`; the capped ones are
  closed manifolds (every edge has two faces) with a positive signed volume in the world (outward normals); the
  holed cap has a hole (the cap's area = rectangle - circle, the Euler characteristic of a solid with a tunnel);
  the open one has no cap; material IDs 0 / 1 / 2 (start cap / end cap / sides) when generated; flat caps and
  sharp corner edges; a UV channel 1 in [0, 1] when mapping is on. Synthetic cases: ear clipping of a concave
  outline, a self-touching outline, two holes, a hole outside every solid (dropped, an issue), degenerate
  outlines (fewer than 3 points, zero area), a hostile point count.
- [ ] `maxdrop/reader/classids.py`: EXTRUDE (with the fixture that has it).
- [ ] `maxdrop/convert/extrude.py`: `Params`, `read_params(modifier)`, `polylines(shape)`, `triangulate(outer,
  holes)`, `extrude(shape, params) -> (MeshData, issues)`.

### Task 3: convert/scene.py, report, build check
- [ ] `describe`: a shape base whose bottom modifier is an Extrude that renders becomes a MESH; anything else
  between the shape and the Extrude keeps the curve (an issue). `NodeDescription.applied`; `report.gather` counts
  it under APPLIED, the rest under IGNORED.
- [ ] Existing convert tests: an extruded shape node is a MESH (its oracle has `shape` and modifiers).
- [ ] `tests/blender/run.py`: extrude: mesh objects, closed (every edge two faces), bbox vs the oracle.

### Task 4: docs and close
- [ ] docs/FORMAT.md (Extrude), docs/SUPPORT.md, CHANGELOG line, corpus scene A: Extrude nodes built vs the
  census (20) and the share whose bbox matches the oracle (dump outside the repo), in the bead notes.
