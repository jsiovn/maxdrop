# A constant on a data input: mean of the swatch Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** settle by a V-Ray render what value a color constant (VRayColor, a Mix's own swatch) gives on a data input
(a Mix mask), and make MaxDrop's data constants follow it.

**Architecture:** the bead (written 2026-11-16) saw MaxDrop give a grey 64 mask 0.051 where renderMap gave 0.251.
That predates the scene swatch rule (`convert/colors.py`, maxdrop-arp.16, 2026-11-17): with the gamma on a swatch is
already linear as stored, so the mask is 0.251 today. The render below checks both gamma modes and a saturated mask.
If V-Ray takes the mono value as the mean of the swatch before the scene's rule, data constants become
`swatches.channel(mean(clamped swatch))` (one helper in `convert/texmaps.py`) instead of the mean of the linear
color: unchanged with the gamma on and for greys, different only for a colored swatch with the gamma off.

**Tech Stack:** 3ds Max 2020 + V-Ray 5.2 (`3dsmaxbatch`, a scratch MAXScript), Blender 5.2 headless (reading the
rendered files), plain Python `unittest`.

---

## Measurement (outside the repository: `C:\maxdrop_fixtures\probe\em3_36\`)

`probe.ms`: five planes with a VRayLightMtl (multiplier 1, GI off, default lights off, color mapping linear, gamma
1), its texmap a Mix black -> white whose mask is: VRayColor grey 64; VRayColor red (255 0 0); a Mix whose own
color 1 and 2 are grey 64 (the `_constant` path); a Bitmap; the fifth plane a plain grey 64 swatch. Gamma off
(`mask_none`) and on, 2.2 (`mask_gamma`); each saved and rendered to PNG and EXR. `readpx.py` (Blender) reads the
files' pixels, `masks.py` (plain Python) prints the Constants MaxDrop makes for the saved scenes.

| Mask | V-Ray PNG, gamma off | V-Ray EXR, gamma on (linear) | MaxDrop today, off / on |
|---|---|---|---|
| VRayColor grey 64 | 64 | 0.251 | 0.0513 (shows 64) / 0.251 |
| VRayColor red | 85 | 0.333 | 0.333 (shows 156) / 0.333 |
| Mix's own grey 64 | 64 | 0.251 | 0.0513 / 0.251 |
| grey 64 swatch (color) | 64 | 0.251 | 0.0513 / 0.251 |

With the gamma off the scene is display-referred: V-Ray mixes by 0.333 and writes 85; Blender shows a linear
`decode(85 / 255)` = 0.0908 as 85. So the mask must be the scene's rule applied to the mean of the swatch: gamma on,
the mean (as today); gamma off, `srgb_to_linear(mean)`. Only a colored swatch with the gamma off changes.

Not settled by this render, left as they are (named in the docstring as unmeasured, a debt bead):
- A data constant on a material input (roughness from a glossiness map's constant, opacity) with the gamma off:
  V-Ray uses the stored number there, the decode is exact only for a mask between black and white.
- The Bitmap mask: the PNG (written by 3ds Max through output gamma 2.2) holds byte 136; with the gamma on V-Ray
  renders 0.251 linear = (136 / 255) ^ 2.2, so it decoded the mask image, while MaxDrop takes every mask image as
  Non-Color (0.533). With the gamma off it renders 136 (raw).
- Corona's swatches (no Corona render in batch).
