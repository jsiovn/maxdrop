# Plain CI on Python 3.13 with numpy 2.3.4 Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The plain CI job runs the unit tests on the Python of Blender 5.2 (3.13) with its numpy (2.3.4), and on
the Python of Blender 4.2 / 4.5 (3.11) with numpy 1.24.3.

**Architecture:** `.github/workflows/test.yml`, job `python`: the matrix keeps its `os` and `numpy` axes; a
`matrix.include` adds a `python` key to each numpy value (1.24.3 -> 3.11, 2.3.4 -> 3.13). `setup-python` takes
`matrix.python`; the version-check step also asserts the interpreter's `major.minor`. The job name carries the
Python version. The `Plain Python` gate and the once-only ruff step (Linux, numpy 2.x) are unchanged; ruff keeps
`target-version = "py311"` from `pyproject.toml`, so 3.11 syntax is still enforced while it runs on 3.13.

**Tech Stack:** GitHub Actions, `actions/setup-python@v7`, uv for the local 3.13 check.
