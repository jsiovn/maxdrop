# Gamma-off mask images, CoronaMix gamma on converted sides, fixture thumbnails Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** three code-only beads of part G in one cycle: maxdrop-6n0.6.36 (a colored image as a gamma-off mask is the
decoded mean of its stored pixel), maxdrop-6n0.6.24 (a) (CoronaMix gamma decided on the converted sides),
maxdrop-6n0.6.13 (check_fixture skips the SummaryInformation thumbnail's picture bytes for the path patterns).

**Architecture:** convert/texmaps.py gains `Decode.mean` (the mean of the input's channels through the exact sRGB
curve, a float) and wraps an image read as stored (a Bitmap, a VRayBitmap From 3ds Max) in a gamma-off MASK in it;
build/materials.py draws it as a DOT_PRODUCT mean and the piecewise sRGB curve in Math nodes (exact for a grey,
which the per-channel sRGB image was before). `_corona_mix` converts the sides of a gamma first (a scratch walk merged
only when drawn) and decides on `isinstance(top, Constant)`. tools/check_fixture.py zeroes the thumbnail value
(FMTID_SUMMARY, pid 17, VT_CF) in the file and stream views before the PATTERNS scan; names are still scanned there.

**Tech Stack:** Python 3.11 (plain tests), Blender 4.2 / 4.5 / 5.2 headless (smokes, tests/blender/run.py), the
6n0.6.2 probe (`blender_render.py`, EEVEE) for the measured rows.

Red-check base: `117aa25` (origin/epic/maxdrop-6n0.6 = HEAD at the start).
