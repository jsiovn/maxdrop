All four start at 1.0.0: M5's wrapper graphs (Falloff and Output kept as graphs instead of peeled to their first
image) and the Color Correction rewiring are new in 1.0.0 and expose two inputs MaxDrop does not read.

1. **Three materials (two VRayMtl, one Multi/Sub-Object): one shared Falloff whose second side is an Output map.**
   The Output's `map1` (ParamBlock2 parameter 0, P_OWNERS_REF) is stored with index -1 in this file (format 14000,
   entries 0x000E, no 0x0013 table); the owner's reference slot 0 holds the map (a VRayColor, the same instance as
   the Falloff's first side). `reader/owner_slots.py` lists only Output's parameter 2 (slot 1), so parameter 0
   stays empty, and the 1.0.0 rule for an empty Output (drawn as over a white map, maxdrop-em3.76) gives white for
   side 2 where 3ds Max gives the VRayColor. At 1.0.0 the signature was `root:type` (the root's class differed); on
   this branch, after 1.0.1's Falloff rule, the same cause shows as `root.b.value` (side 2 white). Census: scene A
   has 8 Output maps, 6 with parameter 0 resolved through a stored index and these 2 with index -1 and a map at
   owner slot 0; scene B has 2, both without a map. The 3ds Max 2020 fixtures store parameter 0's index directly
   and list only parameter 2 in 0x0013, so the slot (0) rests on scene A's owner references and the oracle, not on
   a 0x0013 table. Projection: with `OUTPUT_MAP: {0: {0: 0, 2: 1}}` in a scratch copy, scene A gives 213 / 214,
   scene B stays 220 / 220. The reader is wrong; `maxdrop/reader/` is part E's alone: filed into part E.
2. **One VRayMtl: a Color Correction with custom rewiring (mode 3) whose four channel parameters (3 to 6) are held
   by Bezier Float controllers.** The reader gives `Animated`; `_rewire` (convert/texmaps.py) reports the rewiring
   as not converted and keeps the channels unchanged (`approximated`). The controllers' frame-0 values through
   `reader/controllers.py` are (0, 2, 2, 3), the oracle's. Covered by the open part E bead maxdrop-em3.152 (a
   parameter held by a controller; its scope names the Color Correction rewiring channels). Not filed again.

The oracle graph does not lag a converter rule in any of the four: the tool needs no rule change for them.
