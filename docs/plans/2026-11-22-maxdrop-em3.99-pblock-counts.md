Header rule found while recounting (scratchpad `recount3.py`, `recount4.py`): over all 11,516 blocks, the first
u32 of `0x0009` equals the owner's class index (its chunk id; never its object index) in 10,024 of 10,024; a

the same number as the "4448") as its first u32 in 1,492 of 1,492; the header's owner references the block in all
11,516. A rule does not go stale: it is pinned by a test instead of a range.
