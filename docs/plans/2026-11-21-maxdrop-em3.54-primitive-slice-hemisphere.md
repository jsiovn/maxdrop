# Primitives: Slice and hemispheres Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** build Slice on Sphere / Cylinder / Cone / Tube / Torus and the Sphere / GeoSphere hemisphere as 3ds Max 2020
does, instead of refusing them (bead maxdrop-em3.54).

**Architecture:** `maxdrop/convert/primitives.py` keeps one generator per class; each gains the option's rows,
caps, IDs, groups and UVs in 3ds Max's point and face order, found by probing 3ds Max 2020 headless
(`3dsmaxbatch.exe`, a scratch MAXScript dumping `o.baseObject.mesh` as `tools/fixtures/primitives.ms` does) and
compared with a scratch harness that runs `tests/unit/test_primitives.py`'s `compare()` on every probe dump.

**Tech Stack:** plain Python + numpy (no bpy), MAXScript for the probe and the fixture, Blender 4.2 / 4.5 / 5.2
for the fixture run.

---

## Facts found so far (probe 1, 2026-11-21, 73 meshes)

- Parameter ids (ParamBlock2 descriptors): Sphere 7 slice, 8 sliceFrom, 9 sliceTo; Cylinder 6, 7 from, 8 to;
  Cone and Tube 7, 8 from, 9 to; **Torus 7 slice, 8 sliceTo, 9 sliceFrom**. Sphere 3 hemisphere (float), 4 chop
  (0 chop, 1 squash), 5 recenter. GeoSphere 3 hemisphere (bool). Angles in radians.
- Sphere hemisphere: cut at polar angle (1 - h) * 180 deg. Chop: rings every 360 / segs deg, floor(cut / delta)
  + 1 rings, the last at the cut (a ring doubled when the cut falls on one). Squash: segs // 2 - 1 rings, delta =
  cut / (segs / 2 - 1), the last at the cut. A base fan (ID 1, group 2) to a center on the cut plane. V by row
  index (1 - k / (rings + 1)).
