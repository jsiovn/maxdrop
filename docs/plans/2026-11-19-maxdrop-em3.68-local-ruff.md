# maxdrop-em3.68 Run ruff in the local plain-test block Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A lint slip (E402 from 0518c1d) fails locally before it costs a CI round trip: block 1 of build-and-test
runs ruff at the version CI pins, and that version is written in one place.

**Architecture:** The pin moves to `[tool.ruff] required-version = "==0.17.5"` in `pyproject.toml` (ruff itself
refuses another version, exit 2: checked on 0.17.5). A new `tools/lint.py` reads that pin, finds a ruff of that
version (`ruff` on PATH, else `uvx --offline ruff@<pin>`, which never downloads) and runs `ruff check` with the
given arguments; without one it says how to get it and exits 3 (ruff itself uses 0, 1 and 2; review finding). CI installs `ruff<pin>` read from pyproject and
runs the same tool. `tests/test_lint.py` keeps the pin in one place (no ruff needed) and, when `tools/lint.py`
finds ruff, checks that the real tree passes and an E402 in a scratch copy fails; otherwise it skips with the
reason.

**Tech Stack:** Python 3.9+ standard library (local `python` is 3.9.13, CI 3.11 / 3.13: no `tomllib`), ruff
0.17.5, GitHub Actions bash.

---

Baseline (2026-11-19, before the change): `python -I -m unittest discover tests` -> `OK (skipped=4)`;
`uvx --offline ruff@0.17.5 check .` -> `All checks passed!`.

### Task 2: `tools/lint.py`

- `pin(path=pyproject.toml)` -> `"0.17.5"`: regex `^required-version\s*=\s*"==([0-9][0-9.]*)"` (multiline);
  `ValueError` when missing.
- `find_ruff(version)` -> argv prefix list or `None`: `shutil.which("ruff")` whose `--version` prints
  `ruff <version>`; else `shutil.which("uvx")` and `uvx --offline ruff@<version> --version` succeeds. Each probe
  has a timeout and catches `OSError` / `subprocess.SubprocessError`.
- `main(argv)`: no ruff -> stderr `MaxDrop lint: no ruff <v> found (...)` + how to get it, return 2; else run
  `<ruff> check <args or ".">` from the repo root, return its code.
