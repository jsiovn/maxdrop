# Standard map slots per shader Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Standard material's map slots are read at its shader's own map channels (bead maxdrop-em3.104).

**Architecture:** `convert/materials.py` gets a table `STD_SLOTS` (shader ClassId -> the channel of each slot the
rule reads, `None` where the shader has no such channel) beside `SHADERS`, replacing the Blinn-only `STD_*`
constants; `standard_mtl` looks its slots up by shader (Blinn's for an unknown or missing shader); Strauss reads
diffuse 0, glossiness 1, metalness 2 (driving the metallic input), opacity 3, bump 5, reflection 6.

**Tech Stack:** Python 3.11 syntax, plain unittest; 3ds Max 2020 for the fixture and its oracle.
