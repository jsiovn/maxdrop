# Empty Output, RGB Tint and VRayColor2Bump, measured Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw an Output or RGB Tint without a used map, and a VRayColor2Bump without a map, as what 3ds Max 2020
and V-Ray 5.2 render there (measured), instead of no graph and an issue.

**Architecture:** `maxdrop/convert/texmaps.py` only (bpy-free): `_wrapped` returns a Constant for a wrapper with no
used map; Output and RGB Tint keep wrapping it with their own Adjust / Tint (paths the builder already draws);
VRayColor2Bump leaves the peel table so its constant is not counted as a peel. Tests, module docstring,
docs/SUPPORT.md, docs/FORMAT.md, CHANGELOG.md follow.

**Tech Stack:** Python 3.11; 3ds Max 2020 + V-Ray 5.2 through the 3dsmax-mcp bridge (scratch scene, not committed).

## Measurement (done before the plan, scratch scene outside the repo)

3ds Max 2020, gamma off (`IDisplayGamma.colorCorrectionMode = #none`), V-Ray 5.2 linear color mapping, gamma 1, no
GI, no default lights; a plane under an orthographic camera, center pixel. Sub map for "map off": a Checker of one
color (200, 50, 50). Note: MAXScript `copy` of an Output drops `map1Enabled` (renders the map): the "off" cases use
the original map objects.

| case | renderMap | V-Ray, VRayLightMtl (blue base) | V-Ray, VRayMtl opacity (data) | V-Ray, VRayMtl bump | V-Ray, VRayNormalMap normal |
|---|---|---|---|---|---|
| Output, map unset / map1Enabled off | 1, 1, 1 | 1, 1, 1 (opaque) | 1 | flat | tilted = white map |
| Output, level 0.8, offset 0.1, amount 0.5, unset | = same Output over a white map | = same over a white map | | | |
| RGB Tint unset / off | 1, 1, 1 | 1, 1, 1 | 1 | flat | tilted = white map |
| RGB Tint (128,0,0 / 0,64,0 / 0,0,32) unset | 0.502, 0.251, 0.125 | 0.502, 0.251, 0.125 | 0.293 (mean) | | |
| VRayColor2Bump, map unset | 0.5, 0.5, 1 | 0.5, 0.5, 1 (opaque) | 0.667 (mean) | flat | flat |
| VRayColor2Bump over a white map | 1, 1, 1 | 1, 1, 1 | | | |

Findings:

1. An Output or RGB Tint without a map, or with map1Enabled off, renders exactly as the same wrapper over an opaque
   white map: white through its own Output part or tint.
2. A VRayColor2Bump without a map renders the color (0.5, 0.5, 1) (a flat normal's color): not white. It has no map
   switch parameter (params: map, height, bump_delta_scale).
3. On a data input V-Ray takes the mean of those colors, as for any constant (the `_swatch` rule).
4. In a bump input every case is flat (a constant height). In a normal map's normal input white tilts the normal
   (as a white map does); MaxDrop's builder draws a constant normal color flat: that case stays an issue.
5. Corona: not measured. A Corona render does not run on this machine (maxdrop-em3.28, em3.38): a debt
   bead is filed. renderMap (renderer independent) agrees with V-Ray.
6. The gamma-on case is not measured: the (0.5, 0.5, 1) is taken as a swatch (`_swatch`), exact with the gamma off,
   assumed with it on (white is 1 under either rule).

## Revision after review

- In NORMAL kind (a normal map's normal slot) every empty wrapper keeps no graph and its issue ("... in a normal
  input, not drawn"): a constant is a float there and an Adjust or Tint between it and the NormalMap would draw a
  tilt of another color, so no constant stands for V-Ray's tilt. In BUMP kind the constant stays (flat, exact).
- `_normal` in a color or data input skips a Constant side (an empty wrapper in its bump slot): it takes the other
  side's image, or none (unsupported), as before the change.
- Tests: `test_empty_wrapper_in_a_normal_input` (also below an Output with levels), `test_empty_wrapper_in_a_normal_map_class`,
  a DATA Tint assertion.
