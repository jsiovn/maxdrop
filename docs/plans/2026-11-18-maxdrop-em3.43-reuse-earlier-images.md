# Reuse an earlier import's image Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `MaterialBuilder.image` reuses an image datablock already in `bpy.data.images` (an earlier import, or the user's) when its file and color space match and it is untouched, instead of loading `name.001`.

**Architecture:** On the first texture a builder loads, it indexes the images already in the file that may be reused: local (no `library`), `source == 'FILE'`, not packed, not dirty, keyed by `(normcase(abspath(bpy.path.abspath(filepath))), colorspace_settings.name)`, first by name order. A key of this import found there is reused (its color space is not touched); otherwise the image is loaded with `check_existing=False` as today. Library images are left out: their path is relative to the library and they are read-only; reusing them would tie the import to a link the user may drop.

**Tech Stack:** Blender Python (bpy), tests/blender/run.py.

Bead: maxdrop-em3.43
