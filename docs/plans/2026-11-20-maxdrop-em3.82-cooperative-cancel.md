# Cooperative cancel for the read phase and very large meshes Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Esc on a modal import ends a running read within a node, and no build step of a very large mesh runs for
seconds (bead maxdrop-em3.82).

**Architecture:** `convert.scene.describe()` takes an optional `cancel` callable tested at the top of each node of
both of its walks and raises `convert.scene.Cancelled`; `ops._read_scene()` passes it on and tests it around the
material conversion; the threaded read gets a `threading.Event` that `ops._in_thread(stop=)` sets on close.
`build.objects.make_mesh()` becomes the drain of a phase generator that `build_steps()` steps through (repeating its
`(done, total)`) for meshes above `STEP_LOOPS` face corners; the sharp-edge lookup runs in chunks of edges.

**Tech Stack:** Python 3.11, numpy, Blender 4.2 / 4.5 / 5.2 (bpy only in `build/` and `ops.py`).

---

## Measured before (scene B, Blender 5.2, scratch scripts in the session scratchpad)

- read phase: `Scene.from_file` 0.12 s, asset table 0.01 s, `describe()` 6.64 s, material conversion 0.59 s.
- Esc 2 s into the read: `close()` 0.00 s, close to the worker's end 5.30 s (`_busy()` non-empty meanwhile).
- Stepped import: longest step 2.14 s, the largest mesh (5.6 M face corners). Its phases in isolation: corner
  vertex indices 0.65 s, material indices 0.33 s, positions 0.26 s, UVs 0.25 s, calc_edges 0.12 s, the sharp-edge
  lookup 2.7 s (numpy over every edge).

## Decisions

- `Cancelled(Exception)`, not a ValueError: `_UNREADABLE` must not report a cancel as "Not imported".
- The check is a callable (`stop.is_set`), so `convert/` needs no threading import and stays bpy-free.
- Not inside the material converters: `_read_scene` wraps `_material_slots` in `except Exception`, which would
  swallow it. Tested before and after instead (0.59 s on scene B).
- `foreach_set` cannot write a sub-range: a mesh's phases are the steps (add + positions, corner vertices, loop
  starts + material indices, calc_edges + flat faces, the sharp-edge lookup in chunks of `EDGE_CHUNK` edges, the
  sharp-edge attribute, each UV layer). An indivisible `foreach_set` of a huge mesh stays one step: its time is the
  residual, recorded in the close note. Never a yield between an `add()` and the `foreach_set` that fills it.
- `steps_of()` unchanged: a mesh's inner yields repeat its `(done, total)`.
- `close()` of a threaded read now joins the worker (`_STOP_WAIT`); measured on scene B after the change. If it
  blocks for more than about 1 s, the read gets a shorter join bound than the unpack (no staging to clean).
