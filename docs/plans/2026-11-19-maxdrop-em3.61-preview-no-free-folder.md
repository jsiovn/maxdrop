# Popup: no free pack folder, and previews keyed on the archive Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Scene Pack panel says when no folder name is free (instead of "Unpacks into a folder named after the
archive"), and the popup's previews are dropped when the archive at that path changed since invoke().

**Architecture:** `archive.preview()` raises `PackError` (the message `unpack()` would refuse with) when no
candidate folder name is free, and still returns None when the archive cannot be read. `ops._preview()` caches
that as `("none", message)` and `import_pack` draws it with icon ERROR. `_TARGETS` entries become
`(ops._key(path), parent, problem, previews)`; `_target_of(path)` returns the last three only while the key still
matches (a mismatch or a vanished file counts as missing).

**Tech Stack:** Python 3.11, Blender 4.2 / 4.5 / 5.2 (headless smoke), unittest.

**Files:**

- Test: `tests/test_intake.py` (class `Destination`)

- [ ] **Step 1: failing tests** in `Destination`:
  - one scene, `_CANDIDATES` patched to 3, folders `pack`, `pack (2)`, `pack (3)` each holding `notes.txt`:
    `preview()` raises `PackError` "No free folder", writes nothing, and its message equals `unpack()`'s.
  - several scenes: same with top folders `pack`, `pack (2)`, `pack (3)` holding `notes.txt` (no marker, no copy).
  - an unreadable archive path still returns None (already covered by `gone.zip`).
- [ ] **Step 2:** `python -I -m unittest tests.test_intake -k free` -> FAIL (preview returns None).
- [ ] **Step 3:** in `preview()`: stat inside its own `try/except OSError: return None`; call `_destination()` with
  only `except OSError: return None` so its `PackError` (only `_no_free_folder`) propagates. Docstring: "PackError,
  with unpack()'s message, when no folder name is free".
- [ ] **Step 4:** rerun -> PASS; whole `tests` -> OK.

- [ ] `_ON_DISK = ("reused", "in_place")`; `_preview()` and `import_files` read a .max only for those modes.

- [ ] smoke: `FakeLayout` records icons too; `two_scenes` stores `(ops._key(zip_path), folder, None, {})`; new

  with icon ERROR; (b) the pack rewritten at the same path with other bytes -> the panel shows the generic line
