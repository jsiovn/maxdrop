# Multi/Sub-Object material ID wrap Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A face whose material ID has no entry in its Multi/Sub-Object gets the sub-material 3ds Max renders it
with, instead of no material.

**Architecture:** `convert/materials.py` `MaterialConverter.material_for` looks an ID up per Multi/Sub-Object level
through a new `_entry(index, material_id)` that applies 3ds Max's wrap when the ID has no entry. Nothing else
changes: `assign` and the builder already follow `material_for`.

**Tech Stack:** plain Python (convert/ never imports bpy), unittest, Blender 4.2 / 4.5 / 5.2 smokes.

---

## The rule (oracle: 3ds Max 2020, scanline render of one face per ID, 2026-11-17)

Zero-based face ID `m`, `M` = the highest zero-based ID in the list, every entry counted (switched off or empty
too). An ID with an entry uses it. Otherwise the entry of `m mod (M + 1)`; when that has no entry either, or the
entry is off or empty, the face renders black in Max and stays without a material in MaxDrop. Each nested
Multi/Sub-Object wraps the original face ID by its own `M`. The renders (one-based IDs):

- IDs 1,2: 3->1, 4->2, 11->1, 14->2
- IDs 3,7: 10->3, 14->7, 17->3; 1, 2, 4, 5, 6, 8, 9, 11, 15 black (modulo the highest ID, not the entry count)
- IDs 7,3 in that list order: 10->3, 14->7 (by ID, not by list position)
- IDs 1,5,5: 5->first entry, 6->1, 10->5, 11->1
- IDs 1,2,3 with 3 off or empty: 4->1, 6 black (`M` stays 3)
- outer IDs 1,2 where 2 is a Multi with IDs 1,2,3: face 4 -> outer 2 -> inner 4 mod 3 -> inner 1

No new fixture: `vray_wrappers.max` already has a Multi/Sub-Object with IDs 1, 3 (off), 7, so its fixture test
covers the wrap on a real file by asking for IDs past 7.

```python
    def _entry(self, index, material_id):
        """The sub-material object index (or None) a face ID picks in Multi/Sub-Object index. An ID without an
        entry wraps as 3ds Max renders it: modulo the highest ID of the list plus one (every entry counted)."""
        entries, order = self._multi(index)
        if material_id not in entries and order:
            material_id %= max(order) + 1
        return entries.get(material_id)
```
