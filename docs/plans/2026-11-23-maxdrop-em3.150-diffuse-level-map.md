# Standard shaders: Diffuse Level on a diffuse map and the Diffuse Level map Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Standard material of Anisotropic, Multi-Layer, Oren-Nayar-Blinn or Translucent Shader imports its
diffuse map scaled by the Diffuse Level, and its Diffuse Level map replacing the level by its amount.

**Architecture:** `convert/materials.py` reads the Diffuse Level map channel (`StdSlots.diffuse_level`), puts the
level on the diffuse `MapRef` (`scale`, applied by `convert/texmaps.py` `_slot` to the map before the amount mix),
and with a level map a `DiffuseLevel` on the IR, which `texmaps.texture_graphs` turns into the base color graph
`Multiply(diffuse at level 1, Tint-mean(Mix(level, level map, amount)))`. `build/materials.py` is unchanged: every
node is one it already draws.

**Tech Stack:** plain Python (convert/, unittest), MAXScript (3ds Max 2020, 3dsmaxbatch), Blender 4.2 / 4.5 / 5.2.

---

## Measured (3ds Max 2020, Default Scanline, gamma off; probe outside the repo)

A plane lit head-on by a free direct light, swatch (100, 60, 30), specular level 0, flat Checker maps; the center
pixel against the same shader at level 100 without maps. Same numbers on all four shaders (Anisotropic,
Multi-Layer, Oren-Nayar-Blinn, Translucent):

- Level map grey 128 at amount 100: 0.502 at level 50, 100 and 150 (the map replaces the level); grey 255: 1.0,
  grey 64: 0.25, black: 0.
- Amount 50: grey 128 at level 50 -> 0.5006; grey 255 at level 150 -> 1.25: level = lerp(level, map, amount).
- Map switched off: the level alone (0.5).
- Diffuse map grey 128 at level 50: 64 (= 128 x 0.5); at amount 50: lerp(swatch, 128, 0.5) x 0.5; with a level map
  grey 255 amount 100: 128; both at amount 50: lerp(swatch, 128, 0.5) x lerp(0.5, 1, 0.5).
- A red, green or blue level map: 1/3; yellow 2/3: the mean of the channels.

So diffuse = lerp(swatch, diffuse map, Ad) x lerp(level, mean(level map), Al), on stored (display) values with the
gamma off. Gamma on not rendered: assumed the same product on linear values.

In Blender the maps arrive decoded (the gamma-off sRGB curve): a plain linear x level on a decoded map is too
bright (0.5 map at level 0.5: 0.107 linear for 3ds Max's 0.25 display = 0.051). The level constant goes through the
swatch rule unclamped (gamma off: `srgb_to_linear(level)`, ~level^2.4, gamma on: level), and the level map is a
MASK graph (decoded with the gamma off, linear with it on): within ~10 % in linear, the class of approximation the
gamma-off mixes already accept.
