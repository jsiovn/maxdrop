# Checker as nodes (a pattern leaf of the texture graph) Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Checker map converts to a Mix of its two sides by a 0 / 1 checker pattern (a new IR leaf `Checker`) and
the builder draws that pattern with Math nodes, instead of "no bitmap below".

**Architecture:** `convert/texmaps/maps_pattern.py` holds the rule (`_checker`, in `_KEEP`), the bpy-free evaluator
(`placed_uv`, `checker_value`: the one formula) and its provisional constants. `ir.py` gets the leaf
`Checker(mapping, soften)`. `build/materials/` draws it (`_Tree.checker`: UV -> Mapping node (placement times the
squares per tile) -> Separate XYZ -> FLOOR x 2 -> ADD -> WRAP(2, 0)). The Blender tests mirror it (`_fold` -> MAP) and
the node evaluator (`_sample_vector`) learns ADD, so a builder check compares the nodes with `checker_value`.

**Tech Stack:** Python 3.11, Blender 4.2 / 4.5 / 5.2 shader nodes, unittest.

---

## Decisions (bd notes)

- Bump slot (kind BUMP): the Bump of the leaf itself, as the bead says; non-default sides (colors other than black /
  white, or a side map) are a report line ("its sides in a bump slot not converted: drawn black to white"). Below a
  color wrapper in a bump graph (BUMP_RGB) the Mix, as in a data graph.
- Normal slot (kind NORMAL): None and an issue; not counted in stats.unsupported (it has a rule; "Map classes
  without a map below" would be false). `_sub` adds the parent's "converts to nothing" line.
- Not in DISPLAY_MIXES / MASK_MIXES: a 0 / 1 mask picks one side, so decoding before or after the mix is the same
  (holds while soften is not drawn).
- Provisional (not measured, until maxdrop-o53.3.9): color 1 on the square at the placed UV origin
  ((floor(2x) + floor(2y)) even), 2 squares per tile per axis (CHECKER_SQUARES), soften drawn as 0 (an issue when
  above 0). The placement is the UVGen's, as a Bitmap's (tiling about the tile center, offset, angles).
- UVGen tile off / mirror on: not drawn (the pattern repeats), an issue. Map channel 0 (vertex color): UV channel 1,
  an issue (in convert, so the builder never sees channel 0). Environment / XYZ / real-world: `_placement_issues`.
- A Checker is exact: never walk.approximated, never stats.approximated.
