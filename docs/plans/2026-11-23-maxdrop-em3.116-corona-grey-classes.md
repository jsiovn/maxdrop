**Goal:** The Corona material classes that import grey under "Material classes without a rule" get a rule:
CoronaHairMtl a surface approximation, CoronaShadowCatcherMtl Blender's shadow catcher object setting, CoronaVolumeMtl,

shadow-catcher IR. A new fixture `corona_classes` holds each class (corona_more is at 983 KB: no room).

**Tech Stack:** Python 3.11 syntax, `unittest`; 3ds Max 2020 + Corona 12 (`3dsmaxbatch`) for the fixture and its
oracle; Blender 4.2.23 / 4.5.16 / 5.2 headless.

## Rules

- **CoronaHairMtl** (not measured: no Corona render here) -> one Principled layer, as Blender's Principled Hair BSDF
  (Cycles 4.2 source, `svm/closure.h`, `closure/bsdf_util.h`) colors a strand from melanin, read as Corona's melanin
  (amount) and pheomelanin (the fraction that is red, Blender's Melanin Redness): c = -ln(max(1 - melanin, 1e-4)),
  sigma = c (1 - r) (0.506, 0.841, 1.653) + c r (0.343, 0.733, 1.924) + sigma_tint, sigma_tint = (ln(tint) / f)^2 per
  channel (tint = colorTint x levelTint, clamped to 1e-4..1), f = 5.888 (Blender's roughness scale at its default
  Radial Roughness 0.3); color = exp(-sqrt(sigma) f). Base = min(1, color + colorDiffuse x levelDiffuse); the tint
  map at its amount drives the base color; roughness = 1 - glossiness (map inverted); IOR; specular 1; alpha =
  mono_swatch(colorOpacity) x levelOpacity (map); bump. Maps in the other slots: named issues (`_unread_map`).
- **CoronaShadowCatcherMtl** -> a grey material (the default grey) with `shadow_catcher` set; an object whose every
  material slot (every face's material) is one gets `is_shadow_catcher` (Cycles; EEVEE has none). A backplate map and a
  reflection level above 0 are named issues.
- **CoronaVolumeMtl, CoronaScannedMtl, CoronaSlicerMtl** -> grey (as before) with a named issue ("volume not
  converted", "scanned material (.ctf) not read", "slicing not converted"), no longer counted under "Material classes
  without a rule".
