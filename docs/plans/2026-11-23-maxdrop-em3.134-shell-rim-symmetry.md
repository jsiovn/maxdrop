# Shell rim above a Symmetry Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A converted Shell above a converted Symmetry hardens its rim as 3ds Max 2020 does: the mesh's open edges
are marked sharp before the Mirror, except those the Mirror welds shut (both ends within its merge threshold of
their copies), which would otherwise become a hard seam on the mirror plane (bead maxdrop-em3.134).

**Architecture:** `convert/scene.py`: `_rim` no longer refuses a Mirror below the Shell; `_mirrors(converted,
shell)` lists the Mirrors below it; `welded(positions, mirror)` says which vertices Blender's Mirror merges with
their copies (|p - R p| < merge_threshold, R = F S F^-1, F the mirror object's matrix, identity when None; nothing
with the weld off); `_rim_edges` drops the open edges whose two ends are welded; the mesh key's rim entry holds the
Mirrors' settings and matrices (`("rim", True)` stays without a Mirror). `rim_issues` counts the rim corners on the
mesh with its mirrored, welded copies (`_mirrored`, caller side: `rim_corners`' body is part F's).

**Tech Stack:** Python + numpy (convert/, no bpy), MAXScript in 3ds Max 2020 (probe, fixture), Blender 4.2/4.5/5.2.

Bead: maxdrop-em3.134
