# VRayIES header rules, measured in V-Ray Implementation Plan

> **For agentic workers:** Use subagents when appropriate to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `convert/ies.py` give the flux and rated lumens V-Ray 5.2 renders a VRayIES with (override off),
from renders with self-authored isotropic LM-63 files, and record the pixels in docs/FORMAT.md.

**Architecture:** `convert/ies.py` parses the header and integrates the candela table; `Photometry.scale` is what
the VRayIES power is multiplied by (`convert/lights.py _describe_ies`). The measurements change four rules: the
ballast factor applies, the rated lumens are lamps x lumens per lamp, types A and B are read with their own
integral, and candelas are interpolated linearly in angle (not in cosine). The missing-file case needs no code.

**Tech Stack:** plain Python (convert/ never imports bpy), unittest; 3ds Max 2020 + V-Ray 5.2 (3dsmaxbatch) for the
measurements, scratch outside the repo.

Bead: maxdrop-em3.138 (part E, maxdrop-6n0.6). Owns in `convert/ies.py`: `parse`, `_flux`, `Photometry`, the module
docstring (em3.139 later rewrites `_Numbers` and `_tokens_after_tilt`: not touched here); in `convert/lights.py`:
`_describe_ies`, `IES_LAMPS`, the VRayIES docstring lines.

## Rules to implement

- flux = (integral of the linearly interpolated candela table) x candela multiplier x ballast factor.
- scale = flux / (lamps x lumens per lamp) when lumens per lamp > 0; else 1 (power is the flux).
- Type C zone [a, b] (polar angle from the nadir): `Ia cos a - Ib cos b + (Ib - Ia)(sin b - sin a) / (b - a)`.
- Types A and B zone [a, b] (latitude): `Ib sin b - Ia sin a + (Ib - Ia)(cos b - cos a) / (b - a)`; vertical angles
  from -90 or 0 (mirrored, x2) to 90; horizontal from -90 to 90, or (type B only) from 0 to 90 (mirrored, x2);
  trapezoid over the planes in radians. Anything else: not read (IesError). Type A from 0: not read.
- Negative ballast factor: refused like a negative multiplier.
- IES_LAMPS goes (the lamps are applied, measured).
